# 📷 Photo Manager

**[ 🇯🇵 日本語 (Japanese) ](README.md) | [ 🇺🇸 English ](README_EN.md)**

**Picasa / Tiat にインスパイアされた、RAW・一般画像向けのローカル高速写真ビューア ＆ 選別（セレクト）ツール**

大量の写真（JPEG / PNG / WebP / HEIC および各社一眼カメラの RAW データ）を、元のフォルダ構造やファイルを1バイトも傷つけずに、待ち時間ゼロで軽快に閲覧・選別・整理できる Windows 向けスタンドアロンアプリケーションです。

## ⚠️ Googleドライブ共有・ダウンロード時に「マルウェア（ウイルス）」扱いされる件について

本ソフトを Googleドライブ等で共有・ダウンロードしようとしたり、初回起動したりする際に、**「マルウェア（ウイルス）の疑い」「Windows によって PC が保護されました（SmartScreen）」** といった警告が出ることがあります。

### ❓ なぜ警告が出るのか？（本当にウイルスなの？）
* **ウイルスや不正なプログラムは一切含まれていません**（外部への通信機能すら持たない完全オフライン動作アプリです）。
* ただし、個人の趣味開発であり、年間数万円〜十数万円かかる商用の「コード署名証明書（EV証明書）」を取得していないため、**署名のない自作の `.exe` ファイル（起動用ランチャー）や `autorun.inf`（USBアイコン設定）** が含まれていると、Googleドライブの自動スキャンや Windows Defender / SmartScreen が「身元不明の実行ファイル＝マルウェアかも」と機械的にブロックしてしまいます。

### 🛡️ 本ソフトでの対策（`Build.bat` 方式）
1. **`PhotoManager.exe` を最初から同梱していません**
   * クラウド共有時の誤検知を防ぐため、本リポジトリおよび配布パッケージ（`dist/`）には、最初から `PhotoManager.exe` や `autorun.inf` を入れていません。
2. **初回に `Build.bat` をダブルクリックするだけで手元で安全に作れます**
   * フォルダ内の **`Build.bat`** をダブルクリックすると、Windows に最初から標準搭載されている公式コンパイラ（`csc.exe`）を使って、わずか数十行のテキストコード（[`launcher/Launcher.cs`](launcher/Launcher.cs) — メモ帳で中身をすべて確認できます）から **お使いのPC上で直接 `PhotoManager.exe` を1秒で作成し、そのままアプリを起動**します。
   * 自分のPC内でコンパイルされた `.exe` になるため、ダウンロードブロックや SmartScreen の警告が出にくくなります（2回目からは作成された `PhotoManager.exe` で起動できます）。
3. **💡 Googleドライブ等で知人に配布・共有するときのコツ**
   * `build_dist.bat` を実行して作られる `dist/` フォルダは、誤検知の原因になる `PhotoManager.exe` と `autorun.inf` を自動で除外したクリーンな状態で出力されます。
   * もし Googleドライブの仕様変更等で、同梱のポータブルPython環境（`python/` フォルダ内の公式 `python.exe` 等）や `.bat` ファイルまで誤検知されて共有できない場合は、以下のいずれかの方法をお試しください：
     * **方法A**: `python/` フォルダを除いた状態で共有し、受け取った方のPCで初回に `setup_portable_python.bat`（公式Pythonの自動取得）→ `Build.bat` を実行してもらう。
     * **方法B**: 7-Zip 等でパスワード付きアーカイブにして共有する。

## ✨ 主な特徴

1. **🔍 「排他検索（除外フィルタ）」にこだわった作り**
   * タグ（アルバム）で絞り込む際、単に「そのタグを含む `[+]`」だけでなく、**「そのタグを除外する `[-]`（排他検索）」** に徹底してこだわった作りになっています。
   * フォルダや撮影日と組み合わせることで、**「このアルバム（タグ）に含め忘れた画像」を比較的簡単に探せます！**
2. **🛡️ 完全非破壊（元ファイルは1バイトも変更しません）**
   * アプリ内で写真を回転・トリミング・傾き補正・明るさ調整したり、「棄（ボツ）」の評価を付けても、PC内の元ファイルやフォルダ構造は一切変更・削除されません。
3. **🔒 完全オフライン動作（プライバシー保護）**
   * 写真を外部クラウドへ送信することは一切ありません。AIによる自動タグ付け（ONNX Runtime / CLIP）も、GPS座標からの撮影場所（国・都道府県・市区町村）判定も、すべてローカルPC内だけで完結します。
4. **⚡ 片手でサクサク進む高速セレクト ＆ スタック管理**
   * **4段階評価**: 数字キー（`1`:優 / `2`:良 / `3`:棄 / `0`:可）だけで数万枚の写真を高速仕分け。「棄」にした写真は一覧から即座に隠れます。
   * **連写・露出ブラケット（AEB）・重複写真のスマート管理**: 連写やブラケット撮影、複数フォルダに散らばった重複写真を自動で束ねて表示。拡大表示（ライトボックス）中は `↑` / `↓` キーでブラケットの明暗（EV+ / EV-）や連写カットをその場で比較できます。
   * **スマート・テイクアウト（一括書き出し）**: 選んだベストショットを、非破壊調整（傾き・切り抜き・明るさ）の焼き込み＋用途別リサイズ＋Exif個人情報のクリーニングを行って別フォルダへ安全に一括出力します。
5. **🔌 USBメモリ持ち歩き ＆ 📱 スマホ（Android）ハイブリッド選別**
   * **USBポータブル自走**: Python が入っていない別PCでも、USBメモリや外付けSSDからそのまま起動。ドライブレター（`D:` → `E:` 等）が変わっても自動追跡します。
   * **スマホでのオフライン選別（`PhotoManager_Mobile.html`）**: SQLite データベース（`cache/library.db`）内に高画質 WebP サムネイルを完全内蔵。WebAssembly（`sql.js`）により、数百GBの元写真が無くても `.db` ファイル1つをスマホのメモリへ約1秒で読み込み、**USBメモリを抜いてベッドや移動中に親指ワンタップで選別 → 後からPCへ差分同期**できます（同一Wi-Fiでのリアルタイム直結 `/m` にも対応）。

## 🚀 セットアップと起動方法

### パターンA：配布パッケージ（` python/` 同梱版）を使う場合
1. **初回のみ**: フォルダ内の **`Build.bat`** をダブルクリックします。
   * アイコン付きの `PhotoManager.exe` が自動作成され、そのままアプリが起動します。
2. **2回目以降**: 作成された **`PhotoManager.exe`** をダブルクリックして起動します（黒いコマンド画面を出さずに専用ウィンドウが最大サイズで開きます）。

### パターンB：GitHub からクローン／ダウンロードして使う場合
GitHub のリポジトリには、容量の大きいポータブル Python 本体（`python/`）を含めていません。初回のみ以下の2ステップを実行してください（PC本体への Python インストールは不要です）。

1. **`setup_portable_python.bat` をダブルクリック**（要インターネット接続・初回のみ）
   * Python 公式サイトから Embeddable Python 3.11 と必要ライブラリ（FastAPI, Pillow, rawpy, ONNX Runtime 等）が `python/` フォルダへ自動でダウンロード・構築されます。
2. **`Build.bat` をダブルクリック**
   * `PhotoManager.exe` がビルドされ、アプリが起動します。
