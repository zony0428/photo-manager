# Photo Manager

**日本語 | [English](README_EN.md)**

Picasa および Tiat にインスパイアされた、RAW・一般画像向けのローカル高速写真ビューア・選別（セレクト）ツールです。  
大量の写真（JPEG / PNG / WebP / HEIC および各社一眼カメラの RAW データ）を、元のフォルダ構造やファイルを1バイトも変更することなく、待ち時間ゼロで閲覧・選別・整理できる Windows 向けスタンドアロンアプリケーションです。

## コアコンセプト

### 1. 写真が主役になるストイックな画面設計（v3.00 新UI）
カラー絵文字や太い枠線などの視覚的ノイズを徹底的に排し、写真の色彩と階調が最も映えるニュートラルなインターフェースを採用しています。
- **1段スリムヘッダー（高さ 44px）**: レイアウト切替、サムネイルサイズ、ソート、テーマ切替（`和紙` / `夜墨`）、言語切替（`JP` / `EN`）を1行に集約。
- **2段階左サイドバー**: 左端の「垂直タブレール（`クイック / フォルダ / タグ / ジオタグ / 年月 / 機材 / ラボ / 検索`）」と、1つのパネルを縦 100% の高さで表示する「メニューエリア」に分離。メニューをオフにしても左端のアイコン列は残り、クリック時に写真グリッド上へスマートにオーバーレイ展開します。また、メニュー最上部にはいつでもアクセスできる「種別フィルタ」と「評価フィルタ（`優 / 良 / 可 / 棄`）」を常設しています。
- **4:3 プレビュー ＆ 常時表示クイック EXIF**: 右インスペクタには見切れのない `4:3` プレビューと、タブを切り替えずに撮影日時・解像度・カメラ/レンズ名・露出パラメータを一目で確認できるクイックサマリを常設しています。

### 2. 完全非破壊と XMP サイドカー連携
写真の回転、クロップ、傾き補正、トーン調整、撮影日時のシフト補正、および「棄（ボツ）」の評価を行っても、ディスク上の元ファイルは一切変更・削除されません。  
Lightroom や Adobe Camera Raw 等の同名サイドカー（`.xmp` / `.pp3` / `.dop`）が存在する場合は、右インスペクタの `XMPプレビュー` ボタンを押している間だけ現像パラメータを反映して比較できるほか、評価や階層タグ（既存ツリーと混ざらない `XMP/...` ルート配下に隔離）を安全に取り込めます。

### 3. 排他検索（除外フィルタ `[-]`）とタグ階層管理の分離
タグ（アルバム）や「機材（カメラボディ ＞ 装着レンズ階層）」で絞り込む際、条件を含む `[+]` だけでなく、特定の条件を除外する `[-]`（排他検索）に対応しており、「アルバムに入れ忘れた写真」や「特定のレンズ以外で撮影した写真」を即座に抽出できます。  
日常のタグ付与は右インスペクタおよび右クリックメニューで行い、ドラッグ＆ドロップによる階層組み替え・リネーム・一括削除は「設定」内の専用「タグツリーエディタ」に分離することで、選別中の操作事故を防ぎます。

### 4. 完全ローカル動作・ポータブル自走とアプリ内ストレージ（`storage/`）
写真データを外部クラウドへ送信することは一切ありません。Webフォントや Leaflet もローカル同梱しており、外部サーバーへの写真アップロードや外部CDN通信は行いません（地図の背景タイル表示時のみ OpenStreetMap に接続します）。ONNX Runtime（CLIP）による AI 自動タグ付けも、GPS 座標からの撮影地域（国・都道府県・市区町村）の逆ジオコーディングも、すべてローカル PC 内で完結します。スマホ連携時もQRコード埋め込みトークン認証とAPIホワイトリストにより、同一Wi-Fi環境からの不正アクセスを多層防御します。  
Python がインストールされていない PC でも USB メモリや外付け SSD からそのまま起動でき、外部写真を取り込む際はアプリ内の `storage/` フォルダへコピー集約し、サブフォルダ管理、ドラッグ＆ドロップ移動、`F2` キーによる単一・一括連番リネーム、外部エクスポートまでを、付随するサイドカーやペア RAW ファイルごと自動追従して一元管理できます。

| | **2枚比較（Duel）** | 2枚の写真を左右に並べ、同期ズーム＆パンでピントや描写を厳密比較。`W` キーによる勝ち抜き選別に対応 |
| | **スマートスタック** | 連写・露出ブラケット（AEB）・重複写真を自動で束ねて表示。ライトボックス中は `↑` / `↓` で束内のコマを瞬時に比較 |
| **検索・フィルタ** | **常設種別・評価フィルタ** | 左メニュー上部に種別（`すべて` / `RAW` / `調整済` / `JPEGのみ` / `RAW+JPGペア` / `XMPあり`）と評価（`優 / 良 / 可 / 棄`）を常設 |
| | **タグ・機材ツリー排他検索** | タグおよび「カメラ ＞ レンズ」階層での `[+]` 含む / `[-]` 除外フィルタ。`枚数順` トグルと名前順（辞書順 / 自然順）切替に対応 |
| | **マルチ軸ソート** | 撮影日時、評価、ファイル名、ファイルサイズ、焦点距離、F値、シャッター速度（高速↔低速）、ISO感度での並び替えに対応 |
| **非破壊調整・補正** | **クロップ・傾き・トーン調整** | 水平線の微小角度補正（±45°）、アスペクト比固定クロップ、露出・コントラスト・彩度の調整と複数写真への一括ペースト |

| **書き出し・印刷** | **スマート・テイクアウト** | 非破壊調整の焼き込み、用途別リサイズ、撮影順の連番リネーム、Exif 消去、およびオプションの `.xmp` 出力を一括実行 |
| | **ベタ焼き HTML 出力** | 選択した写真を暗室ネガシート風の単一 HTML（コンタクトシート）として出力。赤鉛筆マークチェックや A4 印刷に対応 |
| **分析・発掘（ラボ）** | **勝ちレンズ・得意設定カルテ** | 過去の評価データ（優・良の歩留まり率）から、相性の良いレンズや得意な焦点距離・F値・撮影時間帯を自動診断 |
| | **太陽高度・手ブレ注意抽出** | 撮影日時と GPS から太陽高度を算出し、マジックアワー・ブルーアワー・夜景を抽出。`< 1/焦点距離 秒` の微ブレ危険カットも検出 |

| | **歴代の今日・未整理ガチャ** | 過去の同じ月日に撮影した写真の振り返り（On This Day）や、未整理フォルダをランダムに引き当てる発掘機能 |

## セットアップと起動方法

### パターンA：配布パッケージ（GitHub Releases の ZIP）を使う場合

1. **初回導入（フルパッケージ版 `PhotoManager_vX.XX.zip`）**  
   ZIP を任意のフォルダ（または USB メモリ）に解凍し、`PhotoManager.exe` をダブルクリックして起動します。黒いコマンドプロンプト画面を出さずに専用ウィンドウが開きます。
2. **既存環境のアップデート（軽量差分版 `PhotoManager_vX.XXdiff.zip`）**  
   すでにフルパッケージ版が稼働している環境では、`python/` や `models/` を再ダウンロードする必要はありません。軽量な差分版 ZIP を解凍して既存フォルダへそのまま上書きコピーするだけで、データベース（`cache/`）や `storage/` を維持したままアップデートが完了します。

> [!IMPORTANT]
> **初回起動時に「Windows によって PC が保護されました（SmartScreen）」と表示される場合について**
>
> 本ソフトは写真の外部送信やレジストリ変更を行わない完全ローカル動作アプリケーション（地図タイル表示時のみ外部接続）ですが、商用の EV コード署名証明書を取得していない個人開発ソフトであるため、ダウンロード直後の `PhotoManager.exe` に対して Windows Defender SmartScreen が確認画面を表示することがあります。以下のいずれかの方法で起動できます。
>
> 1. **そのまま実行する**: SmartScreen の画面で **「詳細情報」→「実行」** をクリックします（2回目以降は表示されません）。
> 2. **`Build.bat` で手元でクリーン生成する**: フォルダ内の **`Build.bat`** をダブルクリックすると、Windows 標準搭載の公式 C# コンパイラ（`csc.exe`）を使用し、平文のソースコード（[`launcher/Launcher.cs`](launcher/Launcher.cs)）から自分の PC 上で直接 `PhotoManager.exe` を1秒でビルドして起動します。ローカルで生成された実行ファイルとなるため、ダウンロード由来のブロック（Mark of the Web）が付かずスムーズに起動できます。

### パターンB：GitHub リポジトリからクローンして使う場合

Git リポジトリには大容量のポータブル Python 本体（`python/`）を含めていません。初回のみ以下の2ステップを実行してください（PC 本体への Python インストールは不要です）。

1. **`setup_portable_python.bat` を実行**（要インターネット接続・初回のみ）  
   Python 公式サイトから Embeddable Python 3.11 と依存ライブラリ（FastAPI, Pillow, rawpy, ONNX Runtime 等）が `python/` フォルダへ自動でダウンロード・構築されます。
2. **`Build.bat` を実行**  
   `PhotoManager.exe` がコンパイルされ、アプリケーションが起動します。
