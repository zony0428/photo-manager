# TETHERACT pm（テザラクト・フォトマネージャー）

日本語 | [English](README_EN.md)

Picasa や Tiat に着想を得た、Windows 向けのローカル写真ビューア・選別・非破壊管理ツールです。  
JPEG / PNG / WebP / HEIC や各社カメラの RAW データを、元ファイルや既存のフォルダ構造に一切変更を加えることなく軽快に閲覧・比較・整理できます。

すぐに試す場合は、[GitHub Releases](../../releases) から最新版 ZIP をダウンロードして解凍し、`Tetheract.exe` を起動してください（インストール・事前ランタイム導入は不要です）。

> 旧称「Photo Manager」は v1.0.0 より **TETHERACT pm**（映画『インターステラー』の超立方体 Tesseract と、記憶を繋ぎ止める Tether を掛け合わせた造語）へ改称しました。既存のデータベース（`cache/`）や写真はそのまま引き継げます。

## 特徴

### 1. 保存先に縛られない、簡単で自由な分類と検索。
フォルダ分けや保存場所をソフトの都合で作り直す必要はありません。普段のフォルダ構造はそのままに、複数のドライブをまたいでタグや撮影情報から自由に写真を束ねたり引き算したりできます。

- 既存フォルダのまま横断管理：PC内蔵ドライブや複数の外付けドライブを、既存のディレクトリ構造のまま横断して閲覧・検索できます。
- タグと機材の包含 `[+]`・除外 `[-]` 検索：階層タグや「カメラ ＞ レンズ」で、含む `[+]` と除外 `[-]` を直感的に組み合わせられます（同グループ内は OR、別グループ間は AND、ワンクリックで反転可）。付け忘れたタグのあぶり出しも簡単に行えます。
- 自然文フィルタバーと条件保存（`Binder`）：絞り込み条件を自然な文章で表示し、条件ピルから兄弟タグの追加・除外や「全年の同じ月」への切り替えが可能です。よく使う条件の組み合わせは `Binder` に保存してワンクリックで呼び出せます。
- 多角的な絞り込みとEXIFソート：撮影年月（カレンダー対応）、場所（国 ＞ 都道府県 ＞ 市区町村）、12色カラー、形式・状態、4段階評価での絞り込みと、焦点距離・F値・シャッター速度・ISO感度等での並び替えに対応しています。
- 撮影傾向を振り返る「ラボ」と地図：47都道府県の撮影白地図・ヒートマップ・移動軌跡や、高評価率から集計する「勝ちレンズカルテ」、太陽高度計算によるマジックアワー抽出を備えています。

### 2. 元データは汚さず壊さず。でも、見るだけでは終わらない。
元の写真ファイルやフォルダには1バイトも触れず、管理用の隠しファイルも作りません。その一線を厳守したまま、選別から調整・書き出しまでをひとつながりで行えます。

- 元ファイル・元フォルダへの書き込みゼロ：回転、調整、タグ付け、「棄（ボツ）」の評価を行っても元ファイルは変更されず、記録はすべてアプリ内の `cache/library.db` 1箇所に保存されます。
- 非破壊の回転・傾き・トリミング・トーン調整：90°回転、水平出し（±45°）、トリミング、明るさ・コントラスト・彩度の調整（リアルタイムヒストグラム連動・複数枚への一括コピペ対応）を非破壊で行えます。
- 日時シフト補正とスマホGPS引き継ぎ：カメラの時計ズレや時差の一括補正（元のEXIF日時へ復元可）と、前後1時間以内のスマホ写真からのGPS位置情報の引き継ぎに対応しています。
- 外部現像ソフト・既存XMPサイドカー連携：外部ソフトでの編集や `.xmp` 出力をウィンドウ復帰時に自動検知して表示へ反映します。既存の `.xmp` 等も書き換えずに読み取り、調整比較プレビューや評価・階層タグの隔離取り込みができます。
- 用途に合わせた書き出し：調整反映・リサイズ・連番リネーム・EXIF消去を一括で行う「スマート・テイクアウト」、暗室風の「ベタ焼きHTML」出力、クリップボードへの画像コピー（<kbd>Ctrl</kbd>+<kbd>C</kbd>）を備えています。
- 専用保管庫「Loome」（`Loome/`・外付け `<Drive>:\Loome`）での実ファイル整理：実ファイルごと整理したい写真だけを `Loome` へ高速コピーすれば、ペアのRAWや `.xmp` を自動追従させながらカスケードメニューやD&Dでの移動、一括連番リネーム（<kbd>F2</kbd>）を行えます。

### 3. 作業を邪魔しない、Look&Feel。
写真の色彩が素直に見える静かな画面設計と、キーボードと最小限の視線移動だけでテンポよく選別を続けられる操作感を重視しました。

- 静かな画面設計と4つの外観テーマ：装飾や絵文字を抑え、視線移動の少ない下部フッター統合ツールバー（上部配置へも切替可）、4つのテーマ（`Tetheract D / L`・`夜墨`・`和紙`）、`JP` / `EN` 言語切替を備えています。
- 3つの一覧レイアウト：標準グリッド、縦横比を保つ「びっしり表示」、フィルム枠風の「マウント表示」を切り替えられ、文字情報の非表示（<kbd>I</kbd> キー）や左右パネル開閉で画面を広く使えます。
- 各社RAWの軽快な表示と原本1:1高精細ズーム：SIGMA Foveon（`X3F`）や SONY ロスレス圧縮（`ARW`）をはじめ各社RAWの埋め込みプレビューを直接抽出し、メーカー固有の色味のまま即座に表示します。拡大時も縮小テクスチャの引き伸ばしを行わず、常に原本フル解像度（1:1等倍基準）から精細に描画します。
- 連写・ブラケットを束ねるスマートスタック：連写、露出ブラケット（AEB）、RAW+JPEGペア、重複写真を自動で1つに束ね（最高評価のコマを自動で代表表示）、拡大表示中の <kbd>↑</kbd> <kbd>↓</kbd> キーで軽快にコマ送りできます。
- 片手レーティングと2枚比較（Duel）：数字キー（<kbd>1</kbd>: 優 / <kbd>2</kbd>: 良 / <kbd>3</kbd>: 棄 / <kbd>0</kbd>: 可）だけで片手選別ができ、迷う2枚は <kbd>V</kbd> キーで左右に並べて同期ズーム・波形比較と勝ち抜き選別（<kbd>W</kbd> キー）ができます。
- 誤操作を防ぐタグ編集設計：複数選択時は全写真に共通するタグのみ一括削除を許可して誤消去を防ぎ、タグ階層の移動・リネーム・削除は「設定」内の専用エディタに分離しています。

### 4. クラウドには頼らない。でもポータブル。
外部クラウドに依存せず、すべての処理をローカル環境で完結させています。フォルダごと外付けSSDやUSBメモリに入れれば、別PCや外出先のスマートフォンでも安全にライブラリを扱えます。

- 外部送信ゼロのローカル完結動作：写真の外部送信や外部CDN通信は一切行いません（地図タイル表示時のみOpenStreetMapへ接続）。ローカルAI自動タグ付け（CLIP・カラー再判定）や撮影地の都道府県・市区町村判定もPC内で完結します。
- インストール不要・USB単体起動とクリーン更新：ポータブルPython・ランタイムDLL・DBが単一フォルダに収まっており、どのPCでも `Tetheract.exe` から即座に起動できます。更新も差分ZIPを置いて起動するだけで古い不要ファイルを一掃してクリーン更新できます。
- メディア個体識別と抜き挿し自動検知：ボリュームシリアル番号（VSN）によりドライブ文字の変動に自動追従し、複数のSDカードを同じカードリーダーで差し替えても個別に認識・即時反映します。SDカード上で付けた評価・タグ・調整はPCや `Loome` へ移動した際にも自動で引き継がれます。
- 3段階セキュリティとエシカル保護：パスワード不要の標準状態（`Lv.0`）でも、借りたドライブ内の他人の `Loome` へのアクセス・上書きを拒否し、`library.db` 単体引き抜きを検知します。さらにパスワード設定により、DBサムネイル暗号化（`Lv.1`）や `Loome` 実ファイルのカプセル化保護（`Lv.2`・鍵自動サルベージ対応）へ引き上げられます。
- 未接続時の閲覧とスマートフォン選別：外付けドライブを外していても保存済みサムネイルで閲覧・選別を続けられます。自宅Wi-Fi（QRコード）や外出先のUSB単体HTML（`Tetheract_Mobile.html`）からスマホで選別し、PCへ差分同期できます。

## ダウンロードと起動方法

### 方法A：配布パッケージ（GitHub Releases の ZIP）を使う場合

Python 環境や依存ライブラリは同梱されているため、事前インストールは不要です。

1. 初回導入（フル版 `Tetheract_vX.X.X.zip`）：ZIP を解凍して `Tetheract.exe` を起動します（初回起動時にドライブアイコン・ラベル表示用の `autorun.inf` を設置するか選択できます）。
2. アップデート（軽量差分版 `Tetheract_vX.X.Xdiff.zip`）：
   - v1.8.0 以降の環境（自動クリーン・アップデート）：ダウンロードした `Tetheract_vX.X.Xdiff.zip` を解凍せずにそのまま `Tetheract.exe` と同じフォルダへ置いて `Tetheract.exe` を起動します。古い不要プログラムファイルを自動消去した上で最新版へクリーン更新されます（`cache/` や `Loome/` のデータおよびセキュリティ鍵はそのまま保たれます）。
   - v1.7.2 以前からの更新時：`diff.zip` を解凍して既存フォルダへ上書きコピーし、`Tetheract.exe` を起動してください（起動時にトップ階層の旧スクリプト類も自動整理されます）。

> [!NOTE]
> データベースの互換性と移行について
> - v1.7.0 以降で一度起動した `cache/library.db` にはセキュリティ・エシカル保護スキーマが自動適用されるため、それ以降は v1.6.1 以前の旧バージョンでは開けなくなります（旧版からのアップグレードは自動で引き継がれ、移行前のバックアップも `cache/backups/` に保存されます）。
> - 旧 Photo Manager（v3.x）の実行ファイルや旧スクリプト類は、`Tetheract.exe` 起動時に自動整理されます。

> [!IMPORTANT]
> 初回起動時に「Windows によって PC が保護されました（SmartScreen）」と表示される場合
> コード署名証明書を持たない個人開発ソフトのため、ダウンロード直後に確認画面が出ることがあります。
> 1. そのまま実行する：「詳細情報」→「実行」を選択します（2回目以降は出ません）。
> 2. 手元でビルドする：`tools/Build.bat` を実行すると、Windows 標準の C# コンパイラで平文のソースコード（`tools/Launcher.cs`）から `Tetheract.exe` を生成して起動します。

### 方法B：GitHub リポジトリからクローンして使う場合

初回のみ以下の2ステップを実行してください（PC 本体への Python インストールは不要です）。

1. `setup_portable_python.bat` を実行（要ネット接続）：`python/` フォルダへポータブル Python 環境と依存パッケージが自動構築されます。
2. `Build.bat` を実行：`Tetheract.exe` が生成され、起動します。

## 今後の構想

個人の趣味開発のため実装時期は未定ですが、オフライン・非破壊・軽快な設計のまま以下の機能を構想しています。

- ローカル類似画像検索：お気に入りの1枚から、構図・色合い・雰囲気が似ている写真をAI解析で探す機能。
- フォーカスピーキング：拡大表示や2枚比較時に、ピントが合っている輪郭をハイライト表示する補助機能。
- GPSロガー（`.gpx`）連携：撮影時刻と `.gpx` ログを照合し、GPS非搭載カメラの写真にも位置情報や軌跡を紐付ける機能。
- 外部RAW現像ソフト連携：選別した写真（またはペアRAW）をショートカットキーで外部現像ソフトへ直接渡す機能。
- 余白フレーム・EXIF付き書き出し：写真の周囲にマット枠を設け、機材名や露出設定を控えめに添えて書き出す機能。
