# 📷 Photo Manager

**[ 🇯🇵 日本語 (Japanese) ](README.md) | [ 🇺🇸 English ](README_EN.md)**

**Picasa / Tiat にインスパイアされた、RAW・一般画像向けのローカル高速写真ビューア ＆ 選別（セレクト）ツール**

大量の写真（JPEG / PNG / WebP / HEIC および各社一眼カメラの RAW データ）を、元のフォルダ構造やファイルを1バイトも傷つけずに、待ち時間ゼロで軽快に閲覧・選別・整理できる Windows 向けスタンドアロンアプリケーションです。

## ⚠️ ダウンロード・初回起動時に「SmartScreen 警告」等が出る件について

本ソフトを GitHub Releases 等からダウンロードして初回起動する際に、**「Windows によって PC が保護されました（Microsoft Defender SmartScreen）」** といった青い確認画面やブラウザのダウンロード警告が出ることがあります。

### ❓ なぜ警告が出るのか？（本当にウイルスなの？）
* **ウイルスや不正なプログラムは一切含まれていません**（外部への通信機能すら持たない完全オフライン動作アプリです）。
* ただし、個人の趣味開発であり、年間数万円〜十数万円かかる商用の「コード署名証明書（EV証明書）」を取得していないため、**署名のない自作の `.exe` ファイル（`PhotoManager.exe`：起動用ランチャー）** に対して Windows Defender SmartScreen が「身元不明の実行ファイル」として確認画面を表示します。

### 🛡️ 起動方法と対策（そのまま起動 or `Build.bat` で現地生成）
1. **そのまま起動する場合**:
   * SmartScreen の青い画面が出たら、**「詳細情報」→「実行」** をクリックすればそのまま起動します（2回目以降は表示されません）。
2. **警告を出さずに手元でクリーン生成したい場合（または `.exe` が消された場合）**:
   * フォルダ内の **`Build.bat`** をダブルクリックすると、Windows に最初から標準搭載されている公式コンパイラ（`csc.exe`）を使って、わずか数十行のテキストコード（[`launcher/Launcher.cs`](launcher/Launcher.cs) — メモ帳で中身をすべて確認できます）から **お使いのPC上で直接 `PhotoManager.exe` と `autorun.inf` を1秒で再作成し、そのままアプリを起動**します。
   * 自分のPC内でコンパイルされた `.exe` になるため、ダウンロード由来のブロック（Mark of the Web）が付かずスムーズに起動できます。

## ✨ 主な特徴

1. **🔍 「排他検索（除外フィルタ `[-]`）」にこだわった作り（タグ ＆ カメラ・レンズ階層ツリー）**
   * タグ（アルバム）や「📷 カメラ・レンズ（機種 ＞ 装着レンズ階層）」で絞り込む際、単に「その条件を含む `[+]`」だけでなく、**「その条件を除外する `[-]`（排他検索）」** に徹底してこだわった作りになっています。
   * フォルダや撮影日と組み合わせることで、**「このアルバム（タグ）に含め忘れた画像」** や **「特定のカメラ・レンズ以外の写真」** を簡単に探せます！
2. **🛡️ 完全非破壊（元ファイルは1バイトも変更しません）**
   * アプリ内で写真を回転・トリミング・傾き補正・明るさ調整したり、「棄（ボツ）」の評価を付けても、PC内の元ファイルやフォルダ構造は一切変更・削除されません。
3. **🔒 完全オフライン動作（プライバシー保護）**
   * 写真を外部クラウドへ送信することは一切ありません。AIによる自動タグ付け（ONNX Runtime / CLIP）も、GPS座標からの撮影場所（国・都道府県・市区町村）判定も、すべてローカルPC内だけで完結します。
4. **⚡ 片手でサクサク進む高速セレクト・⚖️ 2枚比較（Duel）・📊 リアルタイムヒストグラム**
   * **4段階評価**: 数字キー（`1`:優 `Ex` / `2`:良 `Gd` / `3`:棄 `Rj` / `0`:可 `Nm`）だけで数万枚の写真を高速仕分け。「棄」にした写真は一覧から即座に隠れます。
   * **連写・露出ブラケット（AEB）・重複写真のスマートスタック**: 連写やブラケット撮影、複数フォルダに散らばった重複写真を自動で束ねて表示。拡大表示（ライトボックス）中は `↑` / `↓` キーでブラケットの明暗（EV+ / EV-）や連写カットをその場で比較できます。
   * **⚖️ 2枚並べて比較（Side-by-Side Duel）＆ 📊 RGB・輝度ヒストグラム**: 2枚の写真を左右に並べて**同期ズーム＆ドラッグ移動**でピントや描写を厳密に比較し、`W` キーで勝ち抜き選別が可能。露出・トーン調整とリアルタイム連動するRGB・輝度ヒストグラム（`H` キー）も搭載。
   * **📤 スマート・テイクアウト ＆ 🎞️ ベタ焼きHTML（コンタクトシート）出力**: 選んだベストショットを非破壊調整の焼き込み＋用途別リサイズ＋連番リネーム＋Exif消去で一括出力したり、暗室ネガシート風の単一HTML（赤鉛筆の「⭕」チェック＆A4印刷対応）として書き出せます。
5. **🧪 ラボ（実験室）＆ 🗾 47都道府県制覇マップ・さんぽ軌跡**
   * **🏆 勝ちレンズ・得意設定カルテ**: 過去の評価データから高歩留まりな「勝ちレンズランキング」や得意な焦点距離・F値・撮影時間帯を自動診断。
   * **🌅 太陽高度抽出 ＆ ⚠️ 手ブレ危険度（Lens Shaker）**: 撮影日時とGPSから太陽高度を計算してマジックアワー・ブルーアワー・夜景を抽出し、`1/焦点距離 秒` より遅い手ブレ注意カットもワンクリック検出。
   * **🗾 47都道府県制覇白地図・ヒートマップ・👣 撮影さんぽ軌跡**: 撮影した都道府県の制覇マップ、よく行く撮影地のヒートマップ、日付ごとの徒歩ルート軌跡を可視化。
   * **🎂 歴代の今日 ＆ 🎲 未整理フォルダ発掘ガチャ**: 過去の同じ月日に撮った写真の振り返りや、未整理フォルダをランダムに引き当てるガチャ機能を搭載。
6. **📜 和紙／🌙 夜墨（Washi / Urusi）テーマ ＆ 🇯🇵 JP ／ 🇺🇸 EN リアルタイム英語UI切替**
   * 明るい「📜 和紙（Washi）」と暗室風の「🌙 夜墨（Urusi）」テーマ切替に加え、ワンクリックでアプリ全体＆ヘルプマニュアルを日本語・英語（`Ex / Gd / Nm / Rj`, `Lens Shaker`, `Betayaki`, `Gacha` 等）にリアルタイム切り替え可能。
7. **🔌 USBメモリ持ち歩き ＆ 📱 スマホ（Android）ハイブリッド選別**
   * **USBポータブル自走**: Python が入っていない別PCでも、USBメモリや外付けSSDからそのまま起動。ドライブレター（`D:` → `E:` 等）が変わっても自動追跡します。
   * **スマホでのオフライン選別（`PhotoManager_Mobile.html`）**: SQLite データベース（`cache/library.db`）内に高画質 WebP サムネイルを完全内蔵。WebAssembly（`sql.js`）により、数百GBの元写真が無くても `.db` ファイル1つをスマホのメモリへ約1秒で読み込み、**USBメモリを抜いてベッドや移動中に親指ワンタップで選別 → 後からPCへ差分同期**できます（同一Wi-Fiでのリアルタイム直結 `/m` にも対応）。

## 🚀 セットアップと起動方法

### パターンA：配布パッケージ（GitHub Releases の ZIP / `python/` 同梱版）を使う場合
1. ZIP を任意のフォルダ（または USB メモリ）に解凍し、**`PhotoManager.exe`** をダブルクリックして起動します（黒いコマンド画面を出さずに専用ウィンドウが最大サイズで開きます）。
   * ※ もし初回起動時に SmartScreen の警告が出た場合は「詳細情報」→「実行」を選ぶか、同フォルダ内の **`Build.bat`** を1回ダブルクリックすると手元で `PhotoManager.exe` が再生成されて起動します。

### パターンB：GitHub からクローン／ダウンロードして使う場合
GitHub のリポジトリには、容量の大きいポータブル Python 本体（`python/`）を含めていません。初回のみ以下の2ステップを実行してください（PC本体への Python インストールは不要です）。

1. **`setup_portable_python.bat` をダブルクリック**（要インターネット接続・初回のみ）
   * Python 公式サイトから Embeddable Python 3.11 と必要ライブラリ（FastAPI, Pillow, rawpy, ONNX Runtime 等）が `python/` フォルダへ自動でダウンロード・構築されます。
2. **`Build.bat` をダブルクリック**
   * `PhotoManager.exe` がビルドされ、アプリが起動します。
