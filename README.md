# Photo Manager

日本語 | [English](README_EN.md)

Picasa や Tiat に着想を得た、Windows 向けのローカル写真ビューア・選別（セレクト）ツールです。  
JPEG / PNG / WebP / HEIC や各社カメラの RAW データを、元のファイルやフォルダ構造を1バイトも変更することなく、軽快に閲覧・比較・整理できます。

すぐに試す場合は、[GitHub Releases](../../releases) から最新版 ZIP をダウンロードし、解凍して `PhotoManager.exe` を起動してください（インストール不要）。

## 特徴

### 1. タグの「打ち漏れ」がすぐ分かる排他検索（除外フィルタ）と道標表示
Picasa や Tiat のような軽快なタグ検索をベースに、実用上もっとも欲しかった「除外（マイナス）検索」を強化しています。  
タグ（階層化アルバム）や「カメラボディ ＞ レンズ」のツリーで絞り込む際、条件を含む `[+]` だけでなく、特定の条件を除外する `[-]` をワンクリックで指定できます。たとえば「イベントの写真は表示する `[+]`」と同時に「特定のタグが付いたものは隠す `[-]`」と組み合わせることで、「タグを付け忘れている（打ち漏らしている）写真」や「特定のレンズ以外で撮った写真」を簡単にあぶり出せます。  
親階層を閉じていても子項目でフィルタが有効な場合は破線枠と件数バッジ（`+1` / `-1`）の道標が表示され、上部フィルタチップをクリックすると該当するツリー項目へ直接ジャンプできます。また、普段のタグ付けは右インスペクタや右クリックメニューで行い、タグの階層整理やリネームは「設定」内の専用エディタに分離することで、選別中の誤操作を防いでいます。

### 2. Foveon（X3F）や各社の最新 RAW をそのまま高速表示
JPEG / PNG / WebP / HEIC に加え、SIGMA の Foveon（X3F）や Panasonic（RW2）、Canon（CR2 / CR3）、Nikon（NEF）、Sony（ARW）、Olympus（ORF）、Fujifilm（RAF）、Pentax（PEF）、DNG などの RAW データをそのまま閲覧できます。  
RAW 現像処理を行わず、ファイル内部の埋め込み JPEG プレビューを優先して読み出す仕組み（非対応形式のみ LibRaw へフォールバック）のため、メーカー固有の色味を崩さずに待ち時間なしで表示できます。カメラとレンズの階層ツリーも自動で構築されるため、ボディやレンズごとの絞り込みもすぐに行えます。

### 3. 写真フォルダを汚さない非破壊設計と XMP サイドカー連携
写真の回転、傾き補正、トリミング、トーン調整、撮影日時のズレ補正、および「棄（ボツ）」の評価を行っても、ディスク上の元ファイルは変更・削除されません。写真が入っているフォルダの中に管理用の隠しファイルやサイドカーファイルを生成することもありません。  
なお、Lightroom や Adobe Camera Raw などの現像ソフトが既に出力したサイドカーファイル（`.xmp` / `.pp3` / `.dop`）が同じフォルダにある場合は、それを書き換えずに読み取り、右インスペクタの「XMPプレビュー」ボタンを押している間だけ現像パラメータを反映して見比べることができます。サイドカー内の評価や階層タグを、既存のタグと混ざらない `XMP/...` 階層へ安全に取り込むことも可能です。

### 4. Tiat に着想を得た、写真が主役になる静かな画面設計
色付きの絵文字や強い枠線などの視覚的ノイズを抑え、写真の色彩と階調が素直に映えるインターフェースを採用しています。
- 明るい「和紙」テーマと、暗室のように落ち着いた「夜墨」テーマをいつでも切り替えられます。
- アスペクト比を保って並べる「びっしり表示」や、ポジフィルムの枠のように余白をとって眺める「マウント表示」を選べます。
- 左側のメニュー（フォルダ、タグ、ジオタグ、年月、機材、ラボなど）は、折りたたんで写真一覧を広く使うことも、必要なときだけオーバーレイで開くこともできます。
- 右側のインスペクタには、見切れのない 4:3 プレビュー（ダブルクリックで拡大表示）と、撮影日時・解像度・カメラ・レンズ・露出設定がひと目で分かるクイック EXIF を常時表示します。

### 5. ローカル完結の動作と USB ポータブル運用
写真データを外部のクラウドやサーバーへ送信することは一切ありません。Web フォントや地図ライブラリ（Leaflet）もローカル同梱しており、外部 CDN 通信は行いません（地図の背景タイルを表示するときのみ OpenStreetMap に接続します）。AI による自動タグ付け（CLIP）や、GPS 座標からの撮影地（国・都道府県・市区町村）の判定も、すべて手元の PC 内で完結します。  
Python が入っていない PC でも、外付け SSD や USB メモリからそのまま起動できます。また、必要な写真をアプリ内の `storage/` フォルダへコピーして取り込めば、付随する RAW ファイルや `.xmp` サイドカーを自動追従させながら、サブフォルダ整理や連番リネーム（<kbd>F2</kbd>）を行えます。

## ダウンロードと起動方法

### 方法A：配布パッケージ（GitHub Releases の ZIP）を使う場合

Python 実行環境や必要なライブラリがすべて同梱されているため、PC への事前インストール作業は不要です。

1. 初回導入（フルパッケージ版 `PhotoManager_vX.X.X.zip`）：  
   [GitHub Releases](../../releases) からフルパッケージ版 ZIP をダウンロードして任意のフォルダ（または USB メモリ）に解凍し、`PhotoManager.exe` をダブルクリックすると専用ウィンドウで起動します。
2. 既存環境のアップデート（軽量差分版 `PhotoManager_vX.X.Xdiff.zip`）：  
   すでにフルパッケージ版をお使いの場合は、`python/` や `models/` の再ダウンロードは不要です。軽量な差分版 ZIP を解凍して既存フォルダへ上書きコピーするだけで、これまでのデータベース（`cache/`）や `storage/` を保ったまま更新できます。

> [!IMPORTANT]
> 初回起動時に「Windows によって PC が保護されました（SmartScreen）」と表示される場合
>
> 本ソフトは写真の外部送信やレジストリ変更を行わないローカルアプリケーション（地図タイル表示時のみ外部接続）ですが、有償のコード署名証明書を取得していない個人開発ソフトであるため、ダウンロード直後の `PhotoManager.exe` に対して Windows Defender SmartScreen の確認画面が出ることがあります。以下のいずれかの方法で起動できます。
>
> 1. そのまま実行する：確認画面の「詳細情報」をクリックし、「実行」を選択します（2回目以降は表示されません）。
> 2. `Build.bat` で手元で生成する：フォルダ内の `Build.bat` をダブルクリックすると、Windows 標準搭載の C# コンパイラ（`csc.exe`）を使って、平文のソースコード（[`launcher/Launcher.cs`](launcher/Launcher.cs)）から手元の PC 上で `PhotoManager.exe` を生成して起動します。自分の PC 内で作られたファイルになるため、ダウンロード由来のブロックが付かずスムーズに起動できます。

### 方法B：GitHub リポジトリからクローンして使う場合

Git リポジトリには大容量のポータブル Python 本体（`python/`）を含めていません。初回のみ以下の2ステップを実行してください（PC 本体への Python インストールは不要です）。

1. `setup_portable_python.bat` を実行（要インターネット接続・初回のみ）：  
   Python 公式サイトから Embeddable Python 3.11 と依存ライブラリが `python/` フォルダへ自動でダウンロード・構築されます。
2. `Build.bat` を実行：  
   `PhotoManager.exe` が生成され、アプリケーションが起動します。

## 今後の構想

個人の趣味によるバイブコーディング開発のため、実装時期や実現のお約束はできませんが、「完全オフライン・非破壊・軽快な動作」という基本設計を守りながら、将来的に以下のような機能を構想しています。

- 似た構図・雰囲気の写真を探す（ローカル類似画像検索）：  
  手元の PC 内の AI 画像解析を利用して、お気に入りの1枚を選ぶと、これまでに撮りためた写真の中から「構図・色合い・光の雰囲気」が似ているカットをタグ付けなしでも探し出せる機能。
- ピント面のハイライト表示（フォーカスピーキング）：  
  拡大表示や2枚比較（Duel）モードで、カメラのピーキング機能のようにピントが合っている輪郭を色付きで浮かび上がらせ、連写した中から一番シャープな1枚を選びやすくする補助機能。
- GPS ロガー（`.gpx`）からの位置情報・移動軌跡の紐付け：  
  登山や街歩きの GPS ログ（`.gpx` ファイル）と撮影時刻を照らし合わせ、GPS を内蔵していないカメラで撮った写真でも、元ファイルを書き換えずに撮影場所や歩いた軌跡を地図上で楽しめる機能。
- 外部 RAW 現像ソフトへのダイレクト受け渡し：  
  選別して残した写真（またはペアの RAW ファイル）を、ショートカットキーひとつで普段使っている外部の RAW 現像ソフトへそのまま引き渡す連携機能。
- 余白フレーム・撮影データ付き書き出し：  
  スマート・テイクアウトの出力オプションとして、写真のまわりに静かな余白（マット枠）を設け、カメラ・レンズ名や露出設定を控えめに添えて書き出す機能。
