# 実装計画: タスクトレイ常駐化＆任意シャットダウン

## 1. 概要
`pythonw.exe` バックグラウンド起動時に発生していた「サーバーのゾンビ化」「他USB挿入時のポート競合」「F5リロード時のハングアップ」を解決するため、不安定なハートビート自動終了を廃止し、**Windowsタスクトレイ（通知領域）常駐アイコンによる可視化＆任意シャットダウン方式** へ刷新する。

## 2. 変更対象ファイル
1. **新規作成**: `server/tray.py`
   - `pystray` + `Pillow` によるタスクトレイアイコン管理クラス。
   - `frontend/favicon.ico` をトレイアイコンとして読み込み表示。
   - クリック/ダブルクリックでアプリウィンドウ（Edge/Chromeまたは既定ブラウザ）を前面起動。
   - 右クリックメニュー:
     - 📷 **Photo Manager を開く** (デフォルト動作)
     - 🌐 **ブラウザで開く**
     - ──────
     - 🛑 **サーバーを終了 (シャットダウン)** (プロセス完全停止)
2. **修正**: `run.py`
   - Uvicornサーバーを `uvicorn.Server` インスタンスとしてプログラム制御可能にし、別スレッドまたは制御ループで稼働。
   - トレイアイコンからの終了シグナルを受け取った際、`server.should_exit = True` を発行し、トレイアイコンを削除した上で正常終了する。
3. **修正**: `server/app.py` & `server/heartbeat.py`
   - 不安定だった自動終了（ブラウザ全閉じ検知タイマー）を停止。
   - 既存フロントエンドからの `/api/heartbeat` リクエストはダミー200 OKとして吸収。
4. **修正**: `setup_portable_python.py`
   - 新規PCやUSB再構築時に `pystray`, `six` が自動インストールされるよう依存リストに追加。

## 3. 実装手順
1. `server/tray.py` を実装し、単体起動・メニュー動作をテスト。
2. `run.py` で Uvicorn サーバーと `TrayManager` を統合。
3. ハートビート監視タイマーの無効化。
4. `setup_portable_python.py` に `pystray`, `six` を追加。
5. 起動、トレイアイコン表示、ブラウザ起動、メニューからの終了を総合テスト。
