# 実装計画: スキャン進捗バーのフッター（ステータスバー）化

## 1. 目的と課題
- **背景**:
  - フォルダを管理に追加したりスキャンを行う際、プログレスバーがヘッダー直下（ヘッダーとギャラリー・サイドバーの間）に出現していた。
  - 出現・消滅時にギャラリー全体が上下に押し下げられるレイアウトシフト（ガタつき）が発生し、閲覧中の視線やスクロールが乱れる原因となっていた。
- **改修方針**:
  - スキャン進捗バーをヘッダー直下から画面最下部（フッター）へ移動。
  - プロ用アプリのステータスバー風の横1行スリムデザイン（高さ32px）にリデザイン。
  - ギャラリーの高さ領域に一切影響を与えない安定した構造とし、スキャン開始・終了時も画面がガタつかないようにする。
  - 写真選択時に最下部中央に表示されるフローティング選択バー（`.selection-floating-bar`）との重なりを防ぐため、スキャン中は `bottom: 44px` へ自動退避する連動スタイルを導入。
  - バージョン番号はユーザー指定に従い **`2.00`** のまま維持。

## 2. 変更対象ファイル
1. `frontend/index.html`: `#globalScanBanner` をヘッダー直下から `.main-body` 直後・`.app-layout` 最下部へ移動。要素を `<footer>` 化。
2. `frontend/css/style.css`:
   - `.global-scan-banner`, `.global-scan-footer`: 最下部固定ステータスバー（高さ32px、横1行、上部ボーダー、シャドウ、スライドインアニメーション）
   - `.global-scan-track`: 右側に幅240pxで配置
   - `body.has-scan-banner .selection-floating-bar`: スキャン実行時の `bottom: 44px` オフセット
3. `frontend/js/folder_tree.js`:
   - `_ftRenderScanProgress`: スキャン実行中に `body.classList.add('has-scan-banner')`、終了時に `remove`。表示スタイルを `flex` に。
4. `MANUAL.md`: 操作マニュアル内のスキャン進捗表示位置の説明を最下部ステータスバーに更新。

## 3. 検証計画
- ブラウザ上でスキャンプログレスバーを表示させ、画面最下部にスリムな横1行バーとして表示されることを確認。
- 写真を選択した際に、フローティング選択バーがスキャンステータスバーの直上に被らず浮き上がることを確認。
- スキャン停止時にバーが非表示になり、フローティング選択バーが通常の高さ（`bottom: 24px`）に戻ることを確認。
