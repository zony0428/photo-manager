# 修正内容の確認 (Walkthrough): スキャン進捗バーのフッター（ステータスバー）化

## 概要
フォルダスキャン実行時の進捗バー表示位置を、従来のヘッダー直下から**画面最下部のステータスバー（フッター）**へ移行しました。
これにより、スキャンの開始・終了時にギャラリー表示領域が上下に揺れるレイアウトシフト（ガタつき）が完全に解消され、写真閲覧の快適性が大幅に向上しました。

---

## 変更内容

### 1. HTML構造の移行 (`frontend/index.html`)
- `#globalScanBanner` をヘッダー直下から `.main-body` の閉じタグ直後、`.app-layout` の最下端へ移動。
- セマンティックな `<footer>` 要素（クラス: `global-scan-banner global-scan-footer`）として再構築。

### 2. 横1行スリムステータスバーデザイン (`frontend/css/style.css`)
- **高さ32pxのスリムレイアウト**:
  - 左側: アイコン、スキャン状態テキスト、処理件数（`xx / xx`）、処理中ファイル名
  - 右側: 幅240px（`max-width: 32vw`）のコンパクトプログレスバー
- **下からの滑らかなスライドイン**:
  - `animation: slideUpFooter 0.25s cubic-bezier(0.16, 1, 0.3, 1)` で上品に出現。
- **フローティング選択バーとの協調動作**:
  - 写真選択時の `.selection-floating-bar`（通常 `bottom: 24px`）が、スキャン中（`body.has-scan-banner`）は自動的に `bottom: 44px` へ引き上げられ、フッターと重なることなく直上に浮き上がる設計。

### 3. JavaScript制御の拡張 (`frontend/js/folder_tree.js`)
- `_ftRenderScanProgress(status)` において、スキャン進行中に `document.body.classList.add('has-scan-banner')`、終了時に `document.body.classList.remove('has-scan-banner')` を付与。
- 表示スタイルを横並びの `display = 'flex'` で制御。

### 4. 操作マニュアルの同期 (`MANUAL.md`)
- 「画面上部に進捗バー」の記述を「画面最下部にスマートな進捗ステータスバーが常時表示され、ギャラリーを邪魔することなく...」に改訂。

---

## 実機ブラウザ検証結果

1. **スキャンフッターの最下部表示**:
   - 画面最下部に高さ32pxの洗練された1行ステータスバーとして出現。
   - ギャラリーの高さやスクロール位置には一切影響を与えず、上下の揺れ（レイアウトシフト）がゼロであることを確認。
2. **フローティング選択バーの重なり回避**:
   - 写真カードを選択した際、選択操作バーがスキャンフッターの直上（`bottom: 44px`）に綺麗にオフセットされて表示され、クリック・操作が完全に阻害されないことを確認。
3. **スキャン完了後の自動非表示**:
   - スキャン完了・停止時にフッターが速やかに閉じ、フローティングバーも通常の底面位置（`bottom: 24px`）へ滑らかに復帰することを確認。
