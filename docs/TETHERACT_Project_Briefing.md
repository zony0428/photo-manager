## 1. プロダクト基本情報 & ブランドアイデンティティ

### 1.1 基本スペック
- **正式名称**: Tetheract Photo Manager（略称・ロゴ表記: `TETHERACT pm`、旧称: Photo Manager ※v1.0.0で改称）
- **対象バージョン**: `v1.8.9`（v1系最新安定版 / 2026年11月）
- **ジャンル**: Windows向け ローカル高速写真ビューア・選別（セレクト）・非破壊管理ツール
- **ライセンス・価格**: 完全無料・オープンソース（MIT License / 同梱OSSライセンス準拠）
- **対応環境**: Windows 10 / 11（64-bit）＋ Microsoft Edge または Google Chrome
  - ポータブルPython環境および必要なランタイムDLL（VC++ / OpenMP等）をすべて同梱しているため、クリーンなWindows PCやUSBメモリからでも**インストール作業・事前環境構築ゼロ**で `Tetheract.exe` をダブルクリックするだけで起動します。
- **着想元**: かつての「Picasa」の軽快な一覧性・直感性と、「Tiat」のストイックで写真を邪魔しないUI設計にインスパイアされて開発。
- **対応フォーマット**:
  - **一般画像**: `JPEG`, `PNG`, `WebP`, `HEIC` / `HEIF`, `AVIF`, `TIFF`, `BMP`, `GIF`
  - **各社カメラRAW**: SIGMA Foveon（`.X3F`）、Sony α（`.ARW` / `.SR2` / `.SRF` / `.ARQ` ※最新ボディやロスレス圧縮 M/S も完全対応）、Canon（`.CR2` / `.CR3` / `.CRW`）、Nikon（`.NEF` / `.NRW`）、Fujifilm（`.RAF`）、Panasonic（`.RW2`）、Olympus / OM System（`.ORF`）、Pentax（`.PEF`）、Adobe / Leica 等（`.DNG`）、Samsung（`.SRW`）

### 1.2 名称「TETHERACT（テザラクト）」の由来と世界観
映画『インターステラー』に登場する、時間や空間を超えて記憶の断片（本棚）へアクセスする4次元超立方体 **「テサラクト（Tesseract）」** に着想を得て、以下の言葉を掛け合わせた造語です。
- **Tether（繋ぎ止める糸・綱）**: PC内蔵ドライブ、外付けSSD、複数のSDカードなど、時間や場所を超えて散らばっていく写真の記憶を1つに繋ぎ止める。
- **Tesseract（超立方体）**: 保存場所という物理的な次元に縛られず、タグ・時間・場所・機材・色という多元の切り口から瞬時に写真へアクセスする空間。
- **Act（行為・振る舞い）**: ただ眺めるだけでなく、選び抜き、整え、作品や記録として次へ繋げる行為。

### 1.3 ビジュアル・デザイン言語（Stoic Darkroom & Gallery Light）
- **白銀比の超立方体アイコンとW-Z回転アニメーション**:
  白銀比（シルバーレシオ）を取り入れた4次元超立方体アイコンを採用。外周のシャンパンブロンズ枠から中心の純白コア枠へ向かって4本の遠近テザーラインが収束し、カメラレンズのマルチコート反射や暗室の光を思わせる急減衰ブルーム発光を備えています。起動スプラッシュやバックグラウンド処理中には、4本の斜めレールに沿って内側の四角が外枠へ拡大し、奥のコアから次の四角が湧き上がる「超立方体のW-Z回転（1点透視投影）」が滑らかに描画されます。
- **写真が主役になる静かなワークスペース**:
  画面上からカラフルなOS標準絵文字や主張の強い太枠、ブラウザ標準の無機質なアラート類を一切排除し、単色細線SVGアイコンと半透明すりガラスバッジ、統一デザインのカスタムモーダルで統一しています。
- **視線移動を抑えた下部（フッター）統合ツールバーと左端アクティビティレール**:
  選別中の視線移動を最小限に抑えるため、メインツールバーを既定で画面下部のフッター位置に1行でコンパクトに配置しています（設定から「下部（フッター）」⇔「上部（ヘッダー）」をいつでも切替可能。FHD〜QHD環境でも窮屈にならず、各ドロップダウンには選択中の条件全文を示す動的ツールチップが働きます）。
  左端の垂直タブレールは、役割ごとに整理された8つのセクション（`Folder` → セパレータ → `Binder`（初期選択） → `Tag`・`Historia`・`Place`・`Gear` → 下部 `Lab`・`Search`）で構成されています。
- **4つのカラーテーマと日英リアルタイム切替**:
  - `Tetheract D`（既定ダーク：ウォームモノトーン × シャンパンブロンズ）
  - `Tetheract L`（ライト：白飛びしないアンバー＆ソフトモノトーン）
  - `夜墨 (Sumi)` / `和紙 (Paper)`（日本の伝統色ベースの銀墨ダーク／生成りライト）
  - `JP` / `EN` ボタンで画面表示・ダイアログ・ヘルプをワンクリックで日英切り替え可能。

### 1.4 開発スタンス（個人開発 × 100% AI バイブコーディング）
- 開発者自身が自分のカメラ・写真ライフで本当に欲しかった道具を形にした個人開発プロジェクトであり、コードは100% AIとの対話（バイブコーディング）によって構築されています。

## 2. どんな人に刺さるのか？（想定読者像と解決する悩み）

紹介文を組み立てる際は、以下のようなカメラ・写真ユーザーのリアルな悩みに寄り添うと共感を得やすくなります。

1. **大量の連写・RAWデータの選別（セレクト）に時間を奪われている人**:
   - 休日の撮影から帰ってきて数千枚のRAW+JPEGや連写コマを前にしたとき、現像ソフトの重いカタログ読み込みやプレビュー生成待ちで億劫になっている人。メーカー純正の色味のまま待ち時間ゼロで開き、片手の数字キーと2枚比較だけでテンポよくベストカットを絞り込みたい人。
2. **自分のフォルダ構造や元データを1バイトたりともソフトに弄られたくない人**:
   - 専用ライブラリへの強制インポートや、写真フォルダ内に大量の `.xmp` や管理用隠しファイルが勝手に生成されることを嫌う人。「合わなければアプリのフォルダを捨てるだけで100%元の環境に戻る」清潔さと安心感を求める人。
3. **複数の外付けSSDや何枚ものSDカードに写真が分散している人**:
   - 年々増える外付けドライブを横断して「あのレンズで秋に撮った写真」を探したい人。ドライブを外しているときも手元のPCで過去写真を眺めたり、複数のSDカードを差し替えながら整理したい人。
4. **クラウド預けっぱなしやサブスクを避け、ローカル＆ポータブルに完結させたい人**:
   - 写真を外部サーバーへ一切送信せず手元だけでAI分類や地図振り返りを楽しみたい人。外付けSSDやUSBメモリにアプリごと入れて、自宅デスクトップと外出先ノートPCでまったく同じ環境を持ち歩きたい人。

## 3. 普通の写真管理ソフトと何が違うのか？（6つの差別化ポイント）

一般的なクラウド写真サービス、重量級の現像カタログソフト、あるいは単純なフォルダビューアと比較した際、TETHERACT には以下の明確な違いがあります。

### ① 「完全非破壊・元フォルダ汚染ゼロ」の徹底
- 写真を専用フォルダへ強制インポートさせず、既存のフォルダ構造のまま扱えます。
- 回転、傾き補正、トリミング、トーン調整、日時補正、タグ付け、「棄（ボツ）」の評価を行っても、**元の写真ファイルには1バイトも触れず、写真フォルダの中に管理用の隠しファイルや独自サイドカーファイルを作ることも一切ありません**。
- すべての記録はアプリフォルダ内の `cache/library.db` 1箇所にのみ保存されます。

### ② 「元フォルダは汚さない」と「実ファイルを整理したい」を両立する専用保管庫『Loome（ルーム）』
- 通常のフォルダは100%非破壊で守りつつ、「選び抜いたお気に入りの写真だけは、実ファイルごと集めてサブフォルダ分けしたり、連番リネームして持ち歩きたい」という場面のために、アプリが管理する独立した整理特区 **『Loome（ルーム）』** を備えています。
- **『Loome』という部屋に入れた写真だけは、アプリ上からカスケードメニューやドラッグ＆ドロップでサブフォルダ移動したり、<kbd>F2</kbd> キーで撮影順の一括連番リネームができる**という明確な境界線（サンドボックス思想）を持っています。アプリ内の `Loome/` だけでなく、外付けSSDやUSBメモリ直下にも `<ドライブ>:\Loome` を増設して複数ドライブ横断で運用できます。

### ③ 物理ドライブや複数SDカードの壁を超える「VSN個体識別 × 所在リンク分離DB × 抜き挿し即時検知」
- Windowsのドライブ文字（`D:` や `E:`）ではなく、メディア固有の **ボリュームシリアル番号（VSN）** でドライブやSDカードを個体識別します。別PCに繋いでドライブ文字が変わっても自動追従し、同じカードリーダーに複数のSDカードを差し替えても別々のカードとして独立管理できます。
- Windowsネイティブのハードウェア変更通知（`WM_DEVICECHANGE`）により、SDカードや外付けSSDを抜き挿しすると再読込操作なしで即座にフォルダツリーや接続表示が切り替わります。
- データベース内部で「ユニークな写真そのもの（`photos`）」と「どのメディアのどのパスに実ファイルがあるか（`photo_links`）」を分離しているため、**SDカード・PC内蔵SSD・外付けバックアップHDDの複数箇所に同じ写真があっても、一覧上は重複せず1枚として扱われます**（SNS保存画像などExif撮影日時を持たない画像も、ファイル中間のサンプリングハッシュにより別フォルダへコピーしても分裂せず同一画像として認識します）。
- SDカード上で付けた評価・タグ・非破壊調整は、後からPCや `Loome` へ写真を移動・コピーした際にも自動で引き継がれます。また、取り込み元のSDカードを外していても、接続中の `Loome` 等に別リンクがあれば自動でそちらの実ファイルから高画質表示を行い、完全にオフラインの写真もDB内のWebPサムネイルで閲覧・選別を続けられます。

### ④ インストール不要・USB単体で自走し、クリーン更新やスマホでのオフライン選別まで完結
- Python実行環境、ランタイムDLL、ローカルAIモデル、SQLiteデータベースが1つのフォルダに収まっており、フォルダごとポータブルSSDやUSBメモリに入れればどのPCでもそのまま起動します（1GB超の大規模DBでも瞬時に起動します）。
- 外部通信ゼロでありながら、新しい軽量差分パッケージ（`Tetheract_v*diff.zip`）を解凍せずにアプリフォルダへ置いて `Tetheract.exe` を起動するだけで、古い不要プログラムを一掃して最新版へ入れ替える **ローカル完結クリーン・アップデーター** を搭載しています。
- 外出先でPCがない環境でも、USBメモリをスマートフォンに挿して単一HTMLファイル（`Tetheract_Mobile.html`）を開けば、ブラウザ上のWebAssembly版SQLite（`sql.js`）が `library.db` を直接読み込み、スマホの親指操作で選別やタグ付けを行って後からPCへ差分同期できます（自宅Wi-FiでのQRコード接続モードも搭載）。

### ⑤ ポータブル運用の礼節と安全を守る「3段階セキュリティ ＆ エシカル保護（Lv.0 / Lv.1 / Lv.2）」
- USBメモリや外付けSSDを持ち歩いたり貸し借りする運用だからこそ、「他人のプライベートな保管庫を勝手に覗き見しない」「自分のデータベースや保管庫も無断で抜き取らせない」という倫理的（エシカル）な保護機構を備えています。
- パスワード不要で常時働く **Lv.0（エシカルモード）** では、友人や同僚から借りた外付けドライブ内に相手の `Loome` が存在する場合に閲覧・管理登録・上書きをシステムレベルで拒否し、相手のメディアに1バイトも書き込みません。また、`cache/library.db` だけが単体で引き抜かれて別環境に差し込まれた場合もオンメモリで安全にロックして無断閲覧を防ぎます。
- パスワードを設定すれば、起動ロックとDB内全サムネイルの認証付き暗号化を行う **Lv.1（起動＆DBロック）**、および `Loome` 内の画像・RAWファイル自体をカプセル化してエクスプローラー等からの直接閲覧も遮断する **Lv.2（フルロック）** へ引き上げられます。万一 `library.db` を誤削除しても `Loome` 側の電子刻印から暗号鍵を自動サルベージする自己修復設計により、鍵紛失によるデータロスト（セルフブリック）も防ぎます。

### ⑥ 各社RAW（Foveon X3F・SONYロスレスARW含む）の即時表示・原本1:1高精細拡大と、数ミリ秒の高速フィルタ
- 重いRAW現像処理をその場で回すのではなく、RAWファイル内部のカメラ現像済みプレビューJPEGを直接高速抽出（TIFF IFD直接解析およびLibRawフォールバック）するため、SIGMA Foveon（`X3F`）や他ソフトで詰まりやすいSONY αのロスレス圧縮RAW（`ARW`）も、メーカー純正の色味のまま待ち時間なくフルサイズ表示します。
- 拡大表示（ライトボックス）や2枚比較では、縮小キャンバスの引き伸ばし（モザイク化）を行わず、常に原本フル解像度の実ピクセル寸法（1:1等倍＝`100%` 基準）から直接描画するため、ピントの山を精細に確認できます。
- ツールバー中央の3大基本フィルタや左サイドバーの「包含 `[+]`・除外 `[-]`」論理検索は、カバリングインデックスとDB世代連動キャッシュにより数万枚規模のライブラリでも数ミリ秒で切り替わります。

## 5. 主要機能ディープダイブ（v1.8.9 最新仕様）

### 5.1 専用整理・持ち歩き特区『Loome（ルーム）』
「元の写真フォルダには一切手を出さない」という原則を守りながら、選び抜いた写真だけをコピーして持ち歩き、実ファイルのサブフォルダ整理やファイル名変更を自由に行えるTETHERACT専用の隔離保管庫です。

- **『Loome』のネーミングに込められたトリプルミーニング**:
  1. **`Loom`（織機・織りなす場所）**: `Tetheract` の `Tether`（記憶を繋ぐ糸）を手繰り寄せて、1つのコレクションに織り上げる場所。
  2. **`Lume`（光 / Lumen）**: 写真の本質である「光」を宿し、収めておく場所。
  3. **`Room`（部屋 / 暗室）**: 日本語の発音は誰もが直感的に理解できる **「ルーム」**。外の世界（既存の撮影フォルダ）から守られた「自分だけの整理部屋」であり、この部屋の中だけは自由に模様替え（フォルダ移動・リネーム）ができることを意味します。
  - *(開発秘話・裏のウィット)*: 日本人がカタカナ英語で「ルーム（Room）」と発音するとネイティブには `Loom` に聞こえるという自虐的なユーモアから生まれた造語でもあります。また、`Home` や `Dome` と同じ「`o` を中心に `me` で閉じる綴り」により、大切な写真を包み込む空間の温度感を持たせています。
- **主な機能と外部メディアへの展開**:
  - アプリ本体内の標準 `Loome/` だけでなく、接続中の外付けSSDやUSBメモリ直下にも、右クリックメニューや「登録メディア管理」から専用の `<ドライブ>:\Loome` を作成・登録し、複数ドライブにまたがるポータブル保管庫として左サイドバー `Folder` からシームレスに扱えます。
  - **NeXTSTEP風の右展開カスケード階層メニューと高速並列コピー**: 写真の右クリックメニュー「`Loomeへコピー ▶`」「`Loome内で移動 ▶`」から保存先ドライブにカーソルを乗せると、0.3秒の絶妙なホバーディレイとソフトフェードインを伴って右隣へサブフォルダ階層・孫フォルダ階層が滑らかにカスケード展開され、その場での新規サブフォルダ作成＆即時コピー／移動も行えます。転送には Windows カーネル API `CopyFileExW` とドライブ種別（NVMe/SSDは並列、SDカードやHDDはシーク劣化を防ぐ直列）に応じた自動並列化を用い、登録済み写真は重いEXIF再解析をスキップして既存メタデータを引き継ぐため、大量の写真も高速に取り込めます。
  - 外部フォルダから `Loome` へ写真を取り込む際、評価・タグ・非破壊調整が引き継がれるだけでなく、**同名の `.xmp` / `.pp3` / `.dop` 等のサイドカーファイルやペアのRAWファイルも自動で追従**します。
  - `Loome` 内では、サブフォルダの作成・リネーム・空フォルダ削除、ドラッグ＆ドロップでの写真移動、<kbd>F2</kbd> キーによる単一リネームおよび**ミリ秒精度の撮影日時順・一括連番リネーム**（`撮影日時＋3桁連番`、`撮影日時＋元ファイル名`、`自由な接頭辞＋3桁連番`）、外部フォルダへの丸ごとエクスポートがエクスプローラーを開かずに完結します。

### 5.2 3段階セキュリティ ＆ エシカル保護とバックアップ・自己修復設計
ポータブル運用時のプライバシー保護と倫理的配慮、さらにメディア故障への備えを統合しています。

1. **Lv.0：エシカルモード（標準保護・パスワード不要・常時有効）**:
   - **他人の `Loome` が存在するドライブの完全拒否**: 借りた外付けSSD/USBメモリ内に相手の `Loome` フォルダが存在する場合、電子刻印（`.loome_seal` の HMAC 署名）または非空フォルダ検知によって「他環境の `Loome`（保護中）」と判定し、閲覧・ドライブ管理登録・上書き作成をシステムレベルで拒否します（別PCで作成した自分の外付け `Loome` は、同一パスワードまたはリカバリーコードで承認・統合可能）。
   - **`library.db` 単体引き抜き検知ロック ＆ 本体故障時の3つの救済手段**: `cache/library.db` だけが単体で引き抜かれて別環境に差し込まれた場合、パスワード未設定でも本体個体鍵（`.tetheract_instance`）や環境指紋の不一致を検知し、元DBファイルを一切書き換えずにオンメモリでロックします（自環境の正規バックアップDB等は管理パスやVSNの実在確認により自動でペアリングされます）。本体入りUSBメモリが故障して新環境へ引き継ぐ際は、**①パスワード**、**②所有メディア（VSN＋実在写真サイズ）のワンクリック照合**、**③16桁リカバリーコード（`TETH-XXXX-...`）**の3通りで安全に復旧できます。
2. **Lv.1：起動ロック ＆ DBロックモード（パスワード必要）**:
   - アプリ起動時のパスワードロック画面（全データAPI `423 Locked` 遮断）と「今すぐロック」ボタンに加え、**2段階鍵方式（256-bit `DEK` + `PBKDF2-HMAC-SHA256` 200,000反復 `KEK`）**により `library.db` 内の全サムネイル BLOB を認証付き暗号化（`TENC\x01`）し、`VACUUM` で空きページの平文痕跡も消去します。
3. **Lv.2：フルロックモード（Lv.1 ＋ `Loome` カプセル化ロック・パスワード必要）**:
   - Lv.1 に加え、本体および接続中の自分の外付け `Loome` 内の画像・RAWファイルの先頭最大 64KB をインプレース暗号化（`TETHVLT1` マジック置換 ＋ 末尾 72B 認証フッター付与、更新日時 `mtime` 維持）し、エクスプローラーや外部ソフトからの直接閲覧も遮断します。解錠中はオンメモリで透過復号し、書き出し時やレベル変更時には元の無加工ファイルへ 1 ビット単位で完全復元します。
4. **鍵ロストを防ぐ自己修復サルベージ ＆ 7日間バックアップリマインド**:
   - 万一 Lv.2 運用中に `cache/library.db` を誤削除して再起動しても、`Loome/.loome_seal` 内の鍵カプセルから暗号鍵一式を新しいDBへ自動サルベージし、パスワードまたはリカバリーコードで100%復号できます。
   - 前回のDBバックアップから7日以上経過している場合は起動時にリマインドモーダルを表示し、`CopyFileExW` カーネルコピーによる高速バックアップと復旧キー保存、および物理故障に備えた別ドライブへの退避をワンクリックで案内します。

### 5.3 8つのサイドバー・ナビゲーションと多次元論理検索
左端の垂直タブレールには用途順に整理された8つのセクションが並び、メインツールバー中央の **3大基本フィルタ**（①表示対象プルダウン：`すべての写真 / 接続中の写真 / 未接続の写真 / リンク消失の写真 / 未分類の写真 / 重複のある写真`、②形式・状態プルダウン：`すべての形式 / RAW / RAW+JPEG / JPEG / 調整済 / XMPあり`、③4段階評価トグル：`優 / 良 / 可 / 棄`）と自在に組み合わせて絞り込めます。

1. **`Folder`（フォルダ・登録メディア・Loome保管庫）**:
   - 登録メディア一覧（VSN管理・抜き挿しリアルタイム自動反映）、内部・外部の `Loome` 保管庫、一般管理フォルダをツリー表示。親フォルダの「直下＋子フォルダ合計」枚数表示、左クリック時のサブフォルダ増減検知、リンク消失写真の選択消去・絞り込み安全消去に対応。
2. **`Binder`（絞り込み条件セットの保存・呼び出し専用ページ / 初期選択）**:
   - 現在の絞り込み条件の組み合わせに名前を付けて保存し、1行のスリムなカードからワンクリック適用・全画面スライドショー再生を行える専用ページ（保存条件の内訳はホバーツールチップで確認可能）。
3. **`Tag`（階層タグ・12色カラー・論理検索）**:
   - 最上位の親が同じタグ同士（例：`車/Toyota` と `車/Mazda`）は `OR（または）`、異なる親グループ間（例：`車/...` と `季節/秋`）は `AND（かつ）` で自動結合。左クリックで包含 `[+]`、右クリックで除外 `[-]` を組み合わせ、「イベントタグは付けたが被写体タグを付け忘れている写真（打ち漏れ）」もワンクリックで抽出できます。子タグ作成は `+子` ボタン押下時のみ入力欄が開くオンデマンド方式です。
4. **`Historia`（撮影年月・ミニ＆拡大フォトカレンダー）**:
   - 左サイドバー常設の月間ミニカレンダーに加え、日別の代表サムネイル・撮影枚数・「優」枚数・撮影地が並ぶ拡大フォトカレンダーと年間12ヶ月ヒートマップを搭載。
5. **`Place`（撮影地ツリー・都道府県マップ）**:
   - オフライン逆ジオコーディングによりGPS座標から「国 ＞ 都道府県 ＞ 市区町村」を自動判定してツリー化。
6. **`Gear`（カメラ・レンズ階層ツリー）**:
   - カメラボディ配下にそのボディで使用したレンズを階層表示。`[+]` 包含と `[-]` 除外により、「スマホ写真を除外して一眼カメラの写真だけを見る」といった抽出も容易です。
7. **`Lab`（撮影傾向の分析・発掘）**:
   - **47都道府県制覇白地図・ヒートマップ・さんぽ軌跡**: 白地図の塗りつぶしや撮影密度ヒートマップ、日付ごとの移動軌跡ラインを表示。
   - **勝ちレンズ・得意設定カルテ**: 高評価（優・良）の割合から、相性の良いレンズや得意な焦点距離・F値・時間帯を自動集計してカルテ化。
   - **太陽高度・撮影条件抽出**: 撮影日時と緯度経度から太陽高度を計算し、「マジックアワー」「ブルーアワー」「夜景・星空」を抽出するほか、低速シャッターの「手ブレ注意」抽出、「歴代の今日」、未整理フォルダをランダムに開く「ガチャ」を搭載。
8. **`Search`（ファイル名インクリメンタル検索）**:
   - ファイル名や連番の一部からリアルタイムに絞り込み。

- **フローティング自然文フィルタバー ＆ 道標（トレイル）表示**:
  - 絞り込み中、現在の条件が自然な日本語文（英語モード時は英語）でフローティング表示され、文中の `[ または ⇄ ]` `[ かつ ⇄ ]` で結合論理をその場で反転可能。親階層を閉じていても、配下に有効なフィルタがあれば破線枠と件数バッジ（`+1` / `-1`）が道標として点灯します。

### 5.4 高速選別・高精細閲覧ワークフロー
- **片手4段階レーティング（`優` / `良` / `可` / `棄`）**:
  - 星5段階の曖昧さを排した4段階評価。数字キー（<kbd>1</kbd>: 優 / <kbd>2</kbd>: 良 / <kbd>3</kbd>: 棄 / <kbd>0</kbd>: 可）だけで片手選別ができ、「棄」にした写真は確認ダイアログなしで即座に一覧から隠れて次の写真へフォーカスが移ります。
- **最高評価コマが自動で表紙になるスマートスタック**:
  - 連写、露出ブラケット（AEB）、RAW+JPEGペア、重複写真を自動で1つの束に集約（ペア済みの従属RAWが重複・黒枠として混入しない精密なペアリング制御を実装）。
  - 束の中で最も評価が高いコマ（`優 > 良 > 可 > 棄`）が自動的にスタックの表紙として表示され、ライトボックス（<kbd>↑</kbd> <kbd>↓</kbd> キー）や右インスペクタで各コマに評価を付けるだけでベストカットが表紙へ昇格します。
- **ちらつきゼロ・原本1:1基準の高精細ライトボックス ＆ 2枚比較（Duel）**:
  - 拡大表示を開く際、低解像度サムネイルの引き伸ばし表示によるボケちらつきを排し、フルサイズ画像を直接ソフトフェードイン表示（未接続時のサムネイル表示は画質が破綻しない最大200%上限に制御）。
  - ダブルクリックで **全体フィット（縮小 `%`） ⇄ 原本1:1等倍（`100%`）** を瞬時に切り替えられ（ホイールで最大 `300%`、90°/270°回転写真も正確な拡大率で整合）、下部フィルムロールの1ノッチ精密ホイール移動や、マウスのサイド「戻る」ボタンで拡大表示を閉じる操作にも対応しています。
  - 迷う2枚は <kbd>V</kbd> キーで左右に並列表示（`Duel`）し、同期ズーム＆パンと2枚同時RGB・輝度ヒストグラム比較（<kbd>H</kbd> キー）を行いながら、<kbd>W</kbd> キーで良い方を残すトーナメント勝ち抜き選別が可能です。
- **すっきり整理された右インスペクタと安全な一括タグ操作**:
  - 右インスペクタは上部タイトルバーを廃してプレビュー直下のクイックアクションバー（調整・波形・左/右回転・保存先フォルダ表示・外部アプリ起動）へ機能を集約し、縦スペースを写真とEXIF・タグ領域へ還元。
  - 複数写真を選択した際は、**選択したすべての写真に共通するタグにのみ `×` 一括削除ボタンを表示**（一部の写真にしか付いていないタグは破線表示にして誤削除を防止）し、タグ階層の移動・リネーム・削除は「設定」内の専用「タグツリーエディタ」に分離しています。

### 5.5 非破壊調整・外部現像ソフト連携・書き出し
- **非破壊の回転・傾き・トリミング・トーン調整**:
  - 90°回転、水平出し（±45°・自動内接ズーム連動）、アスペクト比固定トリミング、明るさ・コントラスト・彩度の調整をリアルタイムプレビューとヒストグラム連動で実行。<kbd>\</kbd> または <kbd>Space</kbd> 長押しでの Before/After 比較や、トーン3項目のコピー＆複数写真への一括ペーストに対応。
- **撮影日時シフト補正 ＆ スマホGPS引き継ぎ**:
  - 複数カメラ間の時計ズレや時差を `±日・時間・分・秒` で一括非破壊補正（元のEXIF日時も保持されワンクリックで復元可能）。前後1時間以内（±60分）のスマホ写真からGPS座標を非破壊で引き継ぐ機能も搭載。
- **外部現像ソフト連携の自動更新検知 ＆ 既存XMPサイドカーの非破壊読み取り**:
  - 右インスペクタから外部ソフトで写真を開いて編集・保存したり `.xmp` を出力して画面へ戻った際、フォーカス復帰フックで更新を自動検知してサムネイルとUIへ即時反映。フォルダの「リフレッシュ」時には、過去に抽出失敗していたRAWのEXIF・サムネイルも評価やタグを保ったまま自動再取得します。
  - Lightroom等が出力した `.xmp` 等は書き換えずに読み取り、`[XMPプレビュー]` ホールド比較や `XMP/...` ルート配下への安全な評価・階層タグ隔離取り込みが可能です。
- **用途に合わせた3つの書き出し**:
  1. **スマート・テイクアウト**: 非破壊調整の焼き込み、長辺リサイズ、撮影順の連番リネーム、EXIF情報の選択消去（GPSのみ消去／全消去）、オプションの `.xmp` サイドカー同時出力を一括実行（標準出力先 `take_out/`）。
  2. **ベタ焼きHTML出力**: 選択した写真を赤鉛筆チェックマークやA4印刷に対応した暗室コンタクトシート風の単一HTMLファイルとして出力。
  3. **クリップボード画像コピー（<kbd>Ctrl</kbd>+<kbd>C</kbd>）**: 非破壊調整を反映した画像をそのままOSのクリップボードへコピーし、SNSや記事執筆画面へ直接ペースト可能。

### 5.6 ローカルAI・スマホブラウザ連携・クリーンアップデート
- **ローカルAI自動タグ付け ＆ 12色カラー単独再判定**:
  - 外部通信ゼロで同梱のCLIPモデル（ONNX Runtime）が写真を解析し、被写体・シーンのAI候補タグ（確認後にワンクリックで手動タグへ昇格可能）と12色の主要カラーラベルを自動付与。手動タグを保護したままカラータグのみを再判定する機能も搭載。
- **2通りのスマートフォン連携（Wi-Fiブラウザ ＆ USB単体HTML）**:
  - 自宅Wi-Fiでは「スマホ連携」を開いた時のみ軽量なインプロセスTCPリレーが起動し、QRコード（ワンタイムトークン認証・30分無通信自動停止）を読み取るだけでスマホのブラウザから閲覧・選別が可能。
  - 外出先・ネット圏外では、USBメモリ内の単一HTMLファイル `Tetheract_Mobile.html` をスマホのブラウザで開くだけで WebAssembly版SQLite（`sql.js`）が `library.db`（v1.7+保護スキーマ対応・オンデマンド高速読込）を直接読み込み、オフラインで選別・一括タグ付けを行って `mobile_sync.json` でPCへ差分同期できます。
- **ローカル完結クリーン・アップデーター（`Tetheract.exe`）**:
  - 軽量差分パッケージ `Tetheract_v*diff.zip` を解凍せずそのままフォルダへ置いて `Tetheract.exe` を起動すると、バージョン比較とアーカイブ検証を行ったうえで古いプログラムフォルダ（`frontend/`・`server/`・`LICENSES/`・`tools/`）を一度消去してから最新ファイルをクリーン展開し、使用後の `diff.zip` も自動削除します（`cache/`・`Loome/`・セキュリティ鍵等のユーザーデータは一切消えません）。

## 6. 技術スタック & アーキテクチャの裏付け（技術紹介用データ）

エンジニア層や技術系メディア向けの紹介で設計上の工夫に触れる際は、以下の正確な仕様を参照してください。

- **バックエンド**: Python 3.11（`python/` に Embeddable Python ＋ VC++/OpenMP DLL を同梱）+ FastAPI（`server/routers/` による機能別ルーター分割）+ Uvicorn
- **フロントエンド**: Vanilla HTML5 + CSS3 + JavaScript (ES6+)。Node.js やビルドツール（Webpack / Vite 等）を一切使わず、外部CDN通信も行わない完全ローカル完結構成（フォント `Inter` / `Outfit`、地図ライブラリ `Leaflet`、WebAssembly `sql.js` もすべてローカル同梱）。
- **ネイティブランチャー**: C# 製 `Tetheract.exe`（DOS窓なし起動、多重起動時の既存ウィンドウ前面化、ローカル完結クリーン・アップデーター内蔵）。SmartScreen警告を避けたいユーザー向けに、Windows標準の `csc.exe` で平文ソース（`tools/Launcher.cs`）から自己ビルドできる `tools/Build.bat` も同梱。
- **SQLite3 高速化・正規化設計（`cache/library.db`）**:
  - WALモード ＋ 256MB メモリマップドI/O ＋ RAMキャッシュ。
  - ユニーク画像（`photos`：撮影日時・ミリ秒・サイズ・露出値、またはExif欠落時の本体4箇所サンプリングBLAKE2bハッシュによる不変識別キー `content_key`）と、実ファイル所在リンク（`photo_links`：`volume_serial` ＋ ドライブ相対パス）の1対多正規化構造。
  - サムネイル（WebP）を個別ファイルではなく `thumbnails` テーブル（`photo_id INTEGER PRIMARY KEY` ROWID直結）の BLOB として格納し、寸法参照用のカバリングインデックス `idx_thumbnails_dims` を付与。USBメモリ上での微小ファイル大量生成によるランダムI/O崩壊やアンチウイルスのスキャン負荷を根本回避。
  - `photo_tags` テーブルに `PRIMARY KEY (photo_id, tag) WITHOUT ROWID` クラスタ化を採用。
  - 切断ネットワークドライブの120ms高速TCP死活判定＋DBコミット世代連動インメモリキャッシュにより、数万枚規模でもフィルタ切替を数ミリ秒以下で応答。
- **多層セキュリティ防御**:
  - 既定は `127.0.0.1`（PC内部のみ）待受。Host ヘッダ検証（DNS Rebinding 遮断）＋ Origin ヘッダ検証（CSRF 遮断）＋ オンデマンドLAN QRトークン認証＆APIホワイトリスト（PC操作・削除APIはLANから完全遮断）＋ 3段階エシカル＆暗号化保護（Python標準搭載 OpenSSL `PBKDF2-HMAC-SHA256` / `SHAKE256` / `HMAC` によるポータブルAEAD暗号化）。

## 8. 【最重要】紹介文執筆AIが厳守すべき編集原則・切り口ガイド・NG事項

TETHERACT の紹介記事（note等）、SNS告知、レビュー文を作成する際は、**「3. 作業を邪魔しない、Look&Feel。」の哲学を文章そのものにも適用**してください。いわゆる「AIが書いたテンションの高い宣伝ポエム」を最も嫌います。

### 8.1 文体・トーン＆マナーの5原則
1. **感嘆符（`!` / `！`）の原則禁止**:
   - 「〜できます！」「〜を実現しました！」のような宣伝文句のテンションは使わず、落ち着いた句点（`。`）で終えてください（※作者本人のくだけた雑談コラムのツッコミ箇所などを除く）。
2. **カラフルな絵文字スパムの禁止**:
   - 見出しや箇条書きの先頭に派手な絵文字（🚀, ✨, 💡, 🔥, 📁, 🎉 等）を並べないでください。
3. **誇大広告ワード・他社批判の禁止**:
   - 「爆速」「究極」「革命的」「神アプリ」「プロ仕様」「完全無欠」といった安易な煽り言葉は使わないでください。
   - 特定の他社ソフト（Lightroom や Google フォト等）を貶めるような比較表現は避け、「TETHERACT はこういう思想・用途のために作られている」という静かなスタンスで記述してください。
4. **過度な装飾（太字の壁・括弧の多重入れ子）の回避**:
   - 1文の中に何度も太字（`**`）を入れたり、括弧の中にさらに括弧を重ねたりして視線を散らすのを避け、端正で読みやすいリズムを保ってください。
5. **スペックの羅列ではなく「背景の悩み（Why）と解決の工夫（How）」を語る**:
   - 単に「VSN対応」「SQLite BLOB採用」「Loome搭載」「3段階セキュリティ」と専門用語を並べるのではなく、
     - *「年々増えていく外付けSSDや複数のSDカードを、フォルダを作り直さずにそのまま横断して見たい」*
     - *「大切な元データや自分のフォルダ構造は1ミリも汚したくない。でも、選んだ写真だけは『Loome（ルーム）』という自分の部屋に入れて自由に整理・リネームしたい」*
     - *「USBやSSDを持ち歩いたり友人からメディアを借りたりするからこそ、相手のプライベートな領域には触れず、自分の写真カタログもきちんと守りたい」*
     - *「何千枚もの連写やRAWを、メーカー純正の色味のままテンポよく片手で選別し、ピントを等倍で確かめたい」*
     といった、写真を撮る人が実際に抱えている体験と、それを邪魔しない道具としての心地よさを軸に文章を組み立ててください。

### 8.2 誤認・ハルシネーション防止チェックリスト（事実確認ルール）
紹介文を書く際、以下の事実関係を誤って表現しないよう必ず確認してください。
- **スマートフォン連携の仕組み**: スマートフォン向けの専用ネイティブアプリ（App Store / Google Play 等のインストール型アプリ）ではなく、**自宅Wi-Fi経由のスマホブラウザ接続（QRコード）** または **USBメモリ内の単一HTMLファイル（`Tetheract_Mobile.html`）をスマホブラウザで開くオフライン方式** です。「スマホアプリをインストールして〜」とは書かないでください。
- **ソフトの立ち位置**: 本格的なRAW現像・レタッチソフト（トーンカーブや部分マスク現像等を行うソフト）ではなく、**「高速な閲覧・選別（セレクト）・非破壊整理と、普段使いの軽快な調整・書き出しを担うローカル写真管理ツール（外部現像ソフトとも気持ちよく共存するハブ）」** です。
- **非破壊の範囲**: 一般の管理フォルダにある元ファイルは1バイトも変更・移動・削除しません（「棄」にしても画面上で隠れるだけでファイルは消えません）。実ファイルの移動やリネームができるのは、専用保管庫 `Loome` 内にコピーしたファイルのみです。
- **オフライン動作の範囲**: 写真の閲覧・検索・AI自動タグ付け・逆ジオコーディング（市区町村判定）・アップデート適用まですべてオフラインで完結します。インターネット接続が発生するのは、地図画面で背景の地図タイル（OpenStreetMap）を表示するときだけです。

### 8.3 媒体・用途別の構成アプローチ例
- **短文紹介（SNS・リポジトリ紹介・300字前後）**:
  - 「既存のフォルダ構造や元ファイルに1バイトも触れずに、内蔵ドライブや複数の外付けSSD・SDカードを横断してRAWやJPEGを軽快に選別・検索できるWindows向けローカル写真管理ツール」という核を端的に伝え、インストール不要・完全オフラインである点を添える。
- **標準的な紹介記事（note固定記事・ブログレビュー・1,500〜3,000字）**:
  - 導入で「写真が増えるにつれて重くなる選別作業と、ソフトの都合でフォルダを縛られたくない悩み」を提示し、それに対する答えとして **「4つの設計原則（4本の柱）」** に沿って体験（片手選別・RAW即時表示・包含/除外検索・専用部屋 `Loome`・USBポータブル＆エシカル保護）を紹介し、最後に「合わなければフォルダごと捨てるだけで元通りになる気楽さ」で結ぶ。
- **特定テーマの深掘り記事（連載・機能コラム）**:
  - 「なぜ非破壊ビューアの中に『Loome』という整理部屋を作ったのか」「ポータブル運用における礼節としてのエシカルモード（Lv.0）」「数万枚の写真をUSBメモリ上でも軽快に動かすためのSQLite設計」など、1つの思想（Why）と工夫（How）に絞って掘り下げる。
