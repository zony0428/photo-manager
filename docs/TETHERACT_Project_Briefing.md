# TETHERACT Photo Manager（テザラクト）プロジェクト概要ブリーフィング

このドキュメントは、Windows向けローカル写真ビューア・選別・管理ツール **「TETHERACT Photo Manager（表記：TETHERACT pm / 読み：テザラクト・フォトマネージャー）」** のプロモーション企画、紹介記事（note連載等）、ドキュメント作成を支援するAIへ向けた公式コンテキスト資料です。

---

## 1. プロダクト基本情報 & ブランドアイデンティティ

### 1.1 概要
- **正式名称**: Tetheract Photo Manager（略称・ロゴ表記: `TETHERACT pm`、旧称: Photo Manager）
- **ジャンル**: Windows向け ローカル高速写真ビューア・選別・非破壊管理ツール（MITライセンス・オープンソース）
- **着想元**: かつての「Picasa」の軽快な一覧性・直感性と、「Tiat」のストイックで写真を邪魔しないUI設計にインスパイアされて開発。
- **対象フォーマット**: JPEG / PNG / WebP / HEIC および各社カメラのRAWデータ（SIGMA Foveon `.X3F`、Canon `.CR2`/`.CR3`、Nikon `.NEF`、Sony `.ARW`、Fujifilm `.RAF`、Panasonic `.RW2`、Olympus `.ORF`、Pentax `.PEF`、`.DNG` 等）。

### 1.2 名称「TETHERACT（テザラクト）」の由来と世界観
映画『インターステラー』に登場する、時間や空間を超えて記憶の断片（本棚）へアクセスする4次元超立方体 **「テサラクト（Tesseract）」** に着想を得て、以下の言葉を掛け合わせた造語です。
- **Tether（繋ぎ止める糸・綱）**: PC内蔵ドライブ、外付けSSD、複数のSDカードなど、時間や場所を超えて散らばっていく写真の記憶を1つに繋ぎ止める。
- **Tesseract（超立方体）**: 保存場所という物理的な次元に縛られず、タグ・時間・場所・機材・色という多元の切り口から瞬時に写真へアクセスする空間。
- **Act（行為・振る舞い）**: ただ眺めるだけでなく、選び抜き、整え、作品や記録として次へ繋げる行為。

### 1.3 ビジュアル・デザイン言語（Stoic Darkroom）
- **アイコンとW-Z回転アニメーション**:
  白銀比（シルバーレシオ）を取り入れた4次元超立方体アイコンを採用。外周のシャンパンブロンズ枠から中心の純白コア枠へ向かって4本の遠近テザーラインが収束し、カメラレンズのマルチコート反射や暗室の光を思わせる急減衰ブルーム発光を備えています。起動スプラッシュや処理中には、4本の斜めレールに沿って内側の□が外枠へ拡大し、同時に奥のコアから次の□が湧き上がる「超立方体のW-Z回転（1点透視投影）」がリアルタイム描画されます。
- **写真が主役になる静かな暗室UI**:
  画面上からカラフルなOS標準絵文字や主張の強い黒太枠を一切排除し、単色細線SVGアイコンと半透明すりガラスバッジに統一。
- **4つのカラーテーマと日英リアルタイム切替**:
  - `Tetheract D`（既定ダーク：ウォームモノトーン × シャンパンブロンズ）
  - `Tetheract L`（ライト：シルキーストーン × アンバーブロンズ）
  - `夜墨 (Sumi)` / `和紙 (Paper)`（日本の伝統色ベースのダーク／ライト）
  - ヘッダーの `JP` / `EN` ボタンで画面表示・ヘルプをワンクリックで日英切り替え可能。

### 1.4 開発スタンス（個人開発 × 100% AI バイブコーディング）
- 開発者自身が自分のカメラ・写真ライフで本当に欲しかった道具を形にした個人開発プロジェクトであり、コードは100% AIとの対話（バイブコーディング）によって構築されています。
- 「カメラのSDカードや保存用メディアを絶対に壊したくない」「自分が長年作ってきたフォルダ管理の流儀（ディレクトリ構造やファイル名）をソフトの都合で汚されたくない」という開発者自身の強いこだわりが出発点になっています。

## 2. 普通の写真管理アプリと何が違うのか？（5つの強み・差別化ポイント）

一般的なクラウド写真サービス、重量級の現像カタログソフト、あるいは単純なフォルダビューアと比較した際、TETHERACT には以下の明確な違いがあります。

### ① 「完全非破壊・元フォルダ汚染ゼロ」の徹底
- 写真を専用フォルダへ強制インポートさせず、既存のフォルダ構造のまま扱えます。
- 回転、傾き補正、トリミング、トーン調整、日時補正、タグ付け、「棄（ボツ）」の評価を行っても、**元の写真ファイルには1バイトも触れず、写真フォルダの中に管理用の隠しファイルや独自サイドカーファイルを作ることも一切ありません**。
- すべての記録はアプリフォルダ内の `cache/library.db` 1箇所にのみ保存されます。「もしアプリが合わなければ、Tetheractのフォルダごとゴミ箱に捨てるだけで、PCも写真フォルダも100%元のまま残る」という安全性が最大の前提です。

### ② 「元フォルダは汚さない」と「実ファイルを整理したい」を両立する特区『Loome（ルーム）』
- 通常のフォルダは100%非破壊で守りつつ、「選び抜いたお気に入りの写真だけは、実ファイルごと集めてサブフォルダ分けしたり、連番リネームして持ち歩きたい」という場面のために、アプリが管理する独立した整理特区 **『Loome（ルーム）』** を備えています。
- **『Loome』という部屋に入れた写真だけは、アプリ上から自由にドラッグ＆ドロップでサブフォルダ移動したり、<kbd>F2</kbd> キーで撮影順の一括連番リネームができる**という明確な境界線（サンドボックス思想）を持っています。

### ③ 物理ドライブや複数SDカードの壁を超える「VSN個体識別 × 所在リンク分離DB」
- Windowsのドライブ文字（`D:` や `E:`）ではなく、メディア固有の **ボリュームシリアル番号（VSN）** でドライブやSDカードを個体識別します。別PCに繋いでドライブ文字が変わっても自動で追従し、同じカードリーダー（同じ `E:\DCIM`）に複数のSDカードを差し替えても別々のカードとして独立管理できます。
- データベース内部で「ユニークな写真そのもの（`photos`）」と「どのメディアのどのパスに実ファイルがあるか（`photo_links`）」を分離しているため、**SDカード・PC内蔵SSD・外付けバックアップHDDの3箇所に同じ写真があっても、一覧上は重複せず1枚として扱われます**。
- SDカード上で先に付けた評価・タグ・非破壊調整は、後からPCへ写真を移動・コピーしてスキャンした際にも自動で引き継がれます。また、外付けドライブやSDカードを外している状態でも、DB内のWebPサムネイルで閲覧・検索・選別を続けられます。

### ④ インストール不要・USBメモリ単体で自走し、スマホでもオフライン選別できる
- Python実行環境、ローカルAIモデル、SQLiteデータベースが1つのフォルダに収まっており、PCへのインストール作業は不要です。フォルダごとポータブルSSDやUSBメモリに入れれば、どのPCでも `Tetheract.exe` をダブルクリックするだけで同じ環境が立ち上がります。
- さらに、外出先でPCすらない環境でも、USBメモリをスマートフォン（Android等）に挿して単一HTMLファイル（`Tetheract_Mobile.html`）を開けば、**ブラウザ上のWebAssembly版SQLite（`sql.js`）が `library.db` をメモリへ直接読み込み（約1秒、読み込み後はUSBを抜いても操作可）、スマホの親指操作で写真の4段階選別やタグ付けを行って後からPCへ差分同期**できます（自宅Wi-FiでのQRコード直結モードも搭載）。

### ⑤ 重たいRAW（Foveon X3F含む）の即時表示と「引き算（排他）思考」の選別体験
- 重いRAW現像処理をその場で回すのではなく、RAWファイル内部の埋め込みプレビューを高速抽出（非対応形式のみLibRawへフォールバック）するため、SIGMA Foveon（`X3F`）をはじめとする各社RAWをメーカー固有の色味のまま待ち時間なく表示します。
- タグや機材ツリーでは「左クリックで包含 `[+]`、右クリックで除外 `[-]`」を直感的に組み合わせられ、画面下部の「自然文フィルタバー」で条件を日本語の文章として確認しながら、数万枚の写真から「足し算・引き算」で素早く目的の写真を掘り出せます。

## 3. 根幹をなす「4つの設計原則（4本の柱）」

TETHERACT のすべての機能とUI判断は、以下の4つの柱を実現するために設計されています。プロモーションや機能紹介を行う際も、この4本の柱を軸に据えます。

1. **保存先に縛られない、簡単で自由な分類と検索。**
2. **元データは汚さず壊さず。でも、見るだけでは終わらない。**
3. **作業を邪魔しない、Look&Feel。**
4. **クラウドには頼らない。でもポータブル。**

## 4. 主要機能ディープダイブ

### 4.1 専用整理・持ち歩き特区『Loome（ルーム）』（旧称 `storage/`・`carry/` からの進化構想）
「元の写真フォルダには一切手を出さない」という原則を守りながら、ユーザーが選び抜いた写真だけをコピーして持ち歩き、実ファイルのサブフォルダ整理やファイル名変更を自由に行えるTETHERACT専用の隔離領域です。

- **『Loome』のネーミングに込められたトリプルミーニング**:
  1. **`Loom`（織機・織りなす場所）**: `Tetheract` の `Tether`（記憶を繋ぐ糸）を手繰り寄せて、1つのコレクションに織り上げる場所。
  2. **`Lume`（光 / Lumen）**: 写真の本質である「光」を宿し、収めておく場所。
  3. **`Room`（部屋 / 暗室）**: 日本語の発音は誰もが直感的に理解できる **「ルーム」**。外の世界（既存の撮影フォルダ）から守られた「自分だけの整理部屋」であり、この部屋の中だけは自由に模様替え（フォルダ移動・リネーム）ができることを意味します。
  - *(開発秘話・裏のウィット)*: 日本人がカタカナ英語で「ルーム（Room）」と発音するとネイティブには `Loom` に聞こえるという自虐的なユーモアから生まれた造語でもあります。また、`Home` や `Dome` と同じ「`o` を中心に `me` で閉じる綴り」により、大切な写真を包み込む空間の温度感を持たせています。
- **主な機能とマルチメディア展開**:
  - アプリ本体内の `Loome`（実フォルダ `storage/`）だけでなく、VSN登録した外部メディア（ポータブルSSDや別USBメモリ）にも専用の `Loome` 特区（`Tetheract_Loome`）を作成・マウントし、左サイドバーからシームレスに扱える設計。
  - 外部フォルダから `Loome` へ写真を取り込む際、評価・タグ・非破壊調整が引き継がれるだけでなく、**同名の `.xmp` / `.pp3` / `.dop` 等のサイドカーファイルやペアのRAWファイルも自動で追従**します。
  - `Loome` 内では、サブフォルダの作成・リネーム、ドラッグ＆ドロップでの写真移動、<kbd>F2</kbd> キーによる単一リネームおよび**ミリ秒精度の撮影日時順・一括連番リネーム**（`YYYYMMDD_HHMMSS_連番` 等）、外部フォルダへの丸ごとエクスポートがエクスプローラーを開かずに完結します。

### 4.2 分類・検索・振り返り機能
- **階層タグ・機材ツリーの包含 `[+]`・除外 `[-]` 論理検索**:
  - 最上位の親が同じタグ同士（例：`車/Toyota` と `車/Mazda`）は `OR（または）`、異なる親グループ間（例：`車/...` と `季節/秋`）は `AND（かつ）` で自動結合。
  - 親タグを `[+]` で選んだあと不要な子タグだけ `[-]` で引き算したり、「イベントタグは付けたが被写体タグを付け忘れている写真（打ち漏れ）」をあぶり出す検索がワンクリックで行えます。
- **フローティング自然文フィルタバー**:
  - 絞り込み中、画面下部に現在の条件が自然な日本語文（英語モード時は英語）で表示され、文中の `[ または ⇄ ]` `[ かつ ⇄ ]` ボタンで結合論理をその場で反転可能。条件ピルをクリックすると、兄弟タグの追加・除外や「歴代の同じ月すべて」への一括切り替えポップオーバーが開きます。
- **折りたたみ時の「道標（トレイル）」表示**:
  - 親タグや親フォルダ、年、都道府県などを折りたたんでいても、その配下の子項目でフィルタが有効な場合は「破線枠＋カラーエッジ＋件数バッジ（`+1` / `-1`）」が点灯し、どこで絞り込まれているかを見失いません。
- **撮影カレンダー（ミニカレンダー ＆ 拡大フォトカレンダー）**:
  - 左サイドバー常設の月間ミニカレンダーに加え、日別の代表サムネイル・撮影枚数・「優」枚数・撮影地が並ぶ拡大フォトカレンダーと年間12ヶ月ヒートマップを搭載。複数年・複数月・特定日のOR組み合わせ抽出に対応。
- **撮影傾向を振り返る「ラボ」と47都道府県マップ**:
  - **47都道府県制覇白地図・ヒートマップ・さんぽ軌跡**: オフライン逆ジオコーディングによりGPS座標から「国 ＞ 都道府県 ＞ 市区町村」を自動判定。白地図の塗りつぶしや撮影密度ヒートマップ、日付ごとの移動軌跡ラインを表示。
  - **勝ちレンズ・得意設定カルテ**: 高評価（優・良）の写真の割合から、相性の良いレンズやよく使う焦点距離・F値・撮影時間帯を自動集計してカルテ化。
  - **太陽高度・撮影条件抽出**: 撮影日時と緯度経度から太陽高度を計算し、「マジックアワー（薄明・日の出・日の入り）」「ブルーアワー」「夜景・星空」を抽出するほか、焦点距離に対する低速シャッターの「手ブレ注意」抽出、「歴代の今日」、未整理フォルダをランダムに開く「ガチャ」を搭載。

### 4.3 高速選別・閲覧ワークフロー
- **片手4段階レーティング（`優` / `良` / `可` / `棄`）**:
  - 星5段階の曖昧さを排した4段階評価。数字キー（<kbd>1</kbd>: 優 / <kbd>2</kbd>: 良 / <kbd>3</kbd>: 棄 / <kbd>0</kbd>: 可）だけで片手選別ができ、「棄」にした写真は確認ダイアログなしで即座に一覧から隠れて次の写真へ自動でフォーカスが移ります。
- **連写・ブラケットを束ねるスマートスタック**:
  - 高速連写、露出ブラケット（AEB）、RAW+JPGペア、重複写真を自動で1つの束にまとめて一覧の見通しを維持。ライトボックス（拡大表示）中に <kbd>↑</kbd> <kbd>↓</kbd> キーで束の中のコマを秒差（`+0.17s`）や露出差（`-1.00 EV`）を見ながらパラパラ漫画のように比較し、その場で「代表（表紙）」を切り替えられます。
- **2枚比較モード（Duel）**:
  - 最後まで迷う2枚は <kbd>V</kbd> キーで左右に並列表示。同期ズーム＆パンと、2枚同時のRGB・輝度ヒストグラム波形比較（<kbd>H</kbd> キー）を行いながら、<kbd>W</kbd> キーで良い方を残していくトーナメント勝ち抜き選別が可能です。
- **3つの一覧レイアウトとクリーン表示**:
  - 標準グリッド、縦横比を維持して隙間なく並べる「びっしり表示（Masonry）」、ポジフィルムのマウント枠のように余白をとる「マウント表示（Slide Mount）」の3モードを搭載。<kbd>I</kbd> キーでサムネイル上の文字情報をすべて消すクリーン表示にも対応。
- **日常のタグ付けと構造編集の分離**:
  - 選別中の誤ドラッグでタグ階層が崩れる事故を防ぐため、右インスペクタは「写真へのタグ付与・子タグ追加」に専念させ、タグのドラッグ＆ドロップ階層移動・リネーム・削除・省略名設定・ピン留めは「設定」内の専用「タグツリーエディタ」に分離しています。

### 4.4 非破壊調整・XMP連携・書き出し
- **非破壊の回転・傾き・トリミング・トーン調整**:
  - 90°回転、水平出し（±45°・自動内接ズーム連動）、アスペクト比固定トリミング、明るさ・コントラスト・彩度の調整を0msのリアルタイムプレビューとヒストグラム連動で実行。<kbd>\</kbd> または <kbd>Space</kbd> 長押しでの Before/After 比較や、トーン3項目のみのコピー＆複数写真への一括ペーストに対応。
- **撮影日時シフト補正 ＆ スマホGPS引き継ぎ**:
  - 複数カメラ間の時計ズレや海外旅行の時差を `±日・時間・分・秒` で一括非破壊補正（元のEXIF日時もDB内に保持され、いつでもワンクリックで復元可能）。
  - GPS非搭載カメラの写真に対し、前後1時間以内（±60分）にスマートフォン等で撮影した写真からGPS座標を非破壊で引き継ぐ機能を搭載。
- **既存XMPサイドカーの非破壊読み取り（混ぜない・壊さない・比較できる）**:
  - Lightroom等が出力した `.xmp` が同フォルダにある場合、それを一切書き換えずに読み取り、右インスペクタの `[XMPプレビュー]` ボタンを押している間だけ現像パラメータを反映してホールド比較が可能。評価や階層キーワードを取り込む際も、既存タグと混ざらない `XMP/...` ルート配下へ安全に隔離取り込みします。
- **用途に合わせた3つの書き出し**:
  1. **スマート・テイクアウト**: 非破壊調整の焼き込み、長辺リサイズ、撮影順の連番リネーム、EXIF情報の選択消去（GPSのみ消去／全消去）、オプションの `.xmp` サイドカー同時出力を一括実行。
  2. **ベタ焼きHTML出力**: 選択した写真を赤鉛筆チェックマークやA4印刷に対応した暗室コンタクトシート風の単一HTMLファイルとして出力。
  3. **クリップボード画像コピー（<kbd>Ctrl</kbd>+<kbd>C</kbd>）**: 非破壊調整を反映した画像をそのままOSのクリップボードへコピーし、SNSや記事執筆画面へ直接ペースト可能。

### 4.5 ローカルAI ＆ 待ち時間のコミュニケーションUI
- **ローカルAI自動タグ付け ＆ 12色カラー単独再判定**:
  - 外部通信ゼロで同梱のCLIPモデル（ONNX Runtime）が写真を解析し、被写体・シーンのAI候補タグ（確認後にワンクリックで手動タグへ昇格可能）と12色の主要カラーラベルを自動付与。手動タグを保護したままカラータグのみを再判定する機能も搭載。
- **統合アクティビティ・ドック ＆ 起動スプラッシュ**:
  - フォルダスキャン、AIタグ付け、`Loome` へのファイルコピー取り込み、大容量DBマイグレーションなどの待ち時間が発生する際、無言で待たせず、画面下部中央の「統合アクティビティ・ドック」および起動スプラッシュに「現在何枚目を処理しているか（枚数・％・ファイル名）」とテサラクトのアニメーションを表示します。

## 5. 技術スタック & アーキテクチャ概要

- **バックエンド**: Python 3.11（`python/` に Embeddable Python を同梱、ホストPCへのPython導入不要）+ FastAPI + Uvicorn
- **フロントエンド**: Vanilla HTML5 + CSS3 + JavaScript (ES6+)。Node.js やビルドツール（Webpack / Vite 等）を一切使わず、外部CDN通信も行わない完全ローカル完結構成（フォント `Inter` / `Outfit`、地図ライブラリ `Leaflet`、WebAssembly `sql.js` もすべてローカル同梱）。
- **ネイティブランチャー & 常駐制御**:
  - C# 製ネイティブGUIランチャー `Tetheract.exe`（DOS窓を出さずにサーバー起動＆Edge/Chromeの `--app` モードで専用ウィンドウを起動）。
  - コード署名証明書を持たない個人開発ソフトのため、SmartScreen警告を回避したいユーザー向けに、Windows標準搭載のC#コンパイラ（`csc.exe`）で平文ソース（`launcher/Launcher.cs`）からその場で `Tetheract.exe` を自己ビルドできる `Build.bat` を同梱。
  - `pystray` によるシステムトレイ常駐と明示的シャットダウン制御。
- **データベース（SQLite3 高速化設計）**:
  - 単一ファイル `cache/library.db`（WALモード + 256MBメモリマップドI/O + RAMキャッシュ）。
  - **エンティティとリンクの分離**: ユニーク画像（`photos`：撮影日時・ミリ秒・ファイルサイズ・露出値等から成る不変識別キー `content_key`）と、実ファイル所在リンク（`photo_links`：`volume_serial` + ドライブ相対パス）の1対多正規化構造。
  - **SQLite BLOB サムネイル格納**: サムネイル（WebP）をファイルシステム上の個別ファイルとして作らず、`thumbnails` テーブルに `photo_id INTEGER PRIMARY KEY`（ROWID直結・1発ルックアップ）の BLOB として格納。これにより、USBメモリ上で数万個の微小ファイルによるランダムI/O性能崩壊やWindows Defenderのスキャン負荷が発生せず、数万枚のグリッドスクロールとフォルダ丸ごとコピーが高速に動作します。
  - **クラスタ化タグテーブル**: `photo_tags` テーブルに `PRIMARY KEY (photo_id, tag) WITHOUT ROWID` を採用し、一覧表示・フィルタ時の連続スキャンを高速化。
- **セキュリティ（ローカルサーバー4層防御）**:
  1. **Hostヘッダ検証**: DNS Rebinding 攻撃を遮断。
  2. **Originヘッダ検証**: 外部サイトからのCSRF要求を遮断。
  3. **オンデマンドLAN待受 ＆ QRトークン認証**: 既定は `127.0.0.1`（PC内部のみ）で待機。「スマホ連携」を開いた時のみLAN待受を開始し、QRコード内のランダムトークンと HttpOnly Cookie で認証（30分無通信で自動停止）。
  4. **LAN APIホワイトリスト**: スマホからの通信は閲覧・評価・タグ付け・同期のみを許可し、PCのファイル操作や削除APIはすべて遮断。

## 7. 【重要】プロモーション・記事作成AIが厳守すべき文体・編集原則

TETHERACT の紹介記事（note等）、SNS告知、ドキュメントを作成する際は、**「3. 作業を邪魔しない、Look&Feel。」の哲学を文章にも適用**してください。いわゆる「AIが書いたテンションの高い宣伝ポエム」を最も嫌います。
