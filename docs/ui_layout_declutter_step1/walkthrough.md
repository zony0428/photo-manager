# Walkthrough：ステップ1「UIの交通整理（グチャグチャ感の解消）」

機能追加を重ねて発生していた「同じ機能の重複配置」「新旧機能の混在」「ツールバーや選択バーのボタン過密」を整理し、ビジュアル絞り込み・高速選別・単一写真操作の導線をスッキリ一本化しました。

---

## 🛠️ 主な改修内容

### 1. 左サイドバーの整理（実験的機能のラボ集約 ＆ ファイル名検索の最下部配置）
- **「🔍 ファイル名検索」を一番下へ移動**:
  - 各種ビジュアルフィルタ（フォルダ・タグ・場所・年月・機材・ラボ）の組み合わせで絞り込むアプリの特性に合わせ、アコーディオンの並び順を以下の通り整理しました：
    1. ⚡ クイックアクセス
    2. 📁 フォルダ
    3. 🏷️ タグ
    4. 🗺️ ジオタグ
    5. 📅 タイムライン
    6. 📷 カメラ・レンズ
    7. 🧪 ラボ
    8. 🔍 ファイル名検索（最下部）
- **実験的機能を「🧪 ラボ」に一本化**:
  - 「🗺️ ジオタグ」のツールバー (`#locationToolbar`) に重複配置されていた `🗾 制覇マップ` ボタンを削除し、`frontend/js/location_map.js` の自動再注入処理を停止して、「🧪 ラボ」内の `🗾 47都道府県 制覇白地図` (`#labOpenMapShortcutBtn`) に統一しました。

### 2. 上部メインヘッダーの整理 ＆「📥 取り込み」のフォルダツールバー移設
- 上部メインヘッダーの右側にあった `📥 取り込み` (`#uploadFilesBtn`) を外し、ファイル管理の本拠地である左サイドバー **「📁 フォルダ」内のツールバー (`#folderToolbar`)** に移設しました。
- 上部メインヘッダー右側の「表示コントロール・ソート順」と「システム・外部連携ボタン群（`📱 スマホ連携`・`⚙️ 設定`・`❓ ヘルプ`・`⏻ 終了`）」の間に縦セパレータ (`.toolbar-divider`) を設け、視覚的なグループ分けを明確にしました。

### 3. 「📤 テイクアウト」メニューの一本化（新旧重複の解消）
- 右クリックメニュー (`#contextImportSubmenu`) および下部選択バーの「📤 テイクアウト」ポップオーバー (`#floatingImportPopover`) から、旧仕様の単純JPGコピー用フォルダ一覧＆新規フォルダ入力欄を廃止しました。
- 現在は以下の**2つの明確な出力アクションのみ**が並びます（スマート・テイクアウトのデフォルト出力先は引き続き `take_out` フォルダがセットされます）：
  1. **⚡ スマート・テイクアウト...**（回転・クロップ・解像度・Exif・XMP制御）
  2. **🎞️ ベタ焼きHTML出力...**（暗室コンタクトシート・A4印刷対応）

### 4. 下部フローティング選択バーの過密解消（「`⋯ その他`」メニュー新設）
- 下部選択バー (`#selectionFloatingBar`) に横並びで露出していた以下の3つの補助ボタンを、新設の **「`⋯ その他`」ポップオーバー (`#floatingMorePopover`)** 内に格納しました：
  - `🔄 サムネイル更新` (`#floatingRefreshThumbBtn`)
  - `📍 ジオタグ準用 (スマホGPS)` (`#floatingInferGpsBtn`)
  - `🗑️ ジオタグ情報を削除` (`#floatingClearGpsBtn`)
- これにより、下部バー本体の「🗑️ 削除（ライブラリから登録解除）」と「🗑️ ジオタグ削除」のゴミ箱アイコン重複による押し間違いリスクを解消し、横幅を大幅にスリム化しました。
- あわせて `frontend/js/compare.js` の `⚖️ 2枚比較 (V)` ボタン挿入位置を `#floatingMoreGroup` の手前に更新しました。

### 5. 右インスペクタ上部への「単一写真クイックアクションバー」新設
- 右インスペクタ (`#inspectorFixedPreview`) のプレビュー画像直下に、選択中の1枚に対するクイックアクションバー (`#inspectorQuickActionsBar`) を新設しました：
  - **`✂ 調整`** (`#inspectorQuickAdjustBtn`): 切り抜き・傾き・明るさ調整モーダル (`C`キー) を開く
  - **`📊 波形`** (`#inspectorQuickHistBtn`): すぐ下にRGB・輝度ヒストグラム (`H`キー) を展開・格納する
  - **`↺` / `↻`** (`#inspectorQuickRotateLeftBtn` / `#inspectorQuickRotateRightBtn`): 左90° (`L`キー) / 右90° (`R`キー) に即時回転する
- これに伴い、`frontend/js/histogram.js` が「ℹ️ 詳細情報」タブの奥に動的生成していた重複ボタン行 (`#inspectorHistMetaRow`) を廃止し、プレビュー直下に一本化しました。
