# コマンドプロンプト非表示起動 & 自動シャットダウン機能の実装計画

コマンドプロンプト（黒い画面）を表示させずに Photo Manager を起動し、ブラウザを閉じた際にバックグラウンドの Python プロセスが自動的かつ安全に終了する仕組みを導入します。

---

## ユーザー確認事項 (User Review Required)

> [!NOTE]
> - **起動時の挙動**: `start.bat` をダブルクリックすると、Windowsの仕様上コンマ数秒（約0.2秒）だけ黒い枠が出ますが、裏で `pythonw.exe` を立ち上げた瞬間にバッチファイル自身が即座に自動で消えます。
> - **ブラウザを閉じた後の自動終了**:
>   - ブラウザとサーバー間で約3秒ごとに「生存信号（ハートビート）」を通信します。
>   - ブラウザ（全タブ）を閉じてから **約12秒** 通信が途絶えると、サーバーが安全に自動終了します（リロード時などに誤って終了しないための猶予時間です）。
>   - 起動直後はブラウザが立ち上がるまでの準備時間を考慮し、初回ハートビート受信まで **60秒の猶予（タイムアウト）** を設けます。

---

## 変更内容の提案

### 1. バックエンド (サーバー側)

#### [NEW] [heartbeat.py](file:///r:/photo-manager/server/heartbeat.py)
ハートビート監視マネージャーを実装します。
- `last_heartbeat_time`: 最終受信時刻を記録。
- バックグラウンドスレッドで 1 秒ごとに生存チェック。
- 初回接続待機（タイムアウト 60 秒）および通常待機（タイムアウト 12秒）を監視。
- タイムアウト発生時に `signal.raise_signal(signal.SIGINT)` でサーバーをクリーン終了し、数秒後にフェイルセーフでプロセスを確実に強制終了。
- 即時シャットダウン関数（手動終了用）も用意。

#### [MODIFY] [app.py](file:///r:/photo-manager/server/app.py)
- `lifespan` 起動処理内でハートビート監視スレッドを開始。
- API エンドポイントを追加：
  - `POST /api/heartbeat`: 生存確認を受信し時刻を更新。
  - `POST /api/shutdown`: 手動シャットダウン用の即時終了エンドポイント。

---

### 2. フロントエンド (クライアント側)

#### [MODIFY] [app.js](file:///r:/photo-manager/frontend/js/app.js)
- `initHeartbeat()` 関数を追加し、アプリ初期化時（`initializeApp`）に起動。
- 3 秒ごとに `POST /api/heartbeat` を送信。
- タブが非アクティブな状態でもブラウザがタイマーを間引くことを考慮し、余裕を持ったタイムアウト設計（サーバー側12秒）と連携。

---

### 3. ランチャー (起動バッチ)

#### [MODIFY] [start.bat](file:///r:/photo-manager/start.bat)
- Python 検出時に、同階層の `pythonw.exe`（GUI用の非コンソール版 Python）の有無を確認。
- `pythonw.exe` が見つかった場合、`start "" "!PYW_EXE!" run.py` でバックグラウンド起動し、バッチファイル自身は直ちに `exit /b 0` で閉じる。
- `pythonw.exe` が見つからない古い環境では、フォールバックとして従来の `python.exe` 起動を維持。

## 検証計画 (Verification Plan)

### 1. 自動テスト / スクリプト検証
- Python スクリプト単体で `heartbeat.py` を呼び出し、一定時間ハートビートがない場合に正しくプロセス終了シグナルがトリガーされるかを検証。

### 2. 実機・手動検証
1. **起動テスト**:
   - `start.bat` を実行し、黒いコマンドプロンプト画面が瞬時に消え、Edge/Chrome のアプリウィンドウのみが立ち上がることを確認。
2. **動作中確認**:
   - ブラウザの DevTools ネットワークタブで、3秒ごとに `/api/heartbeat` が正常（200 OK）に送信されていることを確認。
3. **自動停止テスト**:
   - アプリウィンドウ（ブラウザ）を閉じる。
   - タスクマネージャーまたはコマンド等で、約12秒後に `pythonw.exe` プロセスが自動で消滅（正常終了）することを確認。
