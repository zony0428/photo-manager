# Photo Manager - 4つの設計原則（4本の柱）と機能体系

本ドキュメントは、Photo Manager のすべての機能設計・UI/UX判断・ドキュメント執筆（`README.md` や `note` 連載記事等）の根幹をなす **「4つの設計原則（4本の柱）」** を定義したコア・ナレッジである。

機能は単体で存在するのではなく、すべて以下の4つの柱のいずれか（または複数）を実現するために存在する。今後新たな機能を追加・改修する際や、外部向けにアプリの特徴を説明する際は、常にこの4本の柱を基準とすること。

---

## 1. 4つの設計原則（4本の柱）

1. **保存先に縛られない、簡単で自由な分類と検索。**
2. **元データは汚さず壊さず。でも、見るだけでは終わらない。**
3. **作業を邪魔しない、Look&Feel。**
4. **クラウドには頼らない。でもポータブル。**

---

## 2. 各柱の背景思想（Why）と実現している機能・仕組み（How / What）

### 柱1：保存先に縛られない、簡単で自由な分類と検索。

#### 背景思想（何を考えて作っているか）
写真は年数とともに内蔵ドライブや外付けSSDに分散していくが、管理ソフト側の都合でフォルダ構造を作り直したり、専用の保存場所へまとめ直したりするのは負担になる。保存場所やフォルダ分けは普段使っている形のままにしておき、その上からタグや撮影情報を使って、フォルダやドライブの垣根を意識せずに自由な切り口で束ねたり引き算したりできることを目指している。

#### 実現している仕組み・機能
- **既存フォルダ階層の維持と複数ドライブ横断管理**:
  - 写真を専用フォルダへ強制インポートせず、PC内蔵ドライブや複数の外付けドライブにある既存のフォルダ階層をそのまま維持して横断閲覧・検索。
- **階層タグ・機材ツリーの包含 `[+]`・除外 `[-]` 検索（同親OR・異親AND）**:
  - タグ（階層化アルバム）や「カメラボディ ＞ レンズ」のツリーで、左クリックで包含 `[+]`、右クリックで除外 `[-]` を指定可能。
  - 最上位の親グループが同じ子タグ同士は「または（OR）」、異なる親グループ間は「かつ（AND）」で自動結合。
  - 大まかに選んだ中から不要な条件を `[-]` で引き算したり、「イベントタグは付けたが被写体タグを付け忘れている写真（打ち漏れ）」をあぶり出したりする操作が直感的に行える。
- **自然文フィルタフッターバーとインラインポップオーバー**:
  - 絞り込み中は画面下部にフローティングの自然文フィルタバー（`#filterFooterBar`）が現れ、現在の条件を自然な日本語文として表示。
  - 条件ピルをクリックするとその場で同じ親を持つ子タグの追加・除外や「全年の同じ月（例：歴代の4月すべて）」への一括切り替えが可能。
- **折りたたみ時の道標（トレイル）表示**:
  - 親階層を閉じているときでも、子項目でフィルタが有効な場合は破線枠と件数バッジ（`+1` / `-1`）で適用箇所を明示。
- **多軸フィルタ・EXIFマルチソート・フィルタプリセット**:
  - 撮影年月、場所（国 ＞ 都道府県 ＞ 市区町村の自動階層）、12色カラーパレット、ファイル種別（RAW / JPEGのみ / RAW+JPGペア / 調整済 / XMPあり）、4段階評価（優 / 良 / 可 / 棄）の組み合わせ検索。
  - 撮影日時、評価、ファイル名（自然順）、サイズに加え、焦点距離・F値・シャッター速度・ISO感度での並び替えに対応。よく使う検索条件は「フィルタプリセット」として保存・呼び出し可能。
- **撮影傾向を振り返る「ラボ」と地図機能**:
  - 47都道府県の撮影白地図・撮影密度ヒートマップ・日付ごとの移動軌跡（さんぽ軌跡）。
  - 高評価（優・良）の割合から相性の良いレンズや得意な焦点距離・F値・時間帯を集計する「勝ちレンズ・得意設定カルテ」。
  - 撮影日時とGPSから太陽高度を計算するマジックアワー・ブルーアワー・夜景抽出、低速シャッターの手ブレ注意抽出、過去の同月日を振り返る「歴代の今日」、未整理フォルダをランダムに開く「ガチャ」。

### 柱2：元データは汚さず壊さず。でも、見るだけでは終わらない。

#### 背景思想（何を考えて作っているか）
大切な原本ファイル（RAWやJPEG）がソフトの都合で書き換えられたり、写真フォルダの中に管理用の隠しファイルやサイドカーファイルが勝手に作られたりするのは避けたい。一方で、ただ眺めるだけのビューアでは、選別後のちょっとした傾き補正やトリミング、時計ズレの修正、書き出しのたびに別ソフトを開く手間が残る。「元ファイルと写真フォルダには1バイトも触れない」という一線を厳守したまま、選別から調整・書き出し・必要なときのファイル整理までをひとつながりで行えるようにしている。

#### 実現している仕組み・機能
- **元ファイル・元フォルダへの書き込みゼロ**:
  - 回転、調整、タグ付け、日時補正、「棄（ボツ）」の評価を行っても、元の写真ファイル（RAW / JPEG / XMP 等）は1バイトも変更・移動・削除しない。
  - 写真フォルダの中に管理用の隠しファイルやサイドカーファイルを生成することも一切なく、すべての操作記録はアプリ内のデータベース（`cache/library.db`）1箇所にのみ保存。アプリが合わなければ Photo Manager のフォルダごとゴミ箱に捨てるだけで元の環境がそのまま残る。
- **非破壊の回転・傾き・トリミング・トーン調整**:
  - 90°単位の回転、水平線の微小角度補正（±45°）、アスペクト比固定トリミング、明るさ・コントラスト・彩度の調整（リアルタイムRGB・輝度ヒストグラム連動）をすべて非破壊で記録。
  - 調整前後のワンタッチ比較（Before / After ホールド）や、調整値をコピーして複数写真へ一括ペーストする機能に対応。
- **撮影日時の非破壊シフト補正とスマホGPS引き継ぎ**:
  - カメラの内蔵時計ズレや海外旅行の時差を、日・時間・分・秒のオフセット指定で一括非破壊補正（元のEXIF日時も保持され、いつでもワンクリックで復元可能）。
  - GPSを持たないカメラの写真に対し、前後1時間以内（±60分）にスマホ等で撮った写真からGPS位置情報を非破壊で引き継ぐ機能。
- **既存XMPサイドカーの非破壊読み取り連携**:
  - Lightroom や Adobe Camera Raw 等の現像ソフトが既に出力した `.xmp` / `.pp3` / `.dop` が同じフォルダにある場合、それらを書き換えずに読み取り、右インスペクタの「XMPプレビュー」を押している間だけ調整結果を反映して比較可能。
  - サイドカー内の評価や階層キーワードを、既存タグと混ざらない `XMP/...` 階層へ安全に取り込む機能。
- **用途に合わせた書き出し**:
  - 非破壊調整の焼き込み・リサイズ・撮影順の連番リネーム・EXIF消去・オプションの `.xmp` 出力を一括で行う「スマート・テイクアウト」。
  - 選択した写真を赤鉛筆マークやA4印刷に対応した暗室コンタクトシート風の単一HTMLとして出力する「ベタ焼きHTML」出力。
  - 拡大表示や一覧から画像を直接クリップボードへコピー（`Ctrl+C`）し、SNSや記事執筆画面へそのまま貼り付け可能。
- **必要なときだけ実ファイルを整理できる内部ストレージ（`storage/`）**:
  - 実ファイルごと整理したい写真だけをアプリ内の `storage/` フォルダへコピーして取り込めば、付随するペアのRAWファイルや `.xmp` サイドカーを自動追従させながら、サブフォルダ整理（D&D移動）や一括連番リネーム（`F2`）を実行可能。

### 柱3：作業を邪魔しない、Look&Feel。

#### 背景思想（何を考えて作っているか）
何百枚・何千枚という写真を見比べて選別するとき、色付きのアイコンや主張の強い枠線、RAW読み込みの待ち時間、あるいはちょっとしたクリックミスでタグ階層が崩れてしまうような挙動は、作業の集中を削いでしまう。画面は写真の色彩と階調が素直に見えるよう静かに保ち、キーボードと最小限の視線移動だけでテンポよく選別を続けられる操作感を重視している。

#### 実現している仕組み・機能
- **写真が主役になる静かな画面設計**:
  - カラフルな絵文字や強い装飾を抑えた単色細線アイコンと落ち着いた配色。
  - 明るい「和紙（Washi）」テーマと暗室のように落ち着いた「夜墨（Urusi）」テーマ、および画面全体の「日本語 / 英語（`JP` / `EN`）」表示をワンクリックでリアルタイム切り替え。
- **3つの一覧レイアウトとパネル開閉**:
  - 標準グリッド、縦横比を保って並べる「びっしり表示（Masonry）」、ポジフィルム枠のように余白をとる「マウント表示（Slide Mount）」の3モード。
  - `I` キーでサムネイル上の文字情報を消すクリーン表示、左右パネルの折りたたみとオーバーレイ展開、右インスペクタでの見切れのない 4:3 プレビュー＆クイックEXIF常時表示。
- **Foveon（`X3F`）や各社RAWデータの軽快な表示**:
  - SIGMA Foveon（`X3F`）、Panasonic（`RW2`）、Canon（`CR2` / `CR3`）、Nikon（`NEF`）、Sony（`ARW`）、Olympus（`ORF`）、Fujifilm（`RAF`）、Pentax（`PEF`）、`DNG` 等に対応。
  - 重いRAW現像処理を行わずファイル内部の埋め込みプレビューを優先抽出（非対応形式のみLibRawへフォールバック）することで、メーカー固有の色味のまま現像処理を待たずに軽快にフルサイズ閲覧。
- **連写・ブラケットを束ねるスマートスタック**:
  - 連写、露出ブラケット（AEB）、RAW+JPGペア、重複写真を自動で1つの束にまとめて一覧の見通しを維持。
  - 拡大表示中は `↑` `↓` キーで束の中のコマをパラパラ漫画のように切り替え、上部の「代表」ボタンで表紙カットを変更可能。
- **片手4段階レーティングと2枚比較（Duel）**:
  - 数字キー（`1`: 優 / `2`: 良 / `3`: 棄 / `0`: 可）だけで片手選別ができ、「棄」にした写真は確認ダイアログなしで即座に一覧から隠れて次の写真へ自動でフォーカス移動。
  - 迷う2枚は `V` キーで左右に並べ、同期ズーム・パンと2枚同時ヒストグラム比較（`H` キー）を行いながら、`W` キーで良い方を残していく勝ち抜き選別が可能。
- **日常操作と構造編集の分離・自然順ソート**:
  - 普段のタグ付けは右インスペクタと右クリックメニューに限定し、タグの階層移動・リネーム・削除は「設定」内の専用「タグツリーエディタ」に分離することで、選別中の誤ドラッグ等による事故を防止。
  - すべてのツリーで数字を含む名前が自然に並ぶ自然順ソート（`2` の次に `10` が来る）を採用し、左メニューと右インスペクタのタグ一覧はそれぞれ独立して「名前順 / 枚数順」を切り替え可能。

### 柱4：クラウドには頼らない。でもポータブル。

#### 背景思想（何を考えて作っているか）
個人の写真ライブラリを外部のクラウドに預けっぱなしにしたり、PCを買い替えるたびに環境構築やデータベースの移行で苦労したりしたくない、という思いからスタートしている。すべての処理をインターネット接続なしのローカル環境で完結させつつ、フォルダごと外付けSSDやUSBメモリに入れて持ち歩けば、どのPCでも、さらには外出先のスマートフォンでも自分のライブラリをそのまま扱える形にしている。

#### 実現している仕組み・機能
- **外部送信ゼロのローカル完結動作**:
  - 写真データの外部送信や外部CDN通信は一切行わない（Webフォントや地図ライブラリ Leaflet もローカル同梱。地図の背景タイルを表示するときのみ OpenStreetMap へ接続）。
  - AIによる自動タグ付け（CLIP ONNX推論）や、GPS座標からの撮影地（国・都道府県・市区町村）のオフライン逆ジオコーディングもすべて手元のPC内で完結。
- **インストール不要・USBメモリからそのまま起動**:
  - ポータブルPython実行環境（`python/`）とSQLiteデータベース（`cache/library.db`）が単一フォルダ内にまとまっているため、Python未導入のPCでも外付けSSDやUSBメモリから `PhotoManager.exe` をダブルクリックするだけで起動。
  - アップデートも軽量な差分ZIP（`PhotoManager_vX.X.Xdiff.zip`）を既存フォルダへ上書きするだけで完了。
- **ドライブレター変動への自動追従と未接続時オフライン閲覧**:
  - ドライブ固有のボリュームシリアル番号（VSN）を記録するため、別PCへ繋ぎ替えてドライブレター（`E:\` → `F:\` 等）が変わってもリンク切れを起こさず自動追従。
  - 外付けドライブを外している状態でも、`cache/library.db` 内のWebPサムネイルとメタデータだけで写真の閲覧・検索・タグ付け・評価付けを継続可能。
- **スマートフォンでのWi-Fi・完全オフライン選別と差分同期**:
  - 自宅Wi-Fi経由（QRコードのワンタイムトークン認証・30分無通信で自動停止）、またはUSBメモリ内の `PhotoManager_Mobile.html` と `cache/library.db` をスマホのブラウザ（WebAssembly / `sql.js`）で直接読み込む完全オフライン方式に対応。外出先でもスマホで選別・タグ付けを行い、あとからPCへ安全に差分同期可能。

## 3. 対外ドキュメント（`README.md` / `note` 記事等）の文体・編集原則

Photo Manager の特徴や機能を文章化する際は、「3. 作業を邪魔しない、Look&Feel。」の精神を文章にも適用し、以下のルールを厳守する。

1. **感嘆符（`!` / `！`）の全面禁止**:
   - 宣伝文句のようなテンション（「〜できます！」「〜を実現！」）は一切使わず、落ち着いた句点（`。`）で終える。
2. **カラフルな絵文字の禁止**:
   - 見出しや箇条書きに派手な絵文字（🚀, ✨, 💡, 📁 等）を並べない。
3. **過度な装飾（太字・斜体の壁）の回避**:
   - 箇条書きの1項目が長くなりすぎないよう端的に切り、太字（`**`）や斜体だらけで視線が散るのを防ぐ。
4. **他ソフト批判・誇大広告ワードの禁止**:
   - 特定の他社ソフトを貶める表現や、「爆速」「究極」「プロ仕様」「革命的」といった誇張表現は使わない。
5. **`README.md` と `note` の役割分担**:
   - **`README.md`**：上記4本の柱を見出しとし、各見出し直下に「何を考えて作ったか（2〜3文のリード文）」＋「それを実現している機能（簡潔な箇条書き）」を配置して全体像がひと目で伝わるようにする。
   - **`note` 記事**：それぞれの柱や機能が生まれた背景ストーリー、試行錯誤、具体的な使いこなしを掘り下げて展開する。
