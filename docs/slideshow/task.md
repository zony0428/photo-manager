## 3. スライドショー制御ロジック
- [x] `frontend/js/slideshow.js` を新規作成
  - ダブルバッファ先行ロード（次スライドのプリロード & フェード切替）
  - 公開API: `startSlideshow(photos, startIndex = 0, title = '')`
  - 公開API: `closeSlideshow()`
  - スライド送り/戻し: `nextSlide()`, `prevSlide()`
  - アニメーション付きプログレスバー (`requestAnimationFrame`)
  - キーボードショートカット:
    - Space: 一時停止 / 再生
    - 矢印右 / PageDown: 次の写真
    - 矢印左 / PageUp: 前の写真
    - S: シャッフル再生切替
    - I: Exif情報表示切替
    - F: 全画面モード切替
    - Escape: スライドショー終了
  - ブラウザ Fullscreen API 連動
  - 3秒アイドル自動非表示タイマー連動
