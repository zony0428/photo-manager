# 確認手順書 (Walkthrough): フルスクリーンスライドショー機能

フルスクリーンスライドショー機能の実装が完了しました。
サーバーを再起動する必要はなく、ブラウザをリロード（`Ctrl + F5`）するだけで即座に体験いただけます。

---

## 1. サーバー起動状態の確認

- **正規起動状態**:
  - `start.bat` 経由で起動した `pythonw.exe` がポート **8088** で正常に稼働しており、タスクトレイに常駐しています。
  - フロントエンド（HTML/CSS/JS）のみの追加・修正のため、**サーバーの再起動は不要**です。
  - エージェントが裏でポート8088を占有するような余分なプロセスは一切起動していません。

---

## 2. 動作確認手順

### Step 1: ブラウザのリロード
アプリのウィンドウで **`Ctrl + F5`**（または `Shift + F5`）を押して、最新の HTML / CSS / JS を読み込みます。

### Step 2: ヘッダーからのスライドショー開始
1. 画面右上のツールバー（ビュー切り替えボタンの左隣）に「**▶ スライドショー**」ボタンが追加されています。
2. クリックすると、現在一覧に表示されている写真群でスライドショーがフルスクリーンで開始されます。

### Step 3: スライドショーの操作と鑑賞
- **自動再生 & プログレスバー**:
  - 画面上端に細いアクセントカラーのプログレスバーが伸び、次の写真への残り時間が表示されます。
  - 次の写真への切り替えは、ダブルバッファ構造により黒画面を挟まず滑らかにクロスフェードします。
- **コントロールバー（画面下部中央）**:
  - **◀ / ▶**: 前の写真 / 次の写真へ送る
  - **▶ / ⏸**: 一時停止 / 再生（Spaceキーでも操作可能）
  - **3s / 5s / 10s**: 表示インターバル速度の即時切り替え
  - **🔀 (シャッフル)**: ランダム再生のON/OFF（Sキー）
  - **ℹ (Exif情報)**: 画面左下の撮影情報バッジの表示/非表示（Iキー）
  - **⛶ (全画面)**: ブラウザを完全全画面（Fullscreen API）にする（Fキー）
- **左右クリック操作**:
  - 画面の左側をクリックすると前の写真、右側をクリックすると次の写真へ送れます。
- **3秒アイドル自動非表示**:
  - マウス操作を止めて3秒経つと、コントロールバー・ヘッダー・Exifバッジ・マウスカーソルが自然にフェードアウトし、写真だけの純粋な鑑賞画面になります。
  - マウスを動かすと瞬時にコントロール類が復帰します。
- **終了**:
  - 右上の「✕」ボタン、またはキーボードの **`Esc` キー** を押すと元の画面に戻ります。

### Step 4: 「★ セット」からの直接スライドショー再生
1. 左サイドバーの「**★ セット**」タブを開きます。
2. 保存したフィルタセットカードに「**▶ 再生**」ボタンが追加されています。
3. クリックすると、そのセットの条件（フォルダ、日付、タグ、評価等）が即座に適用され、その絞り込み写真群でスライドショーが自動スタートします。

---

## 3. 主なキーボードショートカット一覧

| キー | 動作 |
|---|---|
| `Space` | 一時停止 / 再生 の切り替え |
| `→` / `PageDown` | 次の写真へ |
| `←` / `PageUp` | 前の写真へ |
| `S` | シャッフル再生のON / OFF |
| `I` | Exif情報バッジの表示 / 非表示 |
| `F` | 全画面表示モードのON / OFF |
| `Esc` | スライドショーを終了して元の一覧に戻る |
