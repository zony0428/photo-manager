# 実装計画: フルスクリーンスライドショービューアの実装

Picasa や Tiar のような直感的で美しい写真鑑賞体験を提供するフルスクリーンスライドショー機能を実装します。
現在表示中の写真一覧や、保存した「★ フィルタセット」からワンクリックで没入感のあるスライドショーを開始できるようにします。

## 1. ユーザー要求と設計方針

### ユーザー要求
1. 写真一覧からフルスクリーンでのスライドショー再生を行いたい。
2. フィルタセット（日付、タグ、フォルダ等を一括保存したセット）から直接スライドショーを実行したい。
3. サーバー起動・常駐（`start.bat` / タスクトレイ）に影響を与えないよう、慎重に実装・確認を行うこと。

### 設計方針
- **ゼロ・サーバー変更**:
  - 画像取得エンドポイント (`/api/photo/{id}/view`) は既に存在するため、FastAPIサーバーの再起動や変更は不要。
  - フロントエンドのみで完結させることで、既存のタスクトレイ常駐・サーバー動作を一切脅かさない。
- **ダブルバッファリング & プリロード**:
  - スライド切り替え時のチラつきや白飛びを防ぐため、2枚の `<img>` 要素を重ねて先行ロードし、CSSクロスフェード（opacity 0.6s）で滑らかに切り替える。
  - 次に表示される写真もバックグラウンドで事前キャッシュする。
- **没入感の高いUI（和モダン調・ミニマル）**:
  - 写真鑑賞を邪魔しないよう、マウスを動かさずに3秒経過すると操作UIおよびマウスカーソルを自動フェードアウト。
  - 半透明グラスモーフィズムによるフローティングコントロールバー、上部ヘッダー、Exifオーバーレイバッジ。
- **操作性**:
  - キーボード（Space, 矢印, S, I, F, Esc）
  - 画面左右のクリックエリア（◀ / ▶）
  - 再生速度（3秒 / 5秒 / 10秒）のリアルタイム切替
  - アニメーション付きプログレスバーによる残り時間の視覚化

## 3. 実装詳細

### A. フルスクリーンモーダル構造 (`frontend/index.html`)
- `#slideshowProgressBar`: スライド表示の残り時間を上部に表示
- `#slideshowHeaderBar`: 絞り込みタイトル（例：「★ 2024夏旅行」）、枚数（`1 / 45`）、閉じるボタン
- `#slideshowStage`: 画像A (`#slideshowImgA`) と画像B (`#slideshowImgB`) を重ねた表示エリア
- `#slideshowHitboxLeft`, `#slideshowHitboxRight`: 画面左右のクリッカブルエリア
- `#slideshowExifBadge`: 左下に撮影日、カメラ、露出設定、評価を表示
- `#slideshowControls`: 前へ、再生/一時停止、次へ、速度切替(3s/5s/10s)、シャッフル、Exif切替、全画面切替

### B. スタイル設計 (`frontend/css/style.css`)
- 背景: `#000000`、最前面 (`z-index: 99999`)
- `.slideshow-img`: `object-fit: contain`、`opacity: 0`、`transition: opacity 0.6s cubic-bezier(0.4, 0, 0.2, 1)`
- `.slideshow-modal.idle`: `cursor: none`、ヘッダー/コントロールバー/Exifバッジ/矢印を `opacity: 0` & `pointer-events: none`

### C. コントローラーロジック (`frontend/js/slideshow.js`)
- `startSlideshow(photos, startIndex, title)`: 外部から呼び出し可能なエントリーポイント
- `renderCurrentSlide()`: 次スロットに画像をプリロードしてロード完了後にクロスフェード
- `startProgressBarAnimation()`: `requestAnimationFrame` で残り時間を毎フレーム滑らかに計算して描画
- `resetIdleTimer()`: マウス移動・キー入力検知で3秒タイマーをリセット

### D. フィルタセット連動 (`frontend/js/presets.js`)
- 各セットカードの「▶ 再生」ボタンで `applyFilterPreset(p)` 実行後、`window.startSlideshow(state.photos, 0, '★ セット名')` を呼び出す。

## 4. サーバー起動・動作確認手順

1. **サーバー状態の確認**:
   - `pythonw.exe` がタスクトレイに常駐していることを確認（ポート8088）。
   - バックグラウンドで勝手にプロセスを立ち上げない。
2. **ブラウザ確認**:
   - ブラウザで `Ctrl + F5`（キャッシュクリア再読込）を行う。
   - ヘッダーの「▶ スライドショー」をクリックしてフルスクリーン表示を確認。
   - Spaceキーで一時停止/再開、矢印キーで送り/戻し、3s/5s/10sボタンで速度変更。
   - 3秒間マウスを止めると操作バーが綺麗に消えることを確認。
   - 「★ セット」タブからセットカードの「▶ 再生」ボタンを押し、セット絞り込みでのスライドショー開始を確認。
