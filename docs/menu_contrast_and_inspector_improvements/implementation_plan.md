# 実装計画書: サムネイル評価バー両テーマ対応・サブメニュー位置改善・AIタグ除外・インスペクタ色合いエキスパンダ化 (v1.88)

## 1. 概要
本改修では以下の4つのUI・操作性改善を一体的に実施し、Photo Manager の品質を洗練させます：
1. **サムネイルホバー時の評価バー (`.card-rating-bar`) の両テーマ（和紙・夜墨）対応**: 和紙モードでの黒固定表示を解消し、高コントラストな和紙スタイルを新設。
2. **右クリックメニューのサブメニュー位置・操作性改善**: サブメニュー垂直位置を1段引き上げ、斜めマウス移動でも閉じないセーフブリッジを新設。
3. **「タグを付ける」の既存タグ選択からAIタグを除外**: フローティングポップオーバーおよび右クリックサブメニューで手動タグのみを抽出。
4. **インスペクタの色合いセクションのエキスパンダ化**: 左ペイン同様にデフォルト閉じのエキスパンダとし、付与数バッジを配置。

---

## 2. 変更詳細

### (1) サムネイル評価バー (`frontend/css/style.css`)
- `.card-rating-bar`:
  - 和紙モード: 背景 `rgba(251, 249, 244, 0.96)`、枠線 `1px solid rgba(42, 41, 38, 0.2)`、影 `0 4px 12px rgba(42, 41, 38, 0.15)`
  - 優: `#b45309`、良: `#c2410c`、棄: `#4b5563`
  - 夜墨モード (`[data-theme="sumi"]`): 背景 `rgba(24, 28, 36, 0.96)`、枠線 `1px solid rgba(255, 255, 255, 0.18)`、影 `0 4px 14px rgba(0, 0, 0, 0.6)`
  - 優: `#e8b828`、良: `#ff6b4a`、棄: `#9ca3af`

### (2) コンテキストサブメニューの操作性改善 (`frontend/css/style.css`)
- `.context-submenu`:
  - `top: -34px;`（親アイテムの高さ分上へシフト。入力フォームをまたいでタグ一覧1行目へ自然にマウスが進入可能）
  - `margin-left: 0;`（隙間をゼロ化）
  - `::before` 疑似要素（幅14px、左-12px）で透明なマウスセーフガードを設置し、親アイテムからサブメニューへ斜めに動かしても `:hover` が途切れないようにする。

### (3) AIタグ除外 (`frontend/js/selection.js`)
- `renderFloatingTagTree()` および `renderContextTagSubmenu()` 内で:
  `const manualTags = (state.availableTags || []).filter(t => t.source !== 'ai');`
  手動タグ（`t.source !== 'ai'`）のみを `buildTagTree()` に渡す。

### (4) インスペクタ色合いセクションのエキスパンダ化 (`frontend/index.html`, `frontend/js/inspector.js`, `frontend/css/style.css`)
- 単一写真側: `.inspector-color-palette-block` をエキスパンダヘッダー（矢印・タイトル・選択数バッジ）とボディ（デフォルト非表示）に再構成。
- 複数写真（一括）側: `.inspector-batch-color-palette-block` も同様にエキスパンダ化。
- `inspector.js` に開閉トグル処理を追加。

## 3. 検証方針
- 和紙・夜墨双方で写真カードをホバーし、評価バーが背景に応じた美しいコントラストで表示されるか確認。
- 写真を右クリックし、「タグを付ける ＞」から右へマウスをスライドして、サブメニューが閉じずにスムーズにタグを選べるか確認。
- フローティングバーの「タグを付ける」ポップオーバーおよび右クリック「タグ」サブメニューで、AIタグが表示されず手動タグのみが並んでいるか確認。
- インスペクタの色合いセクションが初期状態で閉じており、クリックで開閉できるか、色選択時にバッジが更新されるか確認。
