# 変更内容の確認 (Walkthrough): 左ペイン（サイドバー）の表示・非表示トグル機能 (v1.71)

## 1. 改修概要

ユーザー様からの「**左ペインを非表示にも出来るように、、、はムリ？**」というご要望にお応えし、右ペイン（詳細インスペクタ）と同様に、**ワンクリックまたはキーボードショートカットで左サイドバー全体を瞬時に非表示／再表示できる機能**を実装いたしました。

### 特徴とこだわり
1. **ヘッダーボタン（左上）**:
   - 上部ヘッダー左側（ロゴのすぐ右、テーマ切替の左）に「**サイドバー**」トグルボタン（アイコン付き）を新設。
   - 表示中は朱色（`--accent-primary`）でアクティブ点灯し、非表示時は消灯します。
2. **サイドバー内折りたたみボタン（上部バー）**:
   - サイドバー上部バー（`sidebar-top-bar`）の右端に「◀」ボタンを配置。サイドバー閲覧中にもワンクリックで素早く折りたたむことができます。
3. **キーボードショートカット**:
   - 通常画面で **`[`** キー または **`B`** キー（大文字・小文字両対応、および **`Ctrl + B`**）を押すだけで、一瞬で表示・非表示が切り替わります。
4. **領域の最大化とハンドルの連動**:
   - 左サイドバーを非表示にすると、境界線（リサイズハンドル）も連動して消え、中央の写真グリッドが**画面左端いっぱいまでスムーズに広がり**、広大な鑑賞・選別スペースが得られます。
   - ウィンドウリサイズイベントが自動発火するため、仮想スクロールやMasonry（びっしり敷き詰め）レイアウトも一瞬で新しい幅に最適再計算されます。
5. **幅と開閉状態の自動保存・完全復元**:
   - 再表示した際は、ユーザー様が直前にドラッグ調整していたお好みの幅のまますぐに復元されます。
   - 開閉状態（開いているか閉じているか）はブラウザの `localStorage`（キー: `pm_sidebar_open`）に自動保存され、リロード後や次回起動時も状態が引き継がれます。

- `keydown` イベントリスナーに `[` / `B` / `Ctrl+B` によるトグル処理を追加。

## 3. 動作確認ガイド（ユーザー様向け）

ブラウザ上で以下の点をご確認いただけます：

1. **ヘッダーボタンでの開閉**:
   - アプリをブラウザで開き（または `F5` / `Ctrl+F5` でリロード）、ヘッダーのバージョン表記が **v1.71** になっていることを確認。
   - ヘッダー左側の **「サイドバー」** ボタンをクリック。
   - 左サイドバーが瞬時に消え、中央の写真グリッドが画面左端まで広がることを確認。
   - もう一度クリックすると、以前設定した幅のまま左サイドバーが再表示されることを確認。

2. **サイドバー上部「◀」ボタンでの折りたたみ**:
   - サイドバーが開いている状態で、上部バー（「フィルタ全解除」の右隣）にある **「◀」ボタン** をクリック。
   - サイドバーが折りたたまれることを確認。

3. **キーボードショートカットでの開閉**:
   - キーボードの **`[`**（大括弧）または **`B`**（または **`Ctrl + B`**）を押す。
   - 片手で瞬時に開閉がトグルすることを確認。

4. **状態の保持**:
   - サイドバーを非表示にした状態でブラウザをリロード（`F5`）しても、非表示状態が維持されていること。
   - 表示した状態でリロードしても、表示状態が維持されていること。
