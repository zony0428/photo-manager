## ✨ v2.1.3 の主な修正内容 (What's New in v2.1.3)

### 1. モバイル/タッチ非破壊調整APIの実装・EVスケール統一・トーン/傾き二重掛けバグの解消
- **非破壊調整API（`POST /api/photo/{id}/adjustments`）の追加**: モバイルのサーバー接続モードから露出・コントラスト・彩度・水平傾きを微調整した際、既存の90°回転やクロップ範囲を破壊せずに部分更新・サムネイル再生成する専用エンドポイントを追加。
- **露光量（EV）換算スケールの統一**: モバイル側の `brightness` 換算が `EV × 33.33` となっていた不整合を、PC母艦と同一の **`EV × 10`** およびガンマ計算式（`Math.pow(2.0, ev / 2.2)`）へ完全統一。
- **焼き込み済み画像へのCSSフィルタ二重掛け防止 ＆ 未焼き込み原本/変更差分の正確な視覚反映**: 母艦 `/view` やDBサムネイル（調整焼き込み済み）に対してCSSフィルタ・傾きが二重適用されていた問題を修正。USB直読み原本（未焼き込み）では全量を、サムネイルでは初期焼き込み値からの差分（デルタ）のみをビューア・一覧グリッド・タブレット右ペイン・Duel比較画面へリアルタイム反映。

### 2. Android USB `Loome` 接続時の RAW ファイル埋め込みフルサイズ JPEG 抽出 ＆ SAF 探索キャッシュ高速化
- **RAW 埋め込み JPEG プレビュー高速抽出（`SafUsbManager.kt`）**: USB `Loome` 内の RAW ファイル（`.ARW`, `.CR2`, `.CR3`, `.NEF`, `.ORF`, `.RAF`, `.RW2`, `.DNG` 等）を開いた際、生の RAW バイナリをそのまま WebView に流してデコード失敗していた問題を修正し、JPEG セグメント構造（SOI〜SOS〜EOI）を走査して最大解像度のカメラ内現像 JPEG プレビューを高速抽出して配信。
- **SAF ディレクトリ・ドキュメント URI のオンメモリキャッシュ化**: USB フォルダ内のファイル探索結果をメモリキャッシュし、連続スワイプ時の SAF クエリ負荷を大幅に削減。

### 3. 2枚比較（Duel）・スタック詳細・フィルタ除外スワイプの不具合一掃
- **Duel 比較（`touch_duel.js` / `mobile.js`）**: 3枚以上選択時・3枚以上の連写スタックでの勝ち抜きトーナメント比較（最大12枚）を有効化し、候補写真の Exif サマリー表示と、スタック内サブコマが勝った際の自動表紙昇格を実装。
- **スタック内サブコマのメタデータ・同期キー補完**: スタック内サブコマの調整値・解像度・`content_key` 取得漏れ、および表紙変更時の `stackCountsMap` 更新漏れを修正。
- **フィルタ行の左スワイプ/長押し除外の誤爆防止**: タグ行（`data-tag`）のみで除外（NOT）ジェスチャーが動作するよう制限し、年月・場所・機材行のテキストが除外タグに誤登録されるバグを解消。
- **未焼き込み90°/270°回転時の枠フィット補正**: PC母艦のライトボックス（`lightbox.js`）・2枚比較（`compare.js`）・モバイルビューアで未焼き込み90°/270°回転時に縦横枠を入れ替えて計算し、上下のはみ出しを解消。
