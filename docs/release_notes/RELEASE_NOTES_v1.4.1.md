## 日本語 (Japanese)

### 1. 日英言語切替（`JP` / `EN`）の翻訳網羅性向上（v1.4.1）
- **タグツリー＆タグツリーエディタの英語翻訳対応**: 右インスペクタのオンデマンド子タグ作成ボタン（`+子` ⇄ `+Sub`）、付与状態バッジ（`✓付与済` ⇄ `✓Added`）、ピン留め・ショート名（略称）設定、および「設定 ＞ タグツリーエディタ」内の各種操作ボタン・ツールチップ・トースト通知の英語翻訳を追加しました。
- **アプリ内ヘルプ（`#helpModal`）の日英完全同期**: `v1.4.0` で刷新された下部フッターツールバー（中央3大基本フィルタ）、左サイドバー8セクション（`Binder` / `Folder` / `Tag` / `Place` / `Historia` / `Gear` / `Lab` / `Search`）、専用保管庫 `Loome`、およびスタック代表写真の最高評価自動選出（`優 ＞ 良 ＞ 可 ＞ 棄`）に合わせてアプリ内ヘルプ全タブと英語翻訳辞書を同期しました。

### 2. マニュアル・README・技術ナレッジの最新仕様同期（v1.4.1）
- **操作マニュアル・READMEの更新**: `MANUAL.md`、`README.md`、`README_EN.md`、`README_USB.md`、およびプロジェクト設計ドキュメント一式を最新の `Binder`（条件セット保存専用ページ）および `Loome`（内部・外部ドライブ対応）仕様に統一しました。

## English

### 1. Expanded Bilingual (`JP` / `EN`) UI & Help Coverage (v1.4.1)
- **Tag Tree & Tag Tree Editor Translations**: Added complete English translations for on-demand child tag creation (`+Sub`), applied badges (`✓Added`), tag pinning, mobile short aliases, and all controls, tooltips, and toast notifications in the Tag Tree Editor.
- **In-App Help (`#helpModal`) Synchronization**: Updated all in-app Help tabs and their English translations to reflect the bottom footer toolbar, centered 3-filter bar, 8 sidebar sections (`Binder` / `Folder` / `Tag` / `Place` / `Historia` / `Gear` / `Lab` / `Search`), `Loome` portable storage vault, and automatic highest-rated stack cover selection.

### 2. Documentation & Knowledge Base Alignment (v1.4.1)
- **Manuals & READMEs**: Synchronized `MANUAL.md`, `README.md`, `README_EN.md`, `README_USB.md`, and architecture documentation with the `v1.4.x` `Binder` and `Loome` specifications.
