# スマート・テイクアウト（高機能エクスポート / マーシャリング）実装完了レポート (v2.20)

## 1. 概要 & 達成項目
写真選別・調整後に、**元画像ファイル（RAW/JPEG等）を完全非破壊（1バイトも変更しない）** のまま、回転・クロップ・長辺リサイズ・時系列リネーム・Exifメタデータ制御を一括適用して指定フォルダへ書き出す「**スマート・テイクアウト（収集・マーシャリング）**」を実装しました。

### ユーザー要望への対応状況
- **「Exifについては、撮影条件(SS,F値,ISO感度)、カメラ情報(機種名,レンズ名)、その他全部、を消す/消さないを選べると良いね。(チェックボックスで消す情報を選ぶ。全部オフならExifは全部残す)」**:
  - UI上に「🔒 Exif メタデータの消去」セクションを新設。
  - 各チェックボックスで消去対象をピンポイントに指定可能：
    1. `📍 位置情報（GPS座標・ジオタグ）を消去`
    2. `⏱️ 撮影条件（SS・F値・ISO感度・露出・焦点距離）を消去`
    3. `📷 カメラ・機材情報（メーカー・機種・レンズ・シリアル）を消去`
    4. `🗑️ その他すべてのメタデータを消去（完全クリア）`
  - **すべてオフの場合は元のExifを100%完全維持**して出力。
- **「回転、解像度、ファイル名を整えながらテイクアウト」**:
  - **非破壊調整の適用**: Photo Manager 上で行った「90度回転」および「Twitter (X) 風クロップ」を物理反映して出力。
  - **解像度・サイズ**: オリジナル / 4K Ultra HD (長辺 3840px) / フルHD (長辺 1920px) / 軽量 (長辺 1280px) / カスタム長辺px（Lanczosリサンプル、アスペクト比丸め誤差防止）。
  - **ファイル名ルール**: 元名維持 / 撮影日時+元名 / 撮影日時+連番 / 自由接頭辞+連番。同名ファイル衝突防止ナンバリング（`_1`）搭載。
  - **フォーマット & 画質**: JPEG / WebP、品質スライダー（70%〜100%）。
  - **保存先指定**: Windows標準の FolderBrowserDialog 呼び出しによるフォルダ選択、完了後のエクスプローラー自動オープン。

## 3. 検証結果 (実画像テスト)

ポータブルPython（3.11）環境にて実写真（Panasonic DC-S1R、Exif付きJPEG、実解像度 4000x3000クラス）を用いた単体・結合テストスクリプト（`scratch/test_smart_export.py`）を実行し、以下の動作を検証しました：

1. **Case A (すべてOFF)**:
   - 出力画像の Exif 内に `Model="DC-S1R"`, `Make="Panasonic"`, `ExposureTime`, `FNumber`, `ISO` がすべて100%維持されていることを確認。
2. **Case B (撮影条件のみ消去)**:
   - `Model="DC-S1R"` などのカメラ・機材情報は維持。
   - `ExposureTime (0x829A)`, `FNumber (0x829D)`, `ISO (0x8827)` などの撮影パラメータのみがピンポイントで完全に消去されていることを確認。
3. **Case C (カメラ情報のみ消去)**:
   - `Model (0x0110)`, `Make (0x010F)`, `LensModel (0xA434)` が完全に消去されていることを確認。
   - 撮影条件は維持。
4. **Case D (その他すべて消去)**:
   - Exifバイナリが完全消去（None）され、プライベートなメタデータが一切残らないことを確認。
5. **画像変換・リネーム**:
   - 90度回転および10%クロップが反映され、長辺1920px（`1281x1920`）に高画質リサイズされたことを確認。
   - 撮影日時+連番（`20261011_001.jpg`）で整然と保存されたことを確認。
   - 同名重複時に自動で `20261011_001_1.jpg` とナンバリングされ、元画像・既存出力画像の上書き破壊が一切起きないことを確認。

## 4. 操作方法

1. 画面上でテイクアウトしたい写真を1枚以上選択します。
2. 画面下部のフローティング操作バーにある **「📤 テイクアウト」**（または写真の上で右クリック ＞ **「📤 テイクアウト」**）をクリックします。
3. ポップオーバー最上部の **「⚡ スマート・テイクアウト...」** をクリックします。
4. ダイアログ上で、回転・クロップの反映、解像度、ファイル名規則、**Exif消去チェックボックス**、出力先フォルダをお好みに合わせて指定します。
   - ※設定は次回起動時もブラウザ内に自動記憶されます。
5. **「📤 テイクアウト開始」** をクリックすると、高速一括出力が行われ、完了後に保存先フォルダのエクスプローラーが自動でポップアップします。

## 6. v2.18 Exif 5項目排他化 & 撮影秒数順ソートナンバリングの保証

ユーザーからの設計フィードバックに基づき、Exif消去設定の操作性とファイル名採番の整合性を大幅に向上させました：

1. **Exif消去設定の5項目・排他並び順への統一**:
   - `[ ] 🗑️ すべて（Exifメタデータを完全消去）`（**排他項目**）
   - `[ ] 📍 位置情報（GPS座標・ジオタグ）`
   - `[ ] ⏱️ 撮影条件（SS・F値・ISO感度・露出・焦点距離）`
   - `[ ] 📷 カメラ・機材情報（メーカー・機種・レンズ・シリアル）`
   - `[ ] 🏷️ その他（コメント・説明文・著作権・サムネイル等）`
   - **排他連動ロジック (`takeout.js` / `style.css`)**:
     - 「すべて」にチェックを入れると、下の個別4項目は自動的に `disabled`（淡色化・無効）となり、Exif完全消去モードであることが視覚的・操作的に明確になります。
     - 「すべて」がONの状態で個別項目のいずれかにチェックを入れると、「すべて」は自動解除されて個別指定モードへスムーズに切り替わります。
     - すべてOFFの場合は、オリジナルExifメタデータが完全維持されます。
2. **撮影日時の秒数順ソートによる厳密なナンバリング保証 (`server/exporter.py`)**:
   - 画面上での写真選択順序（クリック順や矩形選択の順序）によらず、バックエンド処理の直前で `_photo_sort_key(p) = (p.get("date_taken") or p.get("modified_at") or "", p.get("file_name") or "", p.get("id") or 0)` により**撮影日時の秒単位昇順で確実に事前ソート**してから一括処理を実行。
   - これにより、「撮影日時＋連番」「自由名＋連番」での `_001.jpg`, `_002.jpg`... ナンバリングが、確実に時系列順に並ぶことを保証しました。
   - また「撮影日時＋元名」ルールでも `YYYYMMDD_HHMMSS_元名.jpg` のように秒数まで付与されるため、ファイルマネージャー等でのソートも完全な時系列順に整列します。
3. **総合テスト (`scratch/test_smart_export.py`)**:
   - Case A〜E（全維持、撮影条件消去、カメラ情報消去、完全消去、その他消去）のすべてでテストをパス。
   - 意図的に逆順のタイムスタンプを持つ写真群での秒数順ソート整合性テストにも合格。
