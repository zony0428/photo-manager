# 実装計画: マップ（場所）ツリー機能 ＆ スマホGPS準用（完全ローカル完結）

## 1. 目的とスコープ
写真が持つExif GPS座標（緯度・経度）から、国・都道府県（州）・市区町村（自治体）を自動判定し、データベースに保存する基盤を構築する。
外部Web APIへの過剰依存を避け、USBメモリ等のポータブル環境でも完全オフラインで高速動作する「ローカル逆ジオコーディングDB + 座標キャッシュ」を実装し、左サイドバーにアコーディオンツリーとして配置してワンクリック絞り込みを可能にする。
また、GPSを持たない一眼レフ写真等に対して、同日時に撮影されたスマホ写真のGPSを準用（時間マッチング引き継ぎ）する機能を提供する。

---

## 2. アーキテクチャ設計

### 2.1 DBスキーマ拡張 & ローカル逆ジオコーディング基盤 (Step 1)
1. **`photos` テーブルに3つのカラムを追加**:
   - `country TEXT` : 国名（例: "日本", "アメリカ合衆国"）
   - `state TEXT`   : 都道府県 / 州 / 地域（例: "栃木県", "東京都", "福島県"）
   - `city TEXT`    : 市区町村 / 自治体（例: "宇都宮市", "日光市", "猪苗代町"）
2. **`geo_cache` テーブルの新設**:
   - `lat_round REAL` : 緯度（小数点第2位に丸めた値、約1.1km精度）
   - `lon_round REAL` : 経度（小数点第2位に丸めた値）
   - `country TEXT`, `state TEXT`, `city TEXT`
   - 主キー: `(lat_round, lon_round)`
3. **インデックス**:
   - `idx_photos_location ON photos(country, state, city)`
4. **軽量オープンデータセット (`server/geocoder/data/`)**:
   - `japan_cities.json`: 1,916自治体（86.9KB）
   - `world_cities.json`: 14,495都市（683.3KB）
   - `countries.json`: 250カ国（25.8KB）
   - 合計796KBの超軽量設計。NumPyベクトル距離計算により1回0.05ms以下で探索。

### 2.2 スマホGPS準用機能 (Step 2)
1. **候補検索アルゴリズム**:
   - 対象写真の撮影日時を基準に、±60分以内でGPSを持つ写真を検索。
   - `time_diff_signed` により直前（before）と直後（after）の最近傍候補を分離して返却。
2. **直前/直後スプリット比較ビュー（どっちにする？）**:
   - インスペクター上の「📍 スマホGPS準用」ボタンからモーダルを起動。
   - 前後の写真サムネイル、撮影地名、時間差（分）、カメラ機種を並べて比較選択可能。
3. **一括準用 & 安全リセット**:
   - 複数写真選択時、下部フローティングバーの「📍 GPS準用」から一括準用を実行。
   - 準用写真には `gps_source = 'inferred'` を記録し、「準用」バッジおよび「準用解除」ボタンを提供。

### 2.3 左ペイン「🗺️ 場所」ツリー & グリッド連動 (Step 3)
1. **バックエンドAPI**:
   - `GET /api/locations/tree`: 国 ＞ 都道府県 ＞ 市区町村 の階層集計および「位置情報なし」件数を返却。
   - `GET /api/photos`: `country`, `state`, `city`, `no_location` クエリパラメータによる写真絞り込みに対応。
2. **フロントエンドUI**:
   - `frontend/index.html`: アコーディオンに「🗺️ 場所」セクション（`accordionItem-location`）を追加。
   - `frontend/js/location_tree.js`: ツリー描画、展開/折りたたみ、選択状態管理、グローバルエクスポート。
   - `frontend/js/app.js`: `fetchPhotos()` でのパラメータ付加、`renderFilterChips()` での場所チップ表示、`resetAllFilters()` でのリセット、`initializeApp()` / `refreshAll()` での自動読み込み。
   - `frontend/css/style.css`: 場所ツリー専用の洗練されたCSSスタイル（インデント・フラグ・バッジ・アクティブハイライト）。
