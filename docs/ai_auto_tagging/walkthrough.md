# AI自動タグ付け機能 実装確認・解説 (Walkthrough)

Photo Manager に、ローカル完結・軽量・高速な「AI自動タグ付け」機能を実装しました。
本機能により、フォルダをスキャンするだけで被写体やシーン（風景、人物、動物、乗り物、グルメなど）が自動的に認識され、専用の `[AI]` バッジ付きタグが付与されます。

---

## 1. コア設計とパフォーマンス

| 項目 | 実装内容 | メリット・特徴 |
| :--- | :--- | :--- |
| **推論モデル** | CLIP ViT-B/32 INT8量子化版 (`vision_model_quantized.onnx`, 84.9MB) | 外部GPU不要、CPU推論で **1枚あたり約22ms（毎秒45枚）** の爆速処理 |
| **ゼロショット事前埋め込み** | 日本語36語のテキスト埋め込みを事前計算 (`tags_embeddings.json`, 545KB) | 実行時に重いテキストモデルやTransformersが一切不要・メモリ消費最小 |
| **入力ソース** | データベース内の 320px WebP サムネイルBLOB | RAWファイルや巨大JPEGのデコードが不要で極限まで高速 |
| **手動タグ保護** | `photo_tags` に `source` ('manual' / 'ai') と `confidence` を追加 | 手動タグを絶対に汚さず、AIタグだけの一括削除や個別手動昇格が可能 |
| **ライセンス適合** | ONNX Runtime (MIT License) | GPL/AGPL禁止規約に適合、`LICENSES/` および `NOTICE.txt` 更新済み |

## 2. 実装された新機能とUI

### ① フォルダマネージャ（モーダル）
- **`[☑ 🤖 スキャン後にAI自動タグ付けを行う]` チェックボックス**:
  - 新規フォルダスキャン時、スキャン完了と連動してバックグラウンドで自動AIタグ付けを開始します。
- **登録済みフォルダテーブルの `🤖` ボタン**:
  - 既に登録済みのフォルダに対して、ワンクリックで未タグ写真へのAIタグ付けを開始できます。
- **リアルタイム進捗カード**:
  - タグ付け中の進捗バー、処理枚数、現在のファイル名を表示。「停止」ボタンでいつでも安全に中断可能です。

### ② 写真グリッドカード
- AIによって付与されたタグには、パープル系の専用スタイルと `[AI]` ピルバッジが付与され、ユーザーの手動タグと一目で区別できます。

### ③ 写真詳細インスペクタ & ライトボックス
- **タグ一覧の表示拡張**:
  - 手動タグとAIタグを区別して描画。
  - AIタグには信頼度パーセンテージ（例: `92%`）を表示。
  - **手動昇格ボタン (`✓`)**: クリックすると、そのAIタグが手動タグとして確定（昇格）されます。
  - **個別削除ボタン (`×`)**: 不要なAIタグを即座に削除できます。
- **`[🤖 AIタグ]` 即時実行ボタン**:
  - 表示中の写真1枚に対して、その場でオンデマンド推論を行い、瞬時にAIタグを付与できます。

### ④ 左ペイン（フィルタードロワー「🏷️ タグ」タブ）
- **タグ種別切替セグメントコントロール**:
  - `[すべて] [👤 手動] [🤖 AI]` の3つのボタンで、一覧表示を瞬時に切り替え可能。
  - AIタグには `[AI]` アイコンが付きます。

## 3. 実機検証結果

DBに登録済みの実写真に対して検証スクリプト (`scratch/verify_all.py`) を実行し、以下の正常動作を確認しました：

1. **推論速度**:
   - 15枚のサムネイル推論合計時間: **0.33秒**（**1枚平均 22.0ms**）
2. **認識精度の一例**:
   - 車の写真 (`DSCN0156.JPG`, `F50-COMP3.JPG`) ➜ 「車・ドライブ (0.249)」
   - 昆虫のマクロ写真 (`DSCN0022.JPG`) ➜ 「昆虫 (0.233)」「マクロ・接写 (0.232)」「花・植物 (0.227)」
   - 鉄道の写真 (`DSCN0029.JPG`) ➜ 「電車・鉄道 (0.241)」
   - 集合写真 (`DSC_0180.JPG`) ➜ 「集合写真 (0.226)」「人物 (0.221)」
3. **タグ昇格・手動保護**:
   - AIタグ「車・ドライブ」を手動昇格 (`/api/ai/promote-tag`) ➜ `source='manual', confidence=1.0` に正常昇格。
   - その後、AIタグ一括削除 (`DELETE /api/ai/tags?photo_id=...`) を実行 ➜ AIタグのみ削除され、手動タグは完全に保持されることを確認。

## 4. 変更・追加ファイル一覧

- **AI推論・ワーカー**:
  - `server/ai/__init__.py`: パッケージ初期化
  - `server/ai/tagger.py`: ONNX CLIP推論エンジン・前処理
  - `server/ai/worker.py`: バックグラウンドバッチ処理・進捗管理
- **データベース**:
  - `server/database/schema.py`: `source`, `confidence` カラムマイグレーションおよびインデックス
  - `server/database/tags.py`: AIタグ追加、昇格、AIタグ削除、集計関数の追加
  - `server/database/photos.py`: 写真取得時の `tag_details` 付与
  - `server/database/__init__.py`: エクスポート追加
- **API**:
  - `server/app.py`: `/api/ai/status`, `/api/ai/tag-folder`, `/api/ai/cancel`, `/api/ai/tag-photo/{photo_id}`, `/api/ai/promote-tag`, `/api/ai/tags` エンドポイント追加、および `/api/scan` 連携

  - `frontend/index.html`: フォルダマネージャのAIトグル & 進捗バー、インスペクタ/ライトボックスのAIボタン、タグタブのセグメント切替
  - `frontend/css/style.css`: AIタグ専用パープルスタイル、バッジ、プログレスバー
  - `frontend/js/app.js`: AIタグ描画、昇格ハンドラー、単体/フォルダ単位AIタグ付け、進捗ポーリング
