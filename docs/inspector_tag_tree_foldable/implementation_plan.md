# 実装計画: インスペクタのクイックタグツリー折りたたみ・階層化

## 1. 目的と現状の課題
- **現状**:  
  インスペクタ内の「タグツリーから選ぶ」セクションは、外枠ブロック自体が開閉エキスパンダになっているものの、中のタグツリー（`inspectorQuickTree`, `batchQuickTree`）は全階層のタグがインデント付きで全てフラットに一括展開されて表示されていた。
- **課題**:  
  階層タグの親子フォルダを個別に折りたたむ・展開することができず、タグの件数が増えるとツリーが非常に長くなり、スクロールや目的のタグを探すのが困難になっていた。
- **改修ゴール**:  
  左サイドバーの階層ツリーと同様に、子を持つ親タグ（フォルダノード）に展開・折りたたみ機能（矢印 `▶`/`▼`）を持たせ、デフォルトで折りたたまれた状態（または前回展開した状態を保持）から目的のフォルダを1段階ずつ展開・折りたたみできるようにする。

---

## 2. 変更対象と実装内容

### 1. `frontend/css/style.css`
- `.inspector-tree-node`: ノード全体（親行＋子コンテナ）のコンテナ。
- `.inspector-tree-item`: 親行のレイアウト。
- `.inspector-tree-item-left`: 矢印、アイコン、タグ名の横並びコンテナ（はみ出し省略）。
- `.inspector-tree-children`: 子ノードの格納コンテナ。`.hidden` クラスで `display: none`。
- `.inspector-quick-tree, .batch-quick-tree`: `max-height` を適度な高さ（200px）に微調整。

### 2. `frontend/js/inspector.js` (`renderInspectorQuickTree`)
- 展開状態管理: `state.inspectorQuickTreeExpandedPaths = state.inspectorQuickTreeExpandedPaths || new Set();` を使用して開閉状態をキャッシュ（再描画時も開閉状態がリセットされない）。
- ノード構築:
  - 親ノード（`node.children.size > 0`）:
    - 矢印アイコン（`tree-toggle-btn`、展開時 `▼`、閉時 `▶`（`collapsed`））
    - フォルダアイコン（`📁`）
    - 右端に `+追加` バッジ
    - 矢印またはラベル行クリック: 展開/折りたたみのトグル
    - `+追加` バッジクリック: その親タグ自体（`node.fullPath`）を写真に付与（`e.stopPropagation()`）
  - リーフノード（子なし）:
    - スペーサー（`tree-toggle-spacer`）
    - タグアイコン（`🏷️`）
    - 右端に `+追加` バッジ
    - 行全体クリック: タグ付与（`onSelect(node.fullPath)`）

## 3. 検証計画
1. テスト用の階層タグ（例: `旅行/2026/北海道`, `人物/家族/子供` など）が存在する状態で、インスペクタの「タグツリーから選ぶ」を開く。
2. 親タグ（`旅行`, `人物` など）が折りたたまれた状態で表示され、クリックで子階層がスムーズに展開されることを確認。
3. 矢印を再クリックすると子階層が綺麗に折りたたまれることを確認。
4. 親タグ右側の `+追加` をクリックすると親タグが付与され、開閉状態が勝手にリセットされないことを確認。
5. 複数写真選択時の一括インスペクタ（`batchQuickTree`）でも全く同様に折りたたみ・展開および一括付与ができることを確認。
