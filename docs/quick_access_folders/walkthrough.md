# 修正内容の確認 (Walkthrough): フォルダマネージャへの「よく使う場所」プリセット追加

## 1. 実施した変更の概要
フォルダマネージャ（スキャンモーダル）の左ペイン「フォルダブラウザ」において、これまでドライブ一覧（C:, D: 等）しか表示されず、ピクチャやデスクトップへのアクセスに `C:\Users\...\` という深いパスの知識が必要だった問題を解消しました。
Windowsエクスプローラーと同等の **「よく使う場所（ピクチャ、デスクトップ、ドキュメント、ダウンロード、ユーザーホーム）」** を最上位にプリセット表示し、ワンクリックで主要フォルダへアクセスできるように改修しました。

---

## 2. 変更ファイル詳細

### 1) [server/app.py](file:///r:/photo-manager/server/app.py) (`_get_windows_quick_access` / `api_browse_folders`)
- Windowsレジストリ（`User Shell Folders`）を参照し、OneDrive同期環境（`OneDrive\Pictures`等）や別ドライブへの移動設定を完全自動検知するロジックを実装。
- 最上位階層（`path` 未指定時）のレスポンスに `quick_access` 配列と `drives` 配列を分けて格納して返却。

### 2) [frontend/js/app.js](file:///r:/photo-manager/frontend/js/app.js) (`loadFolderBrowser`)
- 最上位階層の描画時に：
  1. **⭐ よく使う場所** セクション（ピクチャ、デスクトップ、ドキュメント、ダウンロード、ユーザーホーム）
  2. **💻 PC / ドライブ** セクション（C:, D:, USBドライブ等）
  の2段構成で視覚的に整理して描画。
- 各アイテムのクリックで該当フォルダのサブフォルダ一覧へスムーズに中に入り、右側の「選択」ボタンでスキャンパス欄にワンクリック反映。
- **スマート「上へ」ナビゲーション**: 「よく使う場所（ドキュメントやピクチャ等）」から「⬆ 上へ」を押した際、物理的な親フォルダ（`C:\Users\username` 等）に迷い込まず、自然に「ドライブ・よく使う場所（トップ階層）」に戻るよう判定処理を実装。
- **「🏠 トップ」ボタン**: 深いフォルダ階層にいても一発でトップ階層に復帰できるボタンを新設。

### 3) [frontend/css/style.css](file:///r:/photo-manager/frontend/css/style.css)
- セクション見出し用クラス `.folder-browser-section-title` を追加し、Hinomaru Inkのテーマに合わせた端正なスタイルを適用。

### 4) [frontend/index.html](file:///r:/photo-manager/frontend/index.html)
- フォルダブラウザのヘッダーに「🏠 トップ」ボタンを新設し、初期表示テキストを「ドライブ・よく使う場所」に更新。

## 3. 検証結果
- API 単体テストにより、Windows特殊フォルダ（OneDrive配下のピクチャ、デスクトップ、ドキュメント、ダウンロード、ユーザー）の正確なパスが取得できることを確認済み。
- ピクチャフォルダ指定時のサブフォルダ展開および親フォルダへの復帰動作を確認済み。

---

## 4. ユーザー操作手順
1. アプリヘッダーの「フォルダ管理」ボタンをクリックしてフォルダマネージャを開きます。
2. 左ペインの「フォルダを選択」ツリー最上部に、**「⭐ よく使う場所」** が表示されます。
3. **「🖼️ ピクチャ」や「🖥️ デスクトップ」をクリック** するだけで、即座にそのフォルダ内の写真フォルダ一覧へ移動できます。
4. 「選択」ボタンを押せば、そのフォルダのフルパスが自動的に入力欄にセットされ、そのまま「スキャン開始」ボタンを押せます。
5. 外付けHDDやUSBメモリから取り込みたい場合は、その下の「💻 PC / ドライブ」から選択できます。
