# 実装計画: 評価フィルタ（優・良・可・棄）6パターン化への再設計

## 1. 概要
評価フィルタ（優[2]・良[1]・可[0]・棄[-1]）の選択動作を再設計し、デフォルト（棄以外すべて表示）を含む以下の **6パターンのみ** に遷移する排他・連動ロジックを実装します。
- **パターン 1: 優・良・可** (`[0, 1, 2]`) ※デフォルト基本状態（棄以外すべて）
- **パターン 2: 優と良** (`[1, 2]`)
- **パターン 3: 優だけ** (`[2]`)
- **パターン 4: 良だけ** (`[1]`)
- **パターン 5: 可だけ** (`[0]`) （他と連動せず独立）
- **パターン 6: 棄だけ** (`[-1]`) （他と連動せず独立）

## 3. 改修対象ファイルと変更点
1. **[frontend/js/app.js](file:///r:/photo-manager/frontend/js/app.js)**:
   - `state.ratingFilter`: 初期値を `new Set([0, 1, 2])`（棄以外すべて）に設定。
   - `toggleRatingFilter(rating)`: 6パターン遷移関数を実装。
   - 評価トグルクリックイベントハンドラを `toggleRatingFilter` を使用するように更新。
   - `updateRatingFilterUI()`: ヘッダーおよびサイドバーのボタンの `.active` クラスを同期。
   - `fetchPhotos()`: 選択中の ratings をサーバーへ要求。
   - `updateFilterChips()`: 基本状態（優・良・可）以外の場合にのみ「⭐ 評価: ○○」チップを表示。
   - `resetAllFilters()`: 評価フィルタを `new Set([0, 1, 2])` に復元。
2. **[frontend/index.html](file:///r:/photo-manager/frontend/index.html)**:
   - 初期描画のHTMLにおいて、「優」「良」「可」を `active`、「棄」を通常状態に設定。
3. **[server/database.py](file:///r:/photo-manager/server/database.py)**:
   - `ratings is None` のフォールバックを `[0, 1, 2]` に整合。
