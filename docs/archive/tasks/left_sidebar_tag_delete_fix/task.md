# 左ペイン タグ削除（×ボタン）不具合の修正 タスクリスト

## 状況・課題
- 左サイドバー（左ペイン）の「🏷️ タグ (アルバム)」セクションにおいて、各タグ項目の右端にある「×」削除ボタンをクリックしてもタグの削除が行えない現象が発生している。
- **根本原因**:
  1. **ホバー依存の表示とレイアウトシフト**: `.tag-delete-btn` が初期状態で `display: none` であり、ホバー時のみ `display: inline-block` になる仕様のため、マウスを近づけた瞬間に位置がずれたり、境界付近で一瞬でもホバーが外れるとボタンが消滅（`display: none`）する。
  2. **極小のクリック領域**: ボタンサイズが `16px × 16px` と小さく、マウスクリックミス（downとupの位置ズレ）により親の `.tag-pill-item` にイベントが吸い取られ、削除ではなくタグフィルタ（含む/解除）が発火してしまう。
  3. **イベント伝播の漏れ**: `mousedown` や `pointerdown` が親要素に伝播し、クリック判定が安定しない。
  4. **確認ダイアログ**: ブラウザ標準の `window.confirm()` を使用しているため、Edge/Chrome の `--app` モードでフォーカス外れやダイアログ抑制、背面化のリスクがある。
