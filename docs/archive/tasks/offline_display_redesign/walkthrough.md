# 未接続表示リデザイン ＆ 接続中フィルタ機能

## 背景

Photo Manager はUSBポータブル運用をサポートしており、元ファイルが未接続（ドライブ未マウント等）でもDBサムネイルで閲覧できる「スマートプレビュー」機能を備えている。

従来の未接続表示は `🔌 未接続` テキストバッジをサムネイル右下に配置していたが、以下の問題があった：
- テキストバッジが面積を食い、写真の邪魔になる
- 🔌 絵文字が視覚的に洗練されていない
- 大量の未接続写真があるとグリッドが煩雑になる

## 実施内容

### 1. 未接続表示のデサチュレーション方式への変更

テキストバッジを完全に廃止し、CSSのvisual effectで未接続状態を表現する方式に変更。

#### サムネイルカード
- `.is-offline` クラスをカード要素に付与
- `opacity: 0.6` + `filter: grayscale(35%) brightness(0.88)` で視覚的に区別
- ホバー時に `opacity: 0.85` + `grayscale(10%)` まで復元（インタラクション維持）
- `title` 属性でツールチップ表示（ボリューム名含む詳細情報）

#### ライトボックス
- インラインスタイルのオレンジテキスト表示を廃止
- `.lightbox-offline-pill` ピルバッジに変更（控えめなアンバー色、`プレビュー表示` のみ）

#### 右ペイン（インスペクタ）
- ボリューム情報のアイコンを `🔌`/`💿` → `🔴`（未接続）/`🟢`（接続中）に統一

### 2. 接続中の写真のみ表示フィルタ

- クイックアクセスに「🟢 接続中の写真」ナビアイテムを追加
- トグル式（クリックでON/OFF切替）
- ONのとき `is_offline` な写真をクライアントサイドでフィルタ除外
- 「✕ 絞り込み解除」ボタンおよび「すべての写真」クリックでリセット

## 技術的な設計判断

### なぜクライアントサイドフィルタか
- `is_offline` はAPIレスポンス生成時にディレクトリ単位でキャッシュして算出される動的フラグ
- サーバーサイドでSQLクエリに含める場合、全写真のファイル存在チェックをクエリ前に行う必要があり非効率
- クライアントサイドで `filter()` するだけで十分高速（5000枚上限）

### デサチュレーション方式の利点
- テキスト不要で直感的に「アクセスできない」ことが伝わる
- グリッドが汚れない（大量の未接続写真があっても視覚的にクリーン）
- ホバーで復元するため、写真の内容確認は阻害しない
