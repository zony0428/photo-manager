# 修正内容の確認 (Walkthrough): 評価フィルタ（優・良・可・棄）6パターン化

評価フィルタの選択挙動を再設計し、デフォルト（棄以外すべて表示）を含む **6パターンのみ** に整理・実装しました。
「優と良はOR条件、可と棄は他と連動しない排他」を保ちつつ、アプリ起動時や通常時は「棄以外すべて」が表示され、ワンクリックで「優と良」「優だけ」「良だけ」「可だけ」「棄だけ」に切り替わります。

---

## 6パターンの動作仕様

1. **デフォルト: 優・良・可** (`[0, 1, 2]`)：起動時・リセット時の基本状態（棄以外すべて）
2. **優と良** (`[1, 2]`)：お気に入り写真のみ
3. **優だけ** (`[2]`)
4. **良だけ** (`[1]`)
5. **可だけ** (`[0]`)：独立動作（未選別写真の確認用）
6. **棄だけ** (`[-1]`)：独立動作（削除候補写真の確認用）

## 修正対象ファイルと変更点

1. **[frontend/js/app.js](file:///r:/photo-manager/frontend/js/app.js)**:
   - `state.ratingFilter` の初期値を `new Set([0, 1, 2])`（優・良・可）に設定。
   - `toggleRatingFilter(rating)`: 6パターン遷移関数を実装。
   - ヘッダー・サイドバー両方の評価トグルボタンクリック時に `toggleRatingFilter` を呼び出してUI同期。
   - `fetchPhotos()`: 選択中の評価パラメータを確実にサーバーへ送信。
   - `updateFilterChips()`: 基本状態（優・良・可）以外の場合にのみ「⭐ 評価: ○○」チップを表示し、チップの「✕」で基本状態に復帰。
   - `resetAllFilters()`: すべて解除ボタン時に `new Set([0, 1, 2])` へ復帰。

2. **[frontend/index.html](file:///r:/photo-manager/frontend/index.html)**:
   - クイックアクセス・サイドバーおよびメインヘッダーのトグルボタン初期 `active` クラスを「優」「良」「可」に設定。

3. **[server/database.py](file:///r:/photo-manager/server/database.py)**:
   - `get_photos` 関数で `ratings` 未指定時のデフォルトフォールバックを `[0, 1, 2]` に整合。
