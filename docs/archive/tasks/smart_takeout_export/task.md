# スマート・テイクアウト（高機能エクスポート / マーシャリング）実装タスクリスト

## 概要
Photo Manager に、選択した写真の元ファイルを一切破壊せず、回転・クロップ・リサイズ・リネーム・Exifメタデータ制御（撮影条件・カメラ情報・位置情報等の選択消去）を一括適用して指定フォルダへ書き出す「スマート・テイクアウト」機能を実装する。

## タスク項目

- [x] **1. バックエンド: 画像変換・Exif制御・エクスポートエンジンの設計・実装**
  - [x] `server/exporter.py`（新規モジュール）:
    - [x] 元画像（JPEG/RAW）の読み込み（RAWの場合は埋め込みフルサイズプレビューまたはLibRaw連携）
    - [x] 非破壊回転（90/180/270度）およびクロップ（`crop_x, crop_y, crop_w, crop_h`）の適用
    - [x] 指定長辺（オリジナル / 3840px / 2048px / 1920px / 1280px / カスタム）への高品質リサイズ（Lanczos・丸め誤差防止）
    - [x] Exifメタデータの選択的消去フィルター（Pillow IFD操作）：
      - GPS情報（緯度・経度・高度等）の消去
      - 撮影条件（シャッタースピード、絞りF値、ISO感度、露出補正、焦点距離）の消去
      - カメラ・機材情報（カメラ機種、メーカー、レンズ名、シリアル番号、Software等）の消去
      - その他全メタデータの消去（クリーン化）
