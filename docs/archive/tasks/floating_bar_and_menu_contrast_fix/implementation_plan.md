# 実装計画: フッターバー＆右クリックメニューのコントラスト・日の丸UI両テーマ修正 (v1.87)

## 1. 概要・背景

### 現状の課題
ユーザーから「フッターバーと右クリックのメニュー、日の丸UIにしても色が暗い。コントラストがなくて文字が見えない。それぞれのテーマで確認して修正。」とのクレーム。

### 原因分析
1. **テーマセレクタの不一致**:
   - Hinomaru Ink のテーマ属性は `[data-theme="paper"]`（和紙）と `[data-theme="sumi"]`（夜墨）。
   - しかしポップオーバー等のスタイルで誤って `[data-theme="light"]` が指定されていたため、和紙モードにしてもスタイルが当たらず、黒背景（`rgba(22, 27, 34, ...)`）のままになっていた。
2. **フッターバーのテーマ非対応**:
   - `.selection-floating-bar` の背景が `rgba(22, 27, 34, 0.92)` にハードコードされており、和紙モードでも真っ黒な塊となっていた。
   - `.selection-bar-info` に `color: #f1f5f9 !important`（白固定）が設定されていた。
3. **右クリックメニューの透過度と文字コントラスト**:
   - `.context-menu`, `.context-submenu` の背景が半透明ガラス（`var(--bg-glass)`）で、写真の上に重なると背景と混ざって文字が見えなくなる。
   - メニュー内のタグノード（`.submenu-tag-node`）やフォルダノード（`.submenu-folder-node`）が `color: var(--text-muted)` や `var(--text-dim)` で設定され、薄暗く視認性が悪い。
   - ホバー色が朱墨の世界観と乖離した青系（`rgba(56, 189, 248, ...)`）になっていた。

---

## 2. 改善方針

### A. 和紙モード（`[data-theme="paper"]` / `:root`）
- **フッターバー**:
  - 背景: `rgba(255, 255, 255, 0.98)`（純白和紙・ほぼ不透明）
  - 枠線: `1.5px solid var(--accent-primary, #e14d2a)`（日の丸の朱線）
  - 影: `0 10px 30px rgba(42, 41, 38, 0.18), 0 0 16px rgba(225, 77, 42, 0.12)`
  - 文字色: `#1c1917 !important`（深墨、極めて高い可読性）
  - ボタン: 背景 `#f4efe6`、枠線 `#d6d0c2`、文字色 `#1c1917`（太字 600）
- **ポップオーバー**:
  - 背景: `rgba(251, 249, 244, 0.98)` + 朱色枠線
  - タイトル・入力欄・タグ一覧・フォルダ一覧・評価ボタンの文字色を `#1c1917` に統一
  - 矢印（Caret）も和紙色に完全対応
- **右クリックメニュー**:
  - 背景: `rgba(251, 249, 244, 0.98)` + 朱色枠線
  - ヘッダー文字: `#78716c`（太字 700）
  - メニュー項目文字: `#1c1917`（太字 500）
  - ホバー時: `background: rgba(225, 77, 42, 0.12); color: #e14d2a;`（朱色ハイライト）

### B. 夜墨モード（`[data-theme="sumi"]`）
- **フッターバー**:
  - 背景: `rgba(24, 28, 36, 0.98)`（引き締まった漆黒スレート・高不透明度）
  - 枠線: `1.5px solid var(--accent-primary, #e14d2a)`
  - 影: `0 12px 36px rgba(0, 0, 0, 0.85), 0 0 24px rgba(225, 77, 42, 0.25)`
  - 文字色: `#f8fafc !important`（純白スレート、太字 600）
  - ボタン: 背景 `#2d3542`、枠線 `#4b5563`、文字色 `#f8fafc`（太字 600）
- **ポップオーバー**:
  - 背景: `rgba(24, 28, 36, 0.98)` + 朱色枠線
  - タイトル: `#ffffff`
  - セクションラベル: `#cbd5e1`（暗い色から明るいスレートへ引き上げ）
  - タグ一覧・フォルダ一覧: `#f1f5f9`（くっきり鮮明）
  - 入力欄: 背景 `#111419`、文字色 `#ffffff`、枠線 `#4b5563`
- **右クリックメニュー**:
  - 背景: `rgba(24, 28, 36, 0.98)` + 朱色枠線
  - ヘッダー文字: `#94a3b8`（太字 700）
  - メニュー項目文字: `#f8fafc`（太字 500）
  - ホバー時: `background: rgba(225, 77, 42, 0.2); color: #ff6b4a;`

## 4. 検証手順
1. 和紙（paper）モードでの動作検証:
   - 写真を選択し、フッターバーが純白和紙背景＋朱色ボーダー＋深墨文字でくっきり表示されるか確認。
   - タグ・評価・テイクアウトのポップオーバーを開き、和紙背景・文字がはっきりと読めるか確認。
   - 右クリックメニューを開き、和紙背景＋深墨文字＋朱色ホバーで高コントラストに読めるか確認。
2. 夜墨（sumi）モードでの動作検証:
   - テーマを夜墨に切り替え。
   - フッターバーが漆黒スレート背景＋純白文字で写真の上でも埋もれずくっきり表示されるか確認。
   - ポップオーバーおよび右クリックメニューの文字色が明るく鮮明に読めるか確認。
3. 写真の上での重なりテスト:
   - 明るい写真・暗い写真双方の上でメニューを展開し、透過による文字潰れが一切発生しないことを確認。
