# 修正内容の確認 (Walkthrough): フッターバー＆右クリックメニューのコントラスト・日の丸UI両テーマ最適化 (v1.87)

ユーザー様からの「フッターバーと右クリックのメニュー、日の丸UIにしても色が暗い。コントラストがなくて文字が見えない。それぞれのテーマで確認して修正。」というご要望に基づき、原因の徹底分析と和紙（Paper）・夜墨（Sumi）双方のテーマに完全最適化した高コントラスト日の丸UI改修を実施しました。

---

## 1. 根本原因の特定と改修アプローチ

| 箇所 | 改修前の課題・原因 | v1.87 での解決策 |
|---|---|---|
| **テーマセレクタの乖離** | 以前のCSSでライトモードのスタイルが `[data-theme="light"]` と記述されており、実際の属性である `data-theme="paper"` に一致せず、和紙モードでもダーク用の黒いポップオーバーが強制表示されていた。 | セレクタを `:root, [data-theme="paper"]` と `[data-theme="sumi"]` に統一。和紙モードで確実に明るい和紙背景が適用されるよう修正。 |
| **フッターバーのハードコード** | `.selection-floating-bar` の背景が `rgba(22, 27, 34, 0.92)` にハードコードされ、文字色も `#f1f5f9 !important` で白固定だったため、和紙モードでも真っ黒なバーが表示されていた。 | 和紙モードでは不透明度98%の和紙地色（`rgba(251, 249, 244, 0.98)`）に濃墨色テキスト（`#1c1917`）、夜墨モードでは高不透明度漆黒スレート（`rgba(24, 28, 36, 0.98)`）に純白テキスト（`#f8fafc`）を適用。 |
| **写真透過による文字埋もれ** | 半透明ガラス効果（`backdrop-filter: blur` + 半透明背景）により、背後の写真の明暗パターンが透けて文字のコントラストが著しく低下していた。 | 背景不透明度を **98%** に極大化。写真の上にバーやメニューが重なっても写真の色が文字に干渉せず、常に安定した可読性を確保。 |
| **右クリックメニューの薄暗さ** | `.submenu-tag-node` や `.submenu-folder-node`、ヘッダーに `var(--text-muted)` や `var(--text-dim)` が使われ文字が沈んでいた。またホバー色が朱墨の世界観から浮いた青系水色（`rgba(56, 189, 248)`）だった。 | メニュー項目文字を各テーマのメイン文字色（和紙: `#1c1917` / 夜墨: `#f8fafc`）に引き上げ、ヘッダーも太字化。ホバー色やバッジを日の丸UIの朱色（`#e14d2a` / 夜墨: `#ff6b4a`）に調和。境界線も朱色（1.5px solid #e14d2a）で端正に引き締め。 |
