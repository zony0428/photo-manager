# 評価システムリニューアル: 5段階星 → 4段階（優・良・可・棄）

## 概要

現在の5段階星評価（★1～★5）を、日本語4段階評価（**優・良・可・棄**）に置き換える。
- **可** (rating=0): デフォルト状態。マーキング無し。普通の写真
- **良** (rating=1): マーキングあり。良い写真
- **優** (rating=2): マーキングあり。最も良い写真
- **棄** (rating=-1): 明示的に除外。フィルタで明示しない限り非表示

## User Review Required

> [!IMPORTANT]
> **DB内のratingカラムのマッピング変更**
> 既存データの`rating`値（0～5）は新しい体系に変換が必要です。以下の移行戦略を提案します：
> - 旧 0 → 新 0（可）
> - 旧 1～2 → 新 0（可）
> - 旧 3 → 新 1（良）
> - 旧 4～5 → 新 2（優）
> 
> このマッピングで問題ないですか？ 別のマッピングをご希望の場合はお知らせください。

> [!WARNING]
> **`is_favorite`カラムの扱い**
> 現在 `rating > 0` で `is_favorite = 1` に設定していますが、新体系では `is_favorite` カラムは不要になります。互換性のため一旦残しつつ、新しいロジックでは使用しない方針でよいでしょうか？

## Open Questions

> [!IMPORTANT]
> **サイドバーのフィルタUI**: 現在「お気に入り(★1以上)」と「厳選(★4以上)」がありますが、新体系では以下のようなフィルタに置き換えることを提案します：
> - 🏅 優（最高評価のみ）
> - ⭐ 良以上（良 + 優）
> - 🗑 棄を含む

## UIイメージ

### カードサムネイル上
- **通常時（可）**: 何も表示しない
- **良の場合**: 右上に「良」の一文字を朱印風オーバーレイ
- **優の場合**: 右上に「優」の一文字を金色/朱印風オーバーレイ（より目立つ）
- **棄の場合**: 右上に「棄」を灰色半透明オーバーレイ + サムネイル全体を薄暗く
- **マウスオーバー時**: 右上にフローティングバーが出現、「優」「良」「棄」の3ボタン。現在の評価がハイライト。クリックでトグル（同じものをクリックすると「可」に戻る）

### フィルタバー
- 「最低評価:」のドロップダウン → 4つのトグルボタン/チェックボックス
- `[優] [良] [可] [棄]` — 押されているものだけ表示
- デフォルト: 優・良・可がON、棄がOFF
