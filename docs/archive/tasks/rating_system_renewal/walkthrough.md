# 評価システムリニューアル ウォークスルー

## 概要

5段階星評価（★1～★5）を **4段階評価（優・良・可・棄）** に全面的に置き換えました。

| 評価 | rating値 | 表示 | 説明 |
|------|---------|------|------|
| **優** | `2` | 金色アイコン「優」 | 最も良い写真 |
| **良** | `1` | 朱色アイコン「良」 | 良い写真 |
| **可** | `0` | マーキング無し | 普通の写真（デフォルト） |
| **棄** | `-1` | 灰色アイコン「棄」＋サムネイル薄暗く | 除外対象（デフォルト非表示） |

## 操作方法

### カードサムネイル上
- **マウスオーバー** → 右上に「優」「良」「棄」の3ボタンバーが表示
- **ボタンクリック** → 評価が設定されてアイコンがオーバーレイ表示
- **同じボタンを再クリック** → 「可」に戻る

### キーボードショートカット（ライトボックス内）
- `0` → 可（評価解除）
- `1` → 良
- `2` → 優
- `X` → 棄（トグル）

### フィルタバー
- `[優][良][可][棄]` の各ボタンをクリックでON/OFF
- デフォルトは優・良・可がON（棄は非表示）
