# 実装計画書：ステップ1 UIの交通整理（グチャグチャ感の解消）

段階的な機能拡張に伴い発生していた「新旧機能の重複」「ツールバー・選択バーのボタン過密」「実験的機能や操作導線の分散」を整理し、直感的で迷わないUI配置へ再構築する。

---

## 1. 改修の5つの柱

### ① 「📤 テイクアウト」メニューのスリム化（旧 `take_out` 単純コピー欄の廃止）
- **現状の課題**:
  「📤 テイクアウト」を開くと、「⚡ スマート・テイクアウト」「🎞️ ベタ焼きHTML出力」の下に、旧来の `take_out` フォルダへの単純JPGコピー欄（フォルダ作成フォーム・フォルダを開くボタン・送り先フォルダ一覧）が表示され、機能の意味が重複してメニューが縦に肥大化していた。
- **変更内容**:
  - `frontend/index.html` の右クリックサブメニュー (`#contextImportSubmenu`) および下部フローティングバーポップオーバー (`#floatingImportPopover`) から旧 `take_out` 単純コピー欄を除去し、**「⚡ スマート・テイクアウト...」** と **「🎞️ ベタ焼きHTML出力...」** の2択に集約する（※スマート・テイクアウトのデフォルト出力先は引き続き `take_out` を維持）。
  - `frontend/js/selection.js` のポップオーバー展開時・右クリック表示時の不要な `/api/import/destinations` 通信呼び出しを省き、メニューが0msで即座に開くようにする。

### ② 上部メインヘッダーの整理 ＆「📥 取り込み」ボタンの移設
- **現状の課題**:
  上部ヘッダー右側に「表示切替・ソート群」と「システム・外部連携ボタン群」が区切りなく11個並び、さらに `storage/` へファイルを取り込む「📥 取り込み (`#uploadFilesBtn`)」ボタンがヘッダーの中途半端な位置を占領していた。
- **変更内容**:
  - `#uploadFilesBtn`（`📥 取り込み`）を上部メインヘッダーから外し、左サイドバー **「📁 フォルダ」セクション内のツールバー (`#folderToolbar`)** へコンパクトボタンとして移設する（画面全体へのドラッグ＆ドロップ取り込みはそのまま維持）。
  - 上部ヘッダー右側の「並び替え (`#sortBySelect`)」と「スマホ連携 (`#openMobileModalBtn`)」の間に縦セパレータ (`<div class="toolbar-divider"></div>`) を追加し、「表示コントロール群」と「システム・外部連携群（スマホ連携・設定・ヘルプ・終了）」を視覚的に分離する。

### ③ 左サイドバーの並び順整理 ＆ 実験的機能の「🧪 ラボ」集約
- **現状の課題**:
  実験的機能である「🗾 制覇マップ」ボタンが「🗺️ ジオタグ」と「🧪 ラボ」の両方に重複して存在していた。また、ビジュアルフィルタで絞り込むアプリであるにもかかわらず、「🔍 ファイル名検索」が「🧪 ラボ」より上に配置されていた。
- **変更内容**:
  - 「🗺️ ジオタグ」ツールバー (`#locationToolbar`) にあった `#openLocationMapModalBtn`（`🗾 制覇マップ`）を削除し、実験的・分析的機能はすべて **「🧪 ラボ」セクション** へ一本化する（ラボ内のボタン構成は現状維持）。
  - 左サイドバーのアコーディオン順序を入れ替え、**「🧪 ラボ」をセクション7**、**「🔍 ファイル名検索」をセクション8（最下部）** に配置する。

### ④ 下部フローティング選択バー (`#selectionFloatingBar`) のボタン過密解消
- **現状の課題**:
  写真選択時に下部バーに最大13個のボタンが横一列に並び、特に `🗑️ ジオタグ削除` と `🗑️ 削除（ライブラリ登録解除）` のゴミ箱アイコンが2つ並んで誤操作を誘発していた。
- **変更内容**:
  - 使用頻度が低くメンテナンス性の高い3つの操作：
    1. `🔄 サムネイル更新` (`#floatingRefreshThumbBtn`)
    2. `📍 ジオタグ準用` (`#floatingInferGpsBtn`)
    3. `🗑️ ジオタグ削除` (`#floatingClearGpsBtn`)
    を、新しく設ける **「`⋯ その他`」ボタングループ (`#floatingMoreGroup` / `#floatingMoreBtn` / `#floatingMorePopover`)** の中に格納する。
  - これにより、下部バーのメイン列は主役アクション（タグ・評価・2枚比較・回転・テイクアウト・storage操作・その他・選択解除・削除）のみとなり、視認性と安全性が大幅に向上する。

### ⑤ 右インスペクタ上部へのクイックアクションバー新設 ＆ 重複整理
- **現状の課題**:
  右インスペクタ (`#inspectorPane`) には「✂ 画像調整 (C)」や「⚖️ 2枚比較 (V)」を開くボタンがなく、「📊 ヒストグラム (H)」を開くボタンも「ℹ️ 詳細情報」タブのテーブル中腹までスクロールしないとアクセスできなかった。
- **変更内容**:
  - 右インスペクタのプレビュー枠 (`#inspectorFixedPreview`) の直下に、単一写真表示用のクイックアクションバー (`#inspectorQuickActionsBar`) を新設し、以下のボタンを常設する：
    - **`✂ 調整`** (`#inspectorQuickAdjustBtn` — 画像調整・クロップモーダルを起動)
    - **`📊 波形`** (`#inspectorQuickHistBtn` — RGB・輝度ヒストグラムを開閉し、表示中は `active` 点灯)
    - **`⚖️ 比較`** (`#inspectorQuickCompareBtn` — 2枚並べて比較モードを起動)
    - **`↺`** / **`↻`** (`#inspectorQuickRotateLeftBtn` / `#inspectorQuickRotateRightBtn` — 左90° / 右90°回転)
  - これに伴い、`frontend/js/histogram.js` で「ℹ️ 詳細情報」タブ内に動的挿入していた重複行 (`#inspectorHistMetaRow`) を廃止し、どのタブを開いていてもプレビュー直下から即座に呼び出せるように統一する。

## 2. 変更対象ファイル一覧

- `frontend/index.html`: ヘッダー、左サイドバー、右インスペクタ、下部選択バー、右クリックメニュー、ヘルプモーダルの構造更新
- `frontend/js/selection.js`: 「⋯ その他」ポップオーバー開閉制御、テイクアウトメニューの軽量化
- `frontend/js/inspector.js`: 右インスペクタ上部クイックアクションバーのイベント結線と複数選択時の表示切替
- `frontend/js/histogram.js`: `#inspectorQuickHistBtn` との連動および EXIF タブ内の重複ボタン挿入廃止
- `frontend/js/compare.js`: 下部バーへの「⚖️ 2枚比較 (V)」挿入位置を「⋯ その他」の手前（回転ボタンの隣）へ調整
- `frontend/js/app.js`: `#uploadFilesBtn`（フォルダツールバー内コンパクトボタン）のラベル復元処理の調整
- `frontend/js/i18n.js`: 新設・変更ボタンの日英翻訳キー同期
- `frontend/css/inspector.css` & `frontend/css/selection-menu.css`: インスペクタクイックバーおよび「⋯ その他」ポップオーバーのスタイル定義
- `MANUAL.md` & `docs/knowledge/feature-code-map.md` & `VERSION`: ドキュメントおよび最終更新日時の同期
