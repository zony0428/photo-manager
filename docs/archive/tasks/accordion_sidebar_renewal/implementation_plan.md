# 実装計画書: 左サイドバーのアコーディオン式UI刷新 (v1.56)

## 1. 概要 & 背景
ユーザーからのフィードバックに基づき、左ペインの「90度文字回転によるインデックスタブ＋フローティングドロワー」を廃止し、プロ向け写真編集・管理ツール（Lightroom, Capture One, VS Code 等）で標準的かつ最も洗練された**「アコーディオン式サイドバー（Accordion Sidebar）」**へと抜本的に刷新する。

これにより：
- 不自然な文字回転が完全に撤廃され、正立した美しい日本語・英字（横書き）で快適に一覧・操作できる。
- クイックアクセス、フォルダツリー、タグ一覧、タイムライン等を同一サイドバー内で自在に展開・折りたたみ可能となる。
- ドロワーが中央の写真一覧に被さる・消えるといった煩わしさが解消され、安定したレイアウトを実現する。

### 2.2 セクション構成
1. **上部アクションバー**:
   - `[すべてのフィルタを解除 (リセット)]` ボタン（アクティブなフィルタがあるときは朱色に発光）
   - `[すべて折りたたむ / すべて展開]` トグル
2. **アコーディオン各セクション**:
   - **`quick`**: ⚡ クイックアクセス（全写真、未分類、オンライン、評価フィルタ「優・良・可・棄」）※初期展開
   - **`folder`**: 📁 フォルダツリー（ショートカット、ドライブ、パス直接入力、スキャン進捗）※初期展開
   - **`tags`**: 🏷️ タグ（階層タグツリー、AI自動タグ付け）
   - **`timeline`**: 📅 年月（タイムラインツリー）
   - **`camera`**: 📷 カメラ機種
   - **`presets`**: ★ フィルタプリセット
   - **`search`**: 🔍 ファイル名検索

### 2.3 開閉状態の永続化
- 各セクションの開閉状態（`true` / `false`）を `pm_accordion_state` として JSON 形式で `localStorage` に保存。
- 次回アプリ起動時やリロード時に前回の開閉状態を完全復元。

## 3. 実装ステップ

### ステップ 1: `frontend/index.html` の構造変更
- 旧 `#sidebarIndexTabs` を削除し、`.sidebar` の直下に `.sidebar-header-actions` および `.sidebar-accordion` を配置。
- 既存の各パネル（`tabPanel-quick`, `tabPanel-folder`, `tabPanel-tags` 等）のコンテンツを活かしつつ、それぞれの外側を `<div class="accordion-item" data-section="...">` でラップ。
- 各アイテムに `<div class="accordion-header">`（トグル矢印、アイコン、タイトル、件数バッジ）と `<div class="accordion-body">` を定義。

### ステップ 2: `frontend/css/style.css` のスタイル刷新
- `.sidebar`: 幅 280px、固定幅またはリサイズ対応、`overflow-y: auto`。
- `.accordion-item`: 各セクションの境界線、面取り、Hinomaru Inkデザイン（和紙/夜墨）。
- `.accordion-header`:
  - `cursor: pointer`
  - トグル矢印の滑らかな回転アニメーション（`transform: rotate(90deg)`）
  - ホバー時の上品な背景ハイライト
  - アクティブフィルタが含まれるセクションのヘッダーにインジケータードット表示
- `.accordion-body`:
  - 開閉時のスムーズな表示切替
  - 内部コンテンツ（フォルダツリー、タグツリー等）のパディング最適化

### ステップ 3: `frontend/js/app.js` の制御ロジック刷新
- 旧 `initSidebarTabs` を `initSidebarAccordion` に置き換え。
- クリックによるトグル動作（アコーディオンヘッダークリックで `.is-collapsed` をトグル）。
- 外部API（`window.openSidebarSection(sectionId)`）の提供。
- 空状態ボタン等からのフォルダセクション自動展開処理を連動。

### ステップ 4: 検証と仕上げ
