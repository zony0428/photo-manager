# ウォークスルー: フォルダ自動更新検知・2段階安全確認 & 管理外フォルダ登録確認 (v1.95)

## 1. 概要と背景

ユーザーがアプリ使用中に、左サイドバーのフォルダツリーからフォルダを選択した際のUXを自然で直感的なものへ改善しました。

### ユーザーの着眼点と本質的課題 (v1.95での改善)
- **問題の発生**:
  - DBを削除して再起動した直後など、まだ管理登録されていない未登録フォルダをクリックした際にも、「フォルダの内容が更新された可能性があります（新規追加: X枚）」というダイアログが表示されてしまっていた。
  - これは「更新」ではなく「未登録フォルダの初回アクセス」であるため、ユーザー体験として不自然だった。
- **解決方針 (v1.95)**:
  1. **管理中フォルダの選択時**:
     - すでにスキャン・登録されているフォルダのみ、外部エクスプローラー等での追加・削除を検知して「フォルダの内容が更新された可能性があります」とリフレッシュ確認ダイアログを表示。
  2. **管理外（未登録）フォルダの選択時**:
     - 「更新された可能性があります」は一切表示せず、
     - **「管理外のフォルダです。管理フォルダとして登録しますか？(ファイル数: X枚)」**
     と直感的な登録確認ダイアログを表示。OKで即座にスキャン・管理登録を実行。

## 2. 変更内容一覧

### バックエンド (Python / FastAPI / SQLite)
- **[`server/scanner.py`](../../server/scanner.py)**:
  - `check_folder_diff(folder_path)`:
    - `scan_roots` および `photos` テーブル（直下・配下）を照合し、フォルダが管理対象かどうかの `is_managed: bool` フラグを確実に判定。
    - 管理外フォルダ（`is_managed: False`）の場合は `has_changes: False` とし、誤った更新検知を完全防止。
    - ディスク上の写真ファイル数 `total_disk` を高速カウントして返却。

### フロントエンド (Vanilla HTML / CSS / JS)
- **[`frontend/js/folder_tree.js`](../../frontend/js/folder_tree.js)**:
  - `_ftHandleClick(node)`: `checkAndPromptFolderRefresh(node.path, node.name, node)` に `node` 情報を連携。
- **[`frontend/js/app.js`](../../frontend/js/app.js)**:
  - `checkAndPromptFolderRefresh(folderPath, folderName, node)`:
    - **管理外フォルダの場合**: 「管理外のフォルダです。管理フォルダとして登録しますか？(ファイル数: X枚)」を表示し、OKで `executeScan` を実行して管理追加。
    - **管理フォルダの場合**: 差分がある時のみ、更新確認ダイアログ（第1ダイアログ）およびリンク解除確認ダイアログ（第2ダイアログ）を実行。
- **[`frontend/index.html`](../../frontend/index.html)**:
  - `#helpModal` の選別ワークフロータブに、未登録フォルダ登録確認および管理フォルダ更新検知の解説を反映。

### ドキュメント & バージョン
- **[`VERSION`](../../VERSION)**: `1.94` → `1.95` にカウントアップ。
- **[`MANUAL.md`](../../MANUAL.md)**: フォルダ選択時のスマートアクション仕様を同期更新。

## 3. 検証結果

- **構文チェック**: `py_compile` にて全修正ファイルの正常性を確認。
- **未登録フォルダテスト**:
  - `check_folder_diff('C:\\Windows')`（未登録フォルダ）を実行。
  - `is_managed: False` かつ `has_changes: False` が返り、誤った「更新された可能性があります」ダイアログが出ないことを確認。
  - `total_disk` が正常に取得されることを確認。
