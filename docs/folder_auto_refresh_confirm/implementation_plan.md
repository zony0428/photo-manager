# 実装計画: フォルダ自動更新検知・段階的リフレッシュ確認 & 実体消失写真クイックアクセス

## 1. 概要
ユーザーが接続中のフォルダをブラウズ表示した際に、外部（エクスプローラーやSDカード等）で行われた写真の追加・削除を自動検知し、
勝手に処理を進めるのではなく**ユーザーの同意を得ながら段階的に確認・リフレッシュを行う安全な仕組み**を構築する。
また、「消去確認で残すを選択した写真」や「別フォルダに移動して実体がなくなった写真」がDB内に溜まることを見越して、
**サイドバーのクイックアクセスに「⚠️ 見つからない写真（実体消失）」を追加**し、いつでもワンクリックで確認・一括整理できるようにする。

---

## 2. ユーザー体験（対話フロー）

### 2.1 フォルダ表示時の2段階確認フロー
1. フォルダツリーでフォルダをクリックした際、画面は通常通りキャッシュから即座に表示（0遅延）。
2. 並行してバックグラウンドで `POST /api/folders/check-diff`（所要時間2〜5ms）を呼び出し。
3. **変更なしの場合**: 何もせず終了（ダイアログは一切出ず快適）。
4. **変更ありの場合**:
   - **第1ダイアログ（リフレッシュ確認）**:
     > 📁 **フォルダの更新を検知しました**  
     > フォルダ「`〇〇`」の内容が更新された可能性があります。  
     > ライブラリをリフレッシュ（最新化）しますか？  
     > `[リフレッシュする]` / `[後で]`
   - **キャンセル時**: 何もせず現状のまま。
   - **OK時**:
     - 新規写真のスキャン（差分同期）を実行。
     - 追加があった場合: `「✅ N枚の写真が新しく追加されました」` とトースト通知。
     - もし削除（実体が見つからない写真）がある場合:
       - **第2ダイアログ（消去の再確認）**:
         > 🗑️ **削除された写真の整理確認**  
         > PC上から見つからない写真が **M枚** あります。  
         > ライブラリ（DBの記録・サムネイル）から削除してよろしいですか？  
         > `[記録を削除して整理]` / `[残す（未接続扱い）]`
       - 「削除して整理」時: DBから安全に消去し、グリッドからも除外。
       - 「残す」時: DBの記録を保持（後からクイックアクセスで確認可能）。

### 2.2 クイックアクセス「⚠️ 見つからない写真」
- 左サイドバーの「⚡ クイックアクセス」セクションにナビ項目を追加：
  - `🖼️ すべての写真`
  - `🏷️ 未分類の写真`
  - `🟢 接続中の写真`
  - `⚪ 未接続の写真`
  - `⚠️ 見つからない写真`（実ファイルが消えている写真のみを一覧表示）
- クリックすると、実体パスが消失したレコードだけがグリッドに表示され、写真下部操作バー等から一括削除・確認が可能。

## 3. バックエンド実装詳細

### 3.1 差分チェック関数 `check_folder_diff(folder_path)`
- `os.scandir(folder_path)` により直下の実ファイル（拡張子合致）の `(file_name, size, mtime)` を取得。
- DB `photos` から `directory_path = folder_path` の `(file_name, file_size, file_mtime)` を取得。
- 差分集計:
  - `added`: 実ファイルにあり、DBにない数
  - `deleted`: DBにあり、実ファイルにない数
  - `modified`: サイズまたはmtimeが変更された数
- レスポンス: `{"has_changes": bool, "added": int, "deleted": int, "modified": int}`

### 3.2 消失写真フィルタ `missing_only`
- `get_photos()` に `missing_only: bool = False` を追加。
- `missing_only=True` の場合、接続中ドライブ（または全ドライブ）の登録写真のうち、`os.path.exists(file_path)` が False のもの（またはDB上の消失フラグ）を抽出して返却。

---

## 4. 検証計画
1. フォルダ変更なしでの通常ブラウズ（ダイアログ非表示・爆速維持）
2. 外部エクスプローラーから写真を追加してフォルダ選択 → 第1ダイアログ表示 → OKで取り込み ＆ トースト確認
3. 写真を削除してフォルダ選択 → 第1ダイアログ → 第2ダイアログ（消去確認）→ OKでDB消去、キャンセルで保持
4. クイックアクセス「⚠️ 見つからない写真」の一覧表示と件数バッジの連動確認
