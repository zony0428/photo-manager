📖 Photo Manager 操作マニュアル & ヘルプ

初めての方から応用・スマホ連携まで、目的に合わせて読めるレベル別ガイド
💡 Photo Manager へようこそ — 安心・軽快なローカル写真管理

大量の写真（JPEG / PNG / WebP / HEIC および各社一眼カメラの RAW データ）を、待ち時間ゼロで閲覧・選別・整理できる写真ビューアです。
目的に合わせて上部の 「🟢 Basic編」「🔵 Advance編」「🟣 Mobile & USB編」 タブを切り替えてご覧ください。

🛡️

元写真は絶対に傷つけない（完全非破壊）

アプリ内で写真を回転したり、傾き・明るさを調整したり、「棄（ボツ）」の評価を付けても、パソコン内の元ファイルは1バイトも変更・削除されません。いつでも元の状態に戻せます。

🔒

ネット接続不要（完全オフライン動作）

写真を外部のクラウドへ送信することは一切ありません。AIによる自動タグ付けや撮影場所（県・市区町村）の判定も、すべてお使いのパソコン内部だけで安全に完結します。

⚡

片手でサクサク！4段階の高速選別

数字キーの 1（優）、2（良）、3（棄）、0（可）を押すだけで視線を外さず高速仕分け。「棄」にした写真は一覧から自動で隠れます（いつでも再表示・復活可能）。

🗂️

連写・ブラケット・重複写真を自動で束ねる

連写や露出ブラケット、別フォルダにコピーされた同じ写真も自動で「1つの束（スタック）」に集約。一覧画面が同じ写真で埋め尽くされず、拡大時に ↑ / ↓ キーで瞬時に見比べられます。

✂

傾き・切り抜き・明るさ微調整 ＆ 一括書き出し

斜めの水平線補正（C キー）や露出補正を元ファイル無傷で行い、「📤 スマート・テイクアウト」でリサイズや撮影順の連番リネーム、プライバシー保護（Exif消去）を掛けて別フォルダへ一括出力できます。

📱

USBメモリ持ち歩き ＆ スマホでの片手選別

重たい元写真は自宅に置いたままカタログ（USB）だけを持ち歩けます。さらに自宅Wi-Fi（QRコード）や外出先のUSB直接接続で、スマホの親指操作だけで写真をサクサク選別・同期できます。

🖼️

気分や用途で選べる3つの表示レイアウト

画面上部のツールバーから、ワンクリックで3つの表示モードを切り替えられます。右上の「📜 和紙 ／ 🌙 夜墨」ボタンで明るい画面・暗い画面の切り替えも可能です。

田 グリッド (標準)

正方形の枠に整然と並ぶ標準モード。ファイル名や日付も見やすく、大量の写真を素早く探すのに最適です。

▤ びっしり (Justified)

写真本来の縦横比をそのまま活かし、隙間なく画面いっぱいに敷き詰めるモード。構図や迫力を楽しめます。

🎞️ マウント (Slide Mount)

フィルムのスライドマウント枠を再現した鑑賞モード。「情報」ボタンをOFFにすれば無地枠で作品を堪能できます。

1. 起動と終了のしかた（2つの閉じかた）

🚀 起動: フォルダ内の PhotoManager.exe をダブルクリックすると専用ウィンドウ（最大化状態）が開きます。
※Googleドライブ等で共有された直後で PhotoManager.exe がまだ無い場合は、初回だけ Build.bat をダブルクリックしてください（PhotoManager.exe とUSBアイコン設定 autorun.inf が自動作成されてそのまま起動します）。

⏻ 完全終了（USBを抜く前など）: 画面右上の 「⏻ 終了」ボタン →「サーバーを停止して終了」を選びます。

× 画面だけ閉じる（高速起動待機）: ウィンドウ右上の「×」で閉じると裏で待機状態になり、次回 PhotoManager.exe を開いたときに 0.1秒 で画面が復元します（Windows右下のタスクトレイのアイコンから完全終了もできます）。

2. 写真フォルダを登録する・更新する

📂 新しく登録する: 左サイドバーの 「📁 フォルダ」 を開き、パソコンや外付けドライブのツリーから写真フォルダをクリックします。「子フォルダを含む（おすすめ）」か「直下のみ」を選ぶと、すぐ下に進行バーが出て取り込みが始まります。

🔄 写真を追加・削除したあと: 登録済みのフォルダを左サイドバーでクリックするだけで、アプリが自動で変化を検知し「ライブラリをリフレッシュ（最新化）しますか？」と案内してくれます。

3. 片手でサクサク！写真の選別（4段階評価）

写真を選んでキーボードの数字キー（またはテンキー）を押すだけで、視線を動かさずに仕分けられます。

  • 1 キー：🏅 優（ベストショット！現像やSNS投稿したい最優秀カット）
  • 2 キー：⭐ 良（お気に入り・合格カット）
  • 3 または X キー：🗑️ 棄（ピンボケ・目つぶり等のボツ写真。一覧から自動で隠れます）
  • 0 または 4 キー：⚪ 可（評価を取り消して初期状態に戻す）

💡 「棄」にした写真を見返すには？ ファイル自体は削除されていません。上部ツールバーの 「🗑️ 棄」 ボタンをクリックして点灯させればいつでも再表示でき、0 キーで復活できます。

4. 拡大してピントを確認する（ライトボックス）

写真をダブルクリックするか、選んで Space / Enter キーを押すと全画面で拡大表示します（RAWデータも待ち時間ゼロで高画質表示されます）。

  • 前後の写真へ移動: キーボードの ← / → キー（または画面下部のフィルム帯でホイール）
  • 連写・ブラケット・重複の切替: キーボードの ↑ / ↓ キー（露出ブラケット時は ↑ で明るいEV+ / ↓ で暗いEV-、連写・重複時は ↑ で時間戻り / ↓ で時間進み）
  • ピント拡大ズーム: 見たい場所にマウスを合わせて ホイールを回す と、そこを中心に 100%〜400% 拡大します（ドラッグで移動、ダブルクリックで100%⇔200%切替）。
  • 90度回転: 横向きの写真は R（右回転）/ L（左回転）キーでその場で直せます。
  • 閉じる: もう一度 Space キーまたは Esc キーを押します。

5. 複数の写真をまとめて操作する ＆ 絞り込み検索

👥 複数選択: Ctrl+クリックで追加選択、Shift+クリックで範囲選択、Ctrl+A で全選択できます。選ぶと画面下部に黒い操作バーが現れ、まとめて評価付け・タグ付け・回転・書き出しが行えます。

🔍 写真を探す: 左サイドバーの「📅 撮影年月」「📷 カメラ機種」や、上部の「文字検索ボックス」で絞り込めます。元に戻すときは左サイドバー一番上の 「🖼️ すべての写真」 または 「↺ 絞り込み解除」 を押してください。

1. 連写・露出ブラケット・重複写真をまとめる（スタック機能）

上部ツールバーの 「スタック」 ボタンがONのとき、「連写」「露出ブラケット（AEB）」「別フォルダにある同一写真の重複コピー」を自動で1つの束にまとめ、代表の1枚だけを表示します。

  • 束の中身を見比べる: ライトボックス（Space）を開き、↑ / ↓ キーや下部のミニサムネイルバーで比較できます。
  • 代表（表紙）を変える: 気に入ったコマを表示して、右インスペクタやライトボックスの 「👑 代表に設定」 を押します。
  • 📋 重複写真の確認: 別フォルダに同じ写真がある場合はサムネイル右上角に「折り目マーク」が付きます。左サイドバー「クイックアクセス」の 「📋 重複のある写真」 から一覧でき、右インスペクタで保存先フォルダを確認・整理できます。

2. 階層タグ・色ラベル・ローカルAI自動分類

🏷️ 階層タグ: タグ入力時に 旅行/2026北海道/小樽 のように / で区切ると、左サイドバーで親子ツリーとして整理されます（タグ右端の ＋ ボタンから子タグの追加も可能）。

🎨 色合い（12色パレット）: 右インスペクタの「🎨 色合い」で写真にイメージ色を登録し、左サイドバーの「🎨 色合い」から色別に絞り込めます。

🤖 ローカルAI自動タグ付け: 左サイドバーのフォルダを右クリック → 「🤖 AIタグ付け」 を選ぶと、ネット通信なしでパソコン内のAIが「青空」「海」「猫」「料理」「夜景」などのタグを自動付与します。

🔍 含む [+] と除外 [-]: 左サイドバーのタグ一覧で [+] を押すとそのタグを含む写真、[-] を押すとそのタグを除外した写真に絞り込めます。

3. 傾き補正・切り抜き（クロップ）・明るさ微調整（完全非破壊）

写真を選んで C キー（またはライトボックス上部の 「✂」ボタン）を押すと、元ファイルを一切傷つけずに画面上で以下の調整ができます：

  • 切り抜き（アスペクト比）: 元の比率、1:1、16:9、4:3、3:2、自由サイズから選んで構図を調整（三分割ガイド線付き）。
  • 📐 傾き補正（水平出し）: -15°〜+15° の範囲で斜めの水平線をまっすぐに補正（周囲に黒い余白が出ないよう自動で内側を切り抜きます）。
  • ☀️ 明るさ・コントラスト・彩度: カメラの露出補正感覚（-2.0EV〜+2.0EV、1/3段ステップ）で明るさや色味を微調整。

💡 いつでも「↺ リセット」ボタンから撮影時の初期状態に100%戻せます。

4. 撮影場所（ジオタグ）ツリー ＆ 📍 スマホGPS準用

🗺️ 場所ツリー: GPS情報付き写真は、左サイドバー「🗺️ ジオタグ」から「国 ＞ 都道府県 ＞ 市区町村」の階層で絞り込めます。

📍 スマホから位置情報をコピー（スマホGPS準用）: GPSのない一眼カメラの写真でも、前後1時間以内に撮ったスマホ写真がライブラリにあれば位置情報を引き継げます。

  • 1枚ずつ比較して付ける: 右インスペクタの 「📍 スマホGPS準用」 を押し、前後のスマホ写真候補を見比べて選択。
  • 複数枚にまとめて付ける: 写真を複数選んで画面下部バーの 「📍 ジオタグ準用」 を押すと、最も時刻が近い位置情報を一括セットします。

5. 用途別にまとめて書き出す（📤 スマート・テイクアウト）

選んだ写真をSNS投稿用・印刷用・受け渡し用として別フォルダへ一括出力します。画面下部バーの 「📤 テイクアウト」＞「⚡ スマート・テイクアウト...」 から以下の処理を同時に行えます（元ファイルは無傷のまま維持）：

  • アプリ上で行った回転・傾き・切り抜き・明るさ調整の焼き込み
  • アプリ上で準用・変更した位置情報（GPS）や回転向きのExif反映
  • 長辺リサイズ（オリジナル / 4K 3840px / SNS最適 2048px / フルHD 1920px 等）
  • 複数カメラの写真も撮影時刻順に並べる連番リネーム（001_...）
  • SNS公開時に安心なExifプライバシー消去（位置情報のみ消去 / 撮影機材消去 / すべて消去 等）

6. 検索プリセット保存・外部ソフト連携・DBメンテナンス

💾 プリセット保存: よく使う絞り込み条件は、左サイドバー「💾 プリセット」の ＋ 保存 で名前を付けて登録し、ワンクリックで呼び出せます。

📁 外部ソフト連携 ＆ 🔄 サムネイル更新: 右インスペクタ上部の 📁 でエクスプローラーを開き、🖼️ で既定ソフトで開けます。外部ソフトで編集した後は、写真を右クリック →「🔄 サムネイルの更新」で表示を最新化できます。

🧹 DB最適化: 左サイドバー「📁 フォルダ」上部の 🧹 DB最適化 で、自動バックアップを取りつつデータベース容量をスリム化できます。

1. USBメモリ・外付けSSDでの3つの持ち歩きスタイル

  • ① 写真もアプリも丸ごとUSBに入れる: USBメモリ1本を別のPCに挿して PhotoManager.exe を開くだけで、どこでも同じ環境で使えます。
  • ② 元写真は自宅に置き「カタログ（USB）」だけ持ち歩く: 数百GB〜数TBの元写真は自宅HDDに置いたまま、Photo Manager が入ったUSBメモリだけを持ち歩けます。元写真が未接続（「🔌 未接続」表示）でも、全写真のサムネイル閲覧・評価・タグ付けが快適に行えます。
  • ③ ドライブ文字（D: → E: 等）が変わっても自動追従: 別のPCに挿してドライブ文字が変わっても、ドライブ固有情報を自動認識してリンク切れを防ぎます。

2. スマホで写真をサクサク選別する（2つの方法）

ソファや移動中の電車の中で、スマホの親指操作だけで大量の写真を4段階評価（優・良・可・棄）＆タグ付けできます。

🏠 方法A：自宅のWi-Fiでつなぐ（リアルタイム反映）

  1. パソコン画面右上の 「📱 スマホ連携」 ボタンをクリックします。
  2. 表示された QRコード をスマホのカメラで読み取って開きます（同じWi-Fiに接続）。
  3. スマホで付けた評価やタグが、その瞬間にパソコン画面へリアルタイム反映されます！

🚃 方法B：外出先・ネット圏外でUSBメモリを直接スマホに挿す（完全オフライン）

  1. パソコン電源OFF・ネット圏外でも使えます。Photo Manager が入ったUSBメモリをAndroidスマホ等に挿します。
  2. スマホの「ファイル」アプリでUSB内の PhotoManager_Mobile.html をタップしてブラウザで開きます（※開けない機種では、このHTMLファイル1つだけをスマホ本体のダウンロードフォルダ等にコピーして開いてください）。
  3. 画面の 「📂 DB読込」 をタップし、USBメモリ内の cache フォルダ ＞ library.db を選ぶと、約1秒で全写真が読み込まれます。

3. スマホでの親指操作と、パソコンへの同期手順（USBオフライン時）

👍 親指ドックで連続選別: スマホで写真をタップして拡大し、画面下部の 「🗑️棄」「⚪可」「⭐良」「🏅優」 をタップします。「⚡自動送り」がONならタップと同時に次の写真へ進むため、片手で何百枚でも仕分けられます。

🔄 パソコンへの反映手順:

  1. 選別が終わったらスマホ画面の 「💾 変更を保存」 を押し、USBメモリの先頭（ルート）フォルダに mobile_sync.json を保存します。
  2. 保存完了メッセージから3秒ほど待ち、スマホの通知欄から 「USBドライブを取り外す（マウント解除）」 を実行してからUSBを抜きます。
  3. USBメモリをパソコンに挿して PhotoManager.exe を起動すると、自動的に選別結果が検出・反映され、完了通知が表示されます！

4. ⚠️ USBメモリを安全に抜くための鉄則

💻 パソコンから抜く前: 必ず画面右上の 「⏻ 終了」＞「サーバーを停止して終了」 で完全終了してから抜いてください。

📱 スマホから抜く前: mobile_sync.json 保存後、必ずスマホ通知欄の 「取り外す（マウント解除）」 を実行してから抜いてください（そのまま引き抜くと保存ファイルが空になることがあります）。

❓ よくある質問（FAQ）

Q. 3 キーで「棄」にしたら写真が消えました。ファイルが削除されたのですか？
A. いいえ、パソコン内のファイルは削除されていません。画面上部ツールバーの 「🗑️ 棄」 ボタンを押して点灯させればいつでも再表示でき、0 キーで元に戻せます。

Q. 回転や明るさ調整をした写真を、実際のファイルとして保存したいときは？
A. アプリ内の調整は元ファイルを傷つけない非破壊方式です。調整結果を焼き込んだ画像ファイルを作るには、画面下部バーの 「📤 テイクアウト」＞「⚡ スマート・テイクアウト...」 から書き出してください。

Q. Googleドライブ等で共有しようとしたらマルウェア（ウイルス）扱いされました。
A. 署名のない .exe や autorun.inf に対するクラウド側の自動誤検知です。共有時は build_dist.bat で出力される dist フォルダ（.exe を含まず、初回に Build.bat で現地生成する構成）をお使いください。

さらに詳しい解説はプロジェクト内の MANUAL.md をご覧ください。

【Step 1】PCからUSBを抜くとき
PC画面右上の 「⏻ 終了」ボタン から「サーバーを停止して終了」を実行し（ウィンドウの「×」だけではバックグラウンド常駐が維持されます）、Windowsタスクバー右下の「ハードウェアの安全な取り外し」を行ってからUSBメモリを抜きます。
【Step 2】スマホにUSBを挿して写真を読み込む
スマホにUSBを挿し、「ファイル」アプリでUSB内の PhotoManager_Mobile.html を開きます。続けて 「📂 library.db を読み込む」 から cache/library.db（現在 - MB）を選ぶと全写真が表示され、親指で高速選別できます（選別中はUSBを挿したままでOKです）。
【Step 3】選別結果をUSBに保存してスマホから抜く（⚠️最重要）
選別が終わったらスマホ画面右上の「📂 DB/同期」から 「💾 mobile_sync.json を保存する」 でUSB直下に保存します。
「✅ 書き込み・クローズ完了」と表示されたら、スマホ画面上の通知バーから「USBドライブを取り外す（マウント解除）」を必ずタップしてからUSBを抜いてください。
【Step 4】PCにUSBを挿して起動すると自動反映＆通知！
USBをPCに挿して PhotoManager.exe を起動すると、自動的に mobile_sync.json が取り込まれ、画面中央に「📱 スマホ選別データの取り込み完了」通知ウィンドウが表示されます。
