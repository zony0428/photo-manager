# 📷 Photo Manager - USBポータブル運用ガイド

このフォルダは、**USBメモリや外付けSSDに丸ごとコピーして持ち歩ける** ように設計されています。  
別のPC（職場・自宅・ノートPCなど）にPythonがインストールされていなくても、USB単体でそのまま動きます！

---

## 🚀 かんたん起動方法

1. **配布パッケージ（`dist` フォルダの中身）をUSBメモリのルート（最上位階層）に丸ごとコピーします。**
   - `autorun.inf` が同梱されているため、USBメモリを挿し直すとエクスプローラー上でUSBドライブのアイコンが Photo Manager のカメラアイコンになります。
2. **USBドライブ直下の `PhotoManager.exe` をダブルクリックするだけで瞬時に起動します！**
   - 黒い画面（DOS窓）を出さずに、専用アプリアイコン付きウィンドウで開きます。
   - ※ 万が一、PCのセキュリティソフト等で `PhotoManager.exe` がブロック・隔離された場合は、同フォルダの **`Build.bat`** をダブルクリックすると、Windows標準コンパイラを使ってその場で `PhotoManager.exe` と `autorun.inf` を再生成して起動できます。

※ 終了するときは、画面右上の **「⏻ 終了」ボタン** から安全にサーバーを停止して終了できます。

## 📂 写真の管理パターン（選べる3つの使い方）

### パターン1: 元写真もUSBに入れて持ち歩く場合（おすすめ）
- フォルダの中に **`photos`** フォルダを作成し、その中に写真を入れてください。
- ドライブ文字（D: や E: など）がPCごとに変わっても、自動的に相対パスとして認識されます。

### パターン2: 写真はPCに置いたまま「カタログ（タグ・評価・サムネイル）」だけ持ち歩く場合（超軽量！）
- 元写真ファイル（数百GB）をUSBに入れなくても大丈夫です。
- これまでにつけた**タグ・4段階評価・サムネイル・AIタグ・ブラケットスタック情報はすべて `cache/` フォルダに入っています**。
- USB単体で持ち歩けば、元写真が手元になくても**全写真の高速グリッド鑑賞・検索・タグ編集・評価付け**ができます！
- さらに、Androidスマホ等にUSBを挿して **`PhotoManager_Mobile.html`** を開けば、PC無し・ネット圏外でもスマホで数万枚の写真をサクサク選別し、後からPCへ差分同期できます。
- 元ファイルが未接続の写真は、画面上に **`🔌 未接続`** バッジが控えめに表示されます。

### パターン3: 元写真が入った外付けHDD/SSDを別のPCに繋ぐ場合
- 別のPCに繋いでドライブレター（例: `D:` → `F:`）が変わっても、Photo Manager が自動でドライブを追跡・再認識します。
- ファイル名やExif撮影日時が変わっていなければ、自動で既存のタグやサムネイルと再紐付けされます。

## 🛠️ フォルダ構成について

```text
USBドライブ (ルート)/
├── PhotoManager.exe           ★ 起動用アプリ本体（ダブルクリックで起動）
├── autorun.inf                ★ USBドライブアイコン定義（カメラアイコン設定）
├── Build.bat                  ★ 予備：ランチャー＆アイコン再生成バッチ
├── PhotoManager_Mobile.html   ★ スマホ用オフライン選別アプリ（単体完結型HTML）
├── start.bat                  ★ 予備起動用バッチ
├── MANUAL.md                  ★ 操作マニュアル
├── LICENSE / LICENSES/        ★ ライセンス表記一式
├── python/                    ★ USB同梱の独立Python環境（PCのPython不要）
├── models/                    ★ ローカルAI自動タグ付け用軽量モデル
├── cache/                     ★ データベース(library.db)とサムネイル画像
├── frontend/                  ★ UI画面（HTML/CSS/JS/アイコン）
├── server/                    ★ バックエンド処理（FastAPI/AI推論）
└── photos/                    ★ (任意) 一緒に持ち歩きたい写真を入れる場所
```

## ❓ トラブルシューティング

- **初回起動時に「Windows によって PC が保護されました（SmartScreen）」と出た場合**:  
  個人開発で商用のコード署名証明書を付与していないため表示される確認画面です。「詳細情報」→「実行」で起動するか、フォルダ内の **`Build.bat`** を1回ダブルクリックするとお使いのPC上で `PhotoManager.exe` がクリーンに再生成され、スムーズに起動します。
- **「実行可能なPythonが見つかりませんでした」と出る場合**:  
  インターネットに接続されたPCで **`setup_portable_python.bat`** を1回実行してください。公式の軽量Pythonと必要ライブラリが `python/` に自動ダウンロードされます。
- **ポートが使用中で起動できない場合**:  
  `run.py` 内の `PORT = 8088` を `8089` などに変更してください。
