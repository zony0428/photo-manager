# Photo Manager - USB ポータブル運用ガイド

このフォルダは、USB メモリや外付け SSD に丸ごとコピーして持ち歩けるように設計されています。  
別の PC（自宅・ノート PC など）に Python がインストールされていなくても、USB ドライブ単体でそのまま動作します。

---

## 起動と終了の手順

1. 配布パッケージ（ZIP を解凍した中身）を USB メモリや外付け SSD の任意のフォルダ（またはルート階層）にコピーします。
2. フォルダ内の `PhotoManager.exe` をダブルクリックすると、コマンドプロンプト画面を出さずに専用ウィンドウで起動します。
   - 初回起動時に Windows の保護画面（SmartScreen）やセキュリティソフトのブロックが出た場合は、同フォルダの `Build.bat` をダブルクリックしてください。Windows 標準搭載の C# コンパイラを使って、その場で平文のソースコード（`launcher/Launcher.cs`）から `PhotoManager.exe` を生成して起動します（USB ドライブ直下で実行した際は、ドライブアイコン設定用の `autorun.inf` も選択作成できます）。
3. 終了して USB ドライブを取り外すときは、画面右上の「終了」ボタンから「サーバーを停止して終了」を選び、プロセスを完全に停止させてから取り外してください。

## 写真の管理パターン（選べる3つの使い方）

### パターン1：元写真も USB（アプリ内ストレージ `storage/`）に入れて持ち歩く場合
- アプリ上で持ち出したい写真を選び、右クリックメニュー（または右インスペクタ）の「storageへインポート」を実行すると、アプリ内の `storage/` フォルダ（および作成したサブフォルダ）へ写真と付随するサイドカーファイル（`.xmp` 等）・ペア RAW が自動でコピー取り込みされます。
- 左サイドバー `フォルダ` 先頭の `storage (アプリ内ストレージ)` から、サブフォルダの作成・名前変更、写真のフォルダ間移動（ドラッグ＆ドロップ対応）、ファイル名変更（<kbd>F2</kbd> 単一／複数連番リネーム）、外部フォルダへのエクスポートがすべてアプリ内で完結します。
- ドライブ文字（`D:` や `E:` など）が PC ごとに変わっても、自動的に相対パスとして認識されます。

### パターン2：元写真は PC に置いたまま「カタログ（タグ・評価・サムネイル）」だけ持ち歩く場合
- 大容量の元写真ファイルを USB に入れなくても、カタログだけを軽量に持ち歩けます。
- これまでに付けたタグ・4段階評価・サムネイル・AI タグ・スタック情報はすべて `cache/library.db` に収録されています。
- USB 単体で持ち歩けば、元写真が手元になくても全写真のグリッド閲覧・検索・タグ編集・評価付けが行えます（元ファイルが未接続の写真は、画面上に「未接続」バッジが控えめに表示されます）。
- さらに、Android スマートフォン等に USB を挿して `PhotoManager_Mobile.html` を開けば、PC やネット環境がなくてもスマートフォンで写真を選別し、後から PC へ差分同期（`mobile_sync.json`）できます。

### パターン3：元写真が入った外付け HDD / SSD を別の PC に繋ぐ場合
- 別の PC に繋いでドライブ文字（例：`D:` → `F:`）が変わっても、Photo Manager がボリュームシリアル番号をもとに自動でドライブを追跡・再認識します。
- ファイル名や EXIF 撮影日時が変わっていなければ、既存のタグやサムネイルと自動的に紐付けられます。

## フォルダ構成

```text
PhotoManager/
├── PhotoManager.exe           起動用ランチャー本体（ダブルクリックで起動）
├── Build.bat                  ランチャー再生成＆USBアイコン(autorun.inf)設定バッチ
├── PhotoManager_Mobile.html   スマートフォン用オフライン選別アプリ（単一HTML）
├── start.bat                  予備起動用バッチ
├── MANUAL.md                  操作マニュアル
├── RELEASE_NOTES.md           リリースノート・更新履歴
├── LICENSE / LICENSES/        ライセンス表記一式
├── python/                    同梱のポータブル Python 3.11 環境（PCへのインストール不要）
├── models/                    ローカル AI 自動タグ付け用モデル
├── cache/                     SQLite データベース（library.db）とサムネイルデータ
├── frontend/                  UI 画面（HTML / CSS / JS）
├── server/                    バックエンド処理（FastAPI / RAW・画像解析）
└── storage/                   アプリ内ストレージ（インポートして持ち歩く写真・サブフォルダ）
```

## トラブルシューティング

- 初回起動時に「Windows によって PC が保護されました（SmartScreen）」と出た場合：  
  個人開発ソフトであり商用のコード署名証明書を付与していないため表示される確認画面です。「詳細情報」から「実行」をクリックするか、フォルダ内の `Build.bat` をダブルクリックするとお使いの PC 上で `PhotoManager.exe` が生成され、スムーズに起動します。
- 「実行可能な Python が見つかりませんでした」と出る場合：  
  GitHub のソースコードから直接取得した場合など、`python/` フォルダが空のときは、インターネットに接続された PC で `setup_portable_python.bat` を1回実行してください。公式の Embeddable Python と必要ライブラリが `python/` に自動構築されます。
- ポートが使用中で起動できない場合：  
  `run.py` 内の `PORT = 8088` を `8089` などに変更してください。
